# 다른 논문들은 성공률이 얼마인가 (2026-10-03)

> 사용자 질문: "다른 논문들 참고해서 논문들은 정확도 몇 나왔는지 알려주고 최대한 참고해서 해줘".
> 모두 원문 표에서 옮겼다. 조건(지연, 전환, 장면)이 우리와 다르면 따로 적었다.

## 1. LIBERO 기본 성적 — 지연 없음, 전환 없음, 과제당 사람 시범 50개

출처: [SmolVLA (arXiv 2506.01844) 표](https://arxiv.org/html/2506.01844v1), [OpenVLA-OFT (arXiv 2502.19645) 표](https://arxiv.org/html/2502.19645)

| 모델 | 크기 | Spatial | Object | **Goal** | Long | 평균 |
|---|---|---|---|---|---|---|
| Diffusion Policy | — | 78.3 | 92.5 | 68.3 | 50.5 | 72.4 |
| Octo | 0.09B | 78.9 | 85.7 | 84.6 | 51.1 | 75.1 |
| OpenVLA | 7B | 84.7 | 88.4 | 79.2 | 53.7 | 76.5 |
| π0 | 3.3B | 96.8 | 98.8 | **95.8** | 85.2 | 94.2 |
| π0-FAST | 3.3B | 96.4 | 96.8 | 88.6 | 60.2 | 85.5 |
| OpenVLA-OFT | 7B | 97.6 | 98.4 | **97.9** | 94.5 | **97.1** |
| SmolVLA (논문) | 0.45B | 90 | 96 | **92** | 71 | 87.3 |

- LIBERO-Goal 최고는 OpenVLA-OFT 97.9%. 우리 모델(SmolVLA 0.45B) 논문 값은 92%.
- 단, 이 값들은 **지연 없음, 고정 시작 배치**. [LIBERO-Plus](LIBERO-Plus.md)는 카메라·시작 자세를 조금 바꾸면 95% → 30% 미만으로 무너진다고 보고했다.

## 2. 추론 지연이 있을 때 — SmolVLA, LIBERO 네 묶음 평균

출처: [Understanding Async Inference (arXiv 2605.08168)](https://arxiv.org/abs/2605.08168) 그림에서 읽은 대략 값. 우리 지연은 11스텝.

| 지연(스텝) | 아무것도 안 함 | 추론 때 RTC | 학습 때 RTC (우리가 씀) | VLASH | **A2C2** (우리가 씀) |
|---|---|---|---|---|---|
| 0 | 61 | 75 | 60 | 57 | 70 |
| 8 | 25 | 52 | 51 | 56 | 66 |
| 20 | 10 | 20 | 25 | 55 | **58** |

[VLASH (arXiv 2512.01031)](https://arxiv.org/abs/2512.01031) 원문: π0.5 는 지연 0~2 에서 96.8~97.2% 유지(LIBERO 평균). SmolVLA 는 지연 3 에서 79.1%(지연 없음 79.0%).
[A2C2 (arXiv 2509.23224)](A2C2.md): LIBERO-Spatial 지연 10 에서 67% → 84%.

→ 지연이 클수록 A2C2·VLASH 가 가장 덜 무너진다. 그래도 **지연 10스텝 이상에서 90%를 넘긴 SmolVLA 결과는 없다**.

## 5. 우리 목표가 어느 정도인가

| | 다른 논문 최고 | 우리 목표 (PiPER) |
|---|---|---|
| 단독 (지연 없음) | 92~98% | 95% (지연 0.56초 있음) |
| 쥔 상태 전환 | 51~65% (시뮬) | 95% |
| 재개 | 없음 | 95% |
| 지연 | 지연 10스텝 이상 90% 넘는 결과 없음 | 11스텝 |

목표는 지금 나온 어떤 논문보다 높다. 그래서 다른 논문의 방법을 최대한 함께 쓴다.

## 6. 가져와 쓰는 것

| 논문 | 가져오는 것 | 상태 |
|---|---|---|
| SmolVLA·LIBERO | 과제당 시범 50개로 92% → 우리는 과제당 100개 이상 (정상 1,000 + 전환·재개 1,700) | 적용 |
| OpenVLA-OFT | 짧은 실행 간격(묶음 8) → 우리는 매 스텝 다시 계산(n_act 1) | 적용 |
| Training-Time RTC | 지연 동안 실행될 앞부분을 넣고 학습·추론 | 적용 |
| A2C2 | 매 스텝 손목 카메라로 마지막 1~2cm 보정 | 라운드마다 적용 (자동) |
| DAgger (HG-DAgger) | 학생이 실제 가는 상태에서 시범 프로그램이 넘겨받아 교정 | 라운드마다 적용 (자동) |
| SwitchVLA | 접촉 단계(쥐기 전·중·후)별 전환 시범 | 쥔 직후 전환 시범으로 적용 |
| Causeway | 전환 뒤 B 를 시작하기 좋은 자세로 | 시범 프로그램이 B 시작 자세로 이어 감 |
| VLASH | 지연 동안 실행될 동작으로 로봇 상태를 앞당겨 넣기 + 학습 때 시간 어긋남 섞기 | **다음 라운드 후보**: 1차 학생 모델 결과에서 지연 탓 실패가 많으면 추가 |
| LIBERO-Plus | 평가는 학습과 다른 배치로 | 적용 (새 배치 1000번대) |

## 7. VLASH 를 우리에게 쓸 수 있나 (10/3 밤 측정)

VLASH 는 모델이 생각하는 동안 실행될 동작으로 로봇 상태를 앞으로 굴려(손 위치를 미리 계산해) 넣는다. 학습 때는 사진은 그대로 두고 상태와 정답 동작만 시간을 밀어 섞는다.

PiPER 2차 시범(정상 수행 100개)으로, 0.56초(11스텝) 뒤 손 위치를 동작 명령으로 얼마나 맞힐 수 있는지 쟀다.

| 방법 | 11스텝 뒤 손 위치 오차 (중앙값) |
|---|---|
| 지금 위치 그대로 (아무것도 안 함) | 5.9cm (실제로 움직인 거리) |
| 동작 명령 합 × 0.31 (제어기가 명령의 약 31%만큼 따라감) | 1.5cm |
| 스텝마다 가중치 + 지난 속도 (최소제곱) | 1.3cm |

손 방향은 동작으로 예측하면 오히려 더 틀렸다(3.6° vs 그대로 2.6°). 위치만 앞당기는 게 맞다.

우리는 이미 생각하는 동안 실행될 동작 자체를 모델에 넣고 있어서(학습 때 지연 흉내내기), VLASH 를 더해 얼마나 나아질지는 모른다. PiPER 1차 모델을 지연 있음/없음으로 같은 장면에서 비교해(ab_numsteps.sh) 지연 손해가 크면 다음 라운드에 넣는다.

## 8. 블록 장면에서 100% 가까이 가기 위해 쓰는 것 (10/4, 사용자: "최대한 모든 기술력 논문 참고해서 정확도 100에 인접하게")

측정 전에는 모두 가설이다. 결과가 나오면 이 표에 "효과(측정)" 를 채운다.

| 무엇 | 출처 | 어떻게 | 상태 |
|---|---|---|---|
| 잡기 쉬운 물체 | SmolVLA 실물 실험(블록), PhysVLA(PiPER 블록 95%) | 색 블록·색 판 장면 | 적용 (시범 프로그램 100%) |
| 시범 많이 | LIBERO(과제당 50개로 92~98%) | 과제당 100개 → 2차 수집으로 200개, 일 바꾸기 쌍당 50 → 100 | 1차 수집 중, 2차 예약 |
| 흔들어 모은 시범 | DART | 시범 프로그램 동작에 잡음 0.1 → 벗어났다 돌아오는 시범 | 적용 |
| 멈춘 구간 잘라 냄 | (Panda 에서 배움) | 12프레임 넘게 멈춘 구간을 5프레임으로 | 적용 |
| 학생이 가는 자리에서 가르치기 | DAgger / HG-DAgger | 학생이 실제 조건(지연 0.56초)으로 하다가 시범 프로그램이 넘겨받음. 블록 장면에서는 맞는 블록을 쥐고 있으면 쥔 채 옮김 (놓았다 다시 집으면 버려지던 것 고침) | 2차 라운드 자동 |
| 생각하는 동안 실행될 동작을 넣고 학습 | Training-Time RTC | 지연 0~14스텝을 흉내내 학습 | 적용 |
| 매 스텝 마지막 1~2cm 보정 | A2C2 | 작은 보정 네트워크를 매 라운드 학습 | 라운드마다 자동 |
| 생각 시간 줄이기 | 흐름 정합(flow matching) 반복 수 (π0·SmolVLA 는 10) | 반복 10 → 5 로 0.56초 → 약 0.39초 (학습과 GPU 를 나눠 잰 비율로 추정, GPU 혼자 다시 잼) | 2차 라운드에서 같은 장면 비교 |
| 가중치 평균 | EMA | 0.999 | 적용 |
| 사진 흔들기 | OpenVLA-OFT·Diffusion Policy | 밝기·대비 ±10%, 위치 ±8픽셀 | 적용 |
| 평가는 처음 보는 자리 | LIBERO-Plus | 장면 1000번대 | 적용 |
