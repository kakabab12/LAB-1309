# Causeway: Restoring Task Accessibility for Instruction Switching in VLA Policies

- **저자 / 연도**: 2026-09-25 arXiv
- **링크**: https://arxiv.org/abs/2609.30913
- **읽은 날짜**: 2026-10-02 (본문 HTML 요약)

## 왜 중요한가

우리 연구와 가장 가까운 논문이다. 1주일 전에 나왔다. **LIBERO-Goal에서 A를 하다가 B 지시가 오는 상황**을 다룬다. 물체를 쥔 채 전환하는 경우도 들어 있다.

## 무엇을 하나

- 문제: 모델이 처음 자세에서는 B를 잘하는데, A를 하던 자세에서는 B를 못 한다. 저자들은 이걸 "B에 들어갈 수 있는 상태가 아니다"라고 부른다.
- 방법: 모델을 다시 학습하지 않는다. 추론할 때 B의 시범들에서 "B를 시작하기 좋은 손 자세"를 계산하고, 그쪽으로 가도록 모델 내부 표현을 조금씩 밀어 준다. 위치, 접근 방향, 손목 회전, 그리퍼를 따로 다룬다.
- 쥔 물체가 B에 필요 없으면 놓는 단계가 따로 있다.

## 결과

| 조건 | 그냥 전환 | Causeway |
|---|---|---|
| LIBERO-Goal (π0.5, OpenVLA-OFT, GR00T N1.5) | 3~26% | 47~65% |
| 실물 xArm 7쌍 | 14~43% | 82~100% |

"그냥 전환 3~26%"는 우리가 9월에 잰 SmolVLA 전환 18~39%와 비슷한 수준이다.

## 우리와 다른 점

| | Causeway | 우리 |
|---|---|---|
| 원래 일로 돌아가기(재개) | **없음** | 있음. 내려놓은 물체를 다시 집어 A를 마친다 |
| 처음 자세 | B 시작 자세로 끌어당김 (처음 자세는 아님) | 처음 자세 근처 7cm 안으로 들어가면 실패로 친다 |
| 모델 | π0.5, OFT, GR00T (3B 안팎) | SmolVLA 0.45B, GTX 1080 Ti |
| 추론 지연 | 묶음당 2.5~2.8배 느려짐, 메모리 +4.3GB | 추론 시간 그대로 (학습으로 해결) |
| 방법 | 추론 때 내부 표현 조작 (모델별 층·세기 조정 필요) | 선생 스크립트 시범 + DAgger로 학습 |

## 우리 논문에서

- 관련 연구에 반드시 넣는다. "전환 직후 B에 들어가지 못한다"는 같은 현상을 다른 이름으로 본 것이다.
- 차별점은 세 가지로 정리한다. (1) 재개까지 포함한 전체 흐름, (2) 처음 자세로 돌아가지 않는다는 제약을 수치로 확인, (3) 저사양 GPU 실시간 조건(지연 11스텝)에서 추론 비용 없이.
- 그들이 인정한 한계 "쥔 물체의 움직임, 큰 장면 변화에 약하다"는 우리가 정면으로 다루는 부분이다.
