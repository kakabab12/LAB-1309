# RoboMonkey: Scaling Test-Time Sampling and Verification for Vision-Language-Action Models

- **저자 / 연도 / 학회**: Jacky Kwok 외 / 2025 / **CoRL 2025**
- **링크**: https://arxiv.org/abs/2506.17811
- **읽은 날짜**: 2026-09-17 (초록 기준)

---

## 📌 쉬운 말 요약

**한 줄로**: VLA 가 동작을 **여러 개 뽑고 조금씩 흔들어** 후보를 늘린 뒤, **VLM 기반 검증기**가 제일 좋은 걸 고르는 방법입니다. 실행할 때 계산을 더 쓰면(테스트 타임 스케일링) 성능이 오릅니다.

**비유로**: 시험에서 답을 한 번에 쓰지 않고, **답안을 여러 개 써 본 다음 검토해서** 제일 확실한 걸 제출하는 것과 같습니다. 시간은 더 걸리지만 실수가 줄어듭니다.

**가장 중요한 수치**: **처음 보는 상황(OOD)에서 25%p 향상**, 익숙한 상황에서 8%p 향상.

**우리 연구와의 관계**: 전환 순간은 로봇에게 **처음 보는 상황(OOD)** 입니다. 이 논문에서 OOD 향상 폭이 특히 컸다는 게 `bon` 전략이 통할 가능성을 뒷받침합니다.

---

## 1. 문제

VLA 는 대규모 모방학습으로 잘 움직이지만, 실제 환경에서 **다양한 방식으로 실패**합니다. 언어 모델 분야에서는 "여러 번 뽑고 검증하기"로 성능을 올리는 게 효과적이었는데(테스트 타임 스케일링), 로봇에도 통할까?

## 2. 핵심 아이디어

1. **후보 늘리기**: VLA 에서 소수 샘플 → **가우시안 노이즈로 흔들어** 후보를 더 만들고 → 다수결로 후보 분포 구성
2. **검증기로 고르기**: VLM 기반 **동작 검증기**가 (이미지, 지시, 동작)을 보고 점수
3. **검증기 학습 데이터는 합성**으로 대량 생성

## 3. 작동 원리

```
이미지 + 지시
    │
    ▼
VLA 에서 동작 몇 개 샘플
    │
    ▼
가우시안 노이즈로 흔들어 후보 확장 + 다수결로 정리
    │
    ▼
VLM 검증기가 후보마다 점수
    │
    ▼
최고 점수 동작 실행
```

- 검증기 학습용 **합성 데이터 파이프라인**: 데이터를 늘릴수록 검증과 최종 성공률이 꾸준히 좋아짐
- 새 로봇에 적응할 때 **VLA 와 검증기를 같이 파인튜닝**하면 VLA 만 할 때보다 7%p 더 좋음

## 4. 실험

| 상황 | 향상 |
|---|---|
| **분포 밖(OOD) 태스크** | **+25%p** |
| 분포 안 태스크 | +8%p |
| 새 로봇 적응 | VLA+검증기 파인튜닝이 VLA 만보다 +7%p |

## 5. 한계

- 후보를 여러 개 계산하고 VLM 검증기까지 돌려서 **실행이 무거움**
- 검증기가 틀리면 나쁜 동작을 고를 수 있음

## 6. 내 연구와의 관계

### 왜 중요한가

전환 순간 로봇 팔은 학습 때 본 자세에서 **12~27cm 벗어나** 있습니다 ([ablation](../04_실습/05_libero/retreat_ablation/README.md)) → 전형적인 **OOD 상황**. RoboMonkey 가 OOD 에서 향상 폭이 가장 컸다는 건 **후보를 뽑고 고르는 방식이 우리 문제에 맞을 수 있다**는 근거입니다.

### 참고해서 쓴 곳

- `bon` 전략의 설계 근거 (여러 개 뽑아 고르기가 OOD 에 효과)
- 후보 다양성 확보: SmolVLA 는 flow matching 이라 **초기 노이즈만 바꿔도** 서로 다른 후보가 나옴 (RoboMonkey 의 "가우시안 흔들기"와 같은 역할)

### 1080 Ti 에서의 차이

| | RoboMonkey | 우리 `bon` |
|---|---|---|
| 검증기 | VLM (무거움) | 성공 궤적 거리 (가벼움) |
| 후보 수 | 수십 개 | 8개 |
| 학습 | 검증기 학습 필요 | 없음 |

## 7. 용어

| 용어 | 뜻 |
|---|---|
| 테스트 타임 스케일링 | 학습이 아니라 **실행할 때** 계산을 더 써서 성능을 올리는 것 |
| 검증기 (verifier) | 후보가 맞는지·좋은지 판정하는 모델 |
| OOD (out-of-distribution) | 학습 데이터 분포 밖의 처음 보는 상황 |
| 다수결 (majority voting) | 여러 후보 중 가장 많이 나온 쪽 선택 |
