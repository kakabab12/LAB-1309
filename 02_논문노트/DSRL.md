- **저자 / 연도 / 학회**: Andrew Wagenmaker 외 (UC Berkeley) / 2025 / **CoRL 2025**
- **링크**: https://arxiv.org/abs/2506.15799
- **코드**: https://github.com/ajwagen/dsrl (π0 조종 예시 포함)
- **읽은 날짜**: 2026-09-17 (초록·코드 저장소 설명 기준)

## 📌 쉬운 말 요약

**한 줄로**: diffusion·flow 정책은 **노이즈에서 출발해 동작을 만듭니다.** 그러면 정책은 그대로 두고 **"어떤 노이즈에서 출발할지"만 강화학습으로 고르면** 원하는 방향으로 조종할 수 있다는 방법입니다.

**비유로**: 공 굴리는 기계(정책)가 있는데, 기계는 못 고친다고 합시다. 대신 **공을 어느 위치에 올려놓느냐**(노이즈)에 따라 공이 굴러가는 곳이 달라집니다. DSRL 은 기계를 고치지 않고 **"공을 어디에 올려놓을지" 배우는 작은 조수**를 둡니다.

**놀라운 점**: 조수가 작습니다. π0(30억 파라미터)를 조종하는 데 학습 파라미터가 **약 50만 개**면 됩니다.

**우리 연구와의 관계**: SmolVLA 도 flow matching 이라 **그대로 적용 가능**합니다. 1080 Ti 에서 학습할 수 있는 크기이고, 가중치를 안 바꾸니 **망각이 없고**, 결과 동작은 여전히 원래 정책이 만드니 **자연스러움**도 유지됩니다. `bon`(노이즈를 여러 개 뽑아 고르기)의 **학습 버전**이라고 볼 수 있습니다.

## 1. 문제

diffusion·flow 정책을 강화학습으로 더 좋게 만들고 싶은데

- 여러 단계에 걸친 생성 과정 전체로 기울기를 흘려야 해서 **학습이 불안정하고 비쌈**
- 가중치를 바꾸면 **원래 능력을 잃을** 수 있음
- 모델이 크면(VLA) 파인튜닝 자체가 부담

## 2. 핵심 아이디어

```
보통의 flow 정책:   노이즈 z ~ 표준정규분포  ──▶  [얼린 정책]  ──▶  동작 a

DSRL:              상태 s ──▶ [작은 노이즈 정책] ──▶ z  ──▶  [얼린 정책]  ──▶  동작 a
                              ↑ 강화학습으로 이것만 학습
```

- 원래 정책은 **완전히 고정** (내부를 몰라도 됨 — black-box)
- 강화학습의 "동작 공간"이 **노이즈 공간**이 됨
- 노이즈 z 를 바꾸면 원래 정책이 **자기가 할 줄 아는 동작 범위 안에서** 다른 동작을 냄 → 이상한 동작이 나올 위험이 적음

## 3. 작동 원리

1. 상태를 보고 노이즈 z 를 출력하는 작은 정책을 만듦
2. z 를 원래 정책에 넣어 동작 생성 → 환경에서 실행 → 보상
3. **SAC**(표준 강화학습 알고리즘)로 노이즈 정책만 학습
4. 원래 정책의 생성 과정으로는 기울기를 흘리지 않음 → 계산이 가벼움

## 4. 실험

- 시뮬레이션 벤치마크, 실물 로봇, **범용 정책(π0) 조종**에서 효과
- **샘플 효율이 높음** — 적은 환경 상호작용으로 성능 향상
- π0 조종에 학습 파라미터 약 50만 개

## 4-2. ⭐ 우리 측정이 DSRL 의 전제와 한계를 둘 다 확인했다 (2026-09-18)

DSRL 의 전제는 **"노이즈가 의미 있는 조종 손잡이"** 라는 것입니다. 우리 환경에서 직접 쟀습니다.

| 우리 측정 | 값 | DSRL 과의 관계 |
|---|---|---|
| 같은 상태·같은 지시, 노이즈만 다르게 8번 → 성공 개수 | 0~7개로 갈림 | ✅ **전제 확인** — 노이즈가 결과를 가른다 |
| 미사용 에피소드에서 좋은 시드 vs 나쁜 시드 | **90% vs 20%** (짝 비교 7:0, p=0.016) | ✅ 전제 확인 |
| 좋은 시드는 [idling](PIP-Policy-Idling.md) 10%, 나쁜 시드는 90% | - | ✅ **무엇을 조종하는지**까지 규명 |
| **어떤 노이즈로도 성공 못 하는 상태** | **42%** (1→5 는 100%) | ⚠️ **한계 확인** — 5절의 "아예 못 만드는 동작" |
| 완벽한 노이즈 선택기의 상한 | 28% → **58%** | 노이즈 공간 RL 의 **천장** |

**읽는 법**: 우리 문제에서 DSRL 로 얻을 수 있는 최대치는 **28% → 58%** 입니다.
나머지 42% 는 노이즈를 어떻게 골라도 안 되므로 **다른 방법**(학습으로 정책 자체를 바꾸기)이 필요합니다.

자세히: [오라클 Best-of-N](../04_실습/05_libero/oracle_bon/README.md), [노이즈 시드](../04_실습/05_libero/noise_seed/README.md)

### 우리가 쓴다면 (1080 Ti 기준)

| 항목 | 설계 |
|---|---|
| 조종 시점 | **전환 순간의 첫 chunk** (초반 노이즈가 결정적이라는 증거가 있음) |
| 상태 특징 | `embed_prefix` 평균 풀링 960차원 (이미 [판정기 실험](../04_실습/05_libero/lora_v2/README.md)에서 공짜로 뽑고 있음) |
| 보상 | LIBERO BDDL goal 성공 (이미 구현) |
| 학습 | SAC, 노이즈 정책만 (~50만 파라미터) |
| 주의 | 42% 의 상태에서는 보상이 **항상 0** → 학습 신호가 없다. 쉬운 쌍만으로 먼저 검증할 것 |

## 5. 한계

- 원래 정책이 **아예 못 만드는 동작**은 노이즈를 어떻게 바꿔도 안 나옴
- 강화학습이라 보상 설계와 환경 상호작용이 필요 (시뮬레이션에서는 LIBERO 성공 판정이 보상이 됨)

## 6. 내 연구와의 관계

### 왜 우리에게 잘 맞나

| 우리 조건 | DSRL 이 맞는 이유 |
|---|---|
| SmolVLA = flow matching | 노이즈 공간 조종이 그대로 적용됨 |
| 1080 Ti | 노이즈 정책이 작음 (π0 기준 50만 개) |
| **리셋 금지 + 자연스러움** | 동작은 여전히 원래 정책이 만듦 → 부자연스러운 스크립트 동작이 끼지 않음 |
| **LoRA 1차 망각** | 가중치를 안 바꿈 → 망각 없음 |
| **LoRA 1차 "못하는 건 데이터가 안 생김"** | 강화학습이라 **실패에서도 학습** ([Q-Planning](Q-Planning.md) 이 지적한 filtered SFT 의 한계를 피함) |
| LIBERO 성공 판정 | 보상으로 바로 사용 |

### `bon` 과의 관계

| | `bon` (지금) | DSRL (다음 후보) |
|---|---|---|
| 노이즈 | 무작위로 N개 뽑음 | **상태를 보고 좋은 노이즈를 바로 출력** |
| 고르는 기준 | 성공 궤적 거리 (사람이 정한 점수) | **실제 성공 보상으로 학습** |
| 실행 비용 | 추론 N배 | 추론 1배 + 작은 정책 |
| 학습 | 없음 | 강화학습 |

**`bon` 이 효과가 있으면** → "좋은 노이즈가 존재한다"는 뜻 → DSRL 로 그 노이즈를 **바로 찾도록 학습**하는 게 다음 단계. `bon` 은 DSRL 이 통할지 미리 확인하는 싼 실험입니다.

### 적용 계획 (후보)

- 노이즈 정책 입력: 로봇 상태 8차원 + 지시문 임베딩 (+ 필요하면 SmolVLA 이미지 특징)
- 노이즈 출력: chunk 앞부분(예: 10스텝 × 7차원)만 조종하고 나머지는 표준 노이즈
- 보상: B 성공 1, 실패 0 (+ 자연스러움 보너스: 우회 비율이 작을수록)
- 학습 환경: 전환 시점 상태에서 시작하는 LIBERO 에피소드

## 7. 용어

| 용어 | 뜻 |
|---|---|
| latent (잠재) 공간 | 모델이 내부적으로 쓰는 숨은 변수 공간. 여기서는 노이즈 z |
| 강화학습 (RL) | 보상을 최대화하도록 시행착오로 배우기 |
| SAC (Soft Actor-Critic) | 연속 동작에 널리 쓰는 강화학습 알고리즘 |
| 샘플 효율 | 적은 경험으로 많이 배우는 정도 |
| steering (조종) | 모델을 바꾸지 않고 입력·조건으로 출력을 원하는 쪽으로 이끄는 것 |
