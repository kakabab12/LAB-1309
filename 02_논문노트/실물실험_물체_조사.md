# 실물 실험에 쓰는 물체 조사 (2026-10-03)

PiPER 실물 실험을 준비하며, 다른 논문이 어떤 물체로 실험했는지 정리했다. 물체가 나온 위치(절·표)까지 적었다.

## 한눈에

| 논문 | 로봇 | 물체 | 태스크 |
|---|---|---|---|
| SwitchVLA (전환) | Franka Panda 2팔 | 레몬, 콜라병, 쿠키 상자, 껌 통, 휴지, 샌드위치, 접시, 문 달린 캐비닛 | ○○를 집어 접시에, 캐비닛 열기, 접시를 손님 쪽으로 밀기 |
| Causeway (전환) | xArm 6 | 버튼, 그릇, 접시, 선반, 서랍 속 옥수수 | 버튼, 그릇→접시, 그릇→선반, 옥수수 |
| VLA-Corrector | **AgileX PiPER** | 정육면체 블록, 표시 구역, 작은 서랍장 윗면, 파란 그릇, 네모 구멍 | 집어 놓기 3, 정밀 맞추기 3, 방해 회복 3 |
| PhysVLA | **AgileX PiPER** | 직육면체 스펀지 블록, 도자기 접시 | 스펀지를 접시에 |
| Action with Visual Primitives | AgileX PiPER 2대 | 장기말, 도미노, 일반 물체 | 장기, 도미노 놓기, 집어 놓기 |
| SmolVLA | SO-100 | 색 블록 | 집어 놓기, 쌓기, 색 분류 |

## 논문별 출처

### SwitchVLA — 전환 연구, 우리와 가장 가까운 선행 연구
- 제목: *SwitchVLA: Execution-Aware Task Switching for Vision-Language-Action Models*
- 링크: [arXiv 2506.03574](https://arxiv.org/abs/2506.03574) (2025-06)
- 로봇: Franka Emika Panda 2팔 작업대 2곳, RobotiQ 2F-85 그리퍼, RealSense D455/D457 3대(손목 2, 위쪽 1), 15Hz, RTX 4090 추론
- 물체·태스크 (실물 실험 절): 레몬·콜라병·쿠키·껌 통·휴지·샌드위치를 집어 접시에, 위쪽 캐비닛 문 밀어 열기, 접시를 손님 쪽으로 밀기. 태스크 4개로 순서쌍 12개(₄P₂), 쌍마다 12번

### Causeway — 전환 연구, 가장 최근 경쟁 논문
- 제목: *Causeway: Restoring Task Accessibility for Instruction Switching in VLA Policies*
- 링크: [arXiv 2609.30913](https://arxiv.org/abs/2609.30913) (2026-09-25)
- 로봇: xArm 6
- 물체·태스크 (VI절 실물 실험): 버튼, 그릇→접시, 그릇→선반, 서랍 속 옥수수. 단독 성공 80~100%, 순서쌍 7개(다른 물체 5, 같은 물체 2)
- 노트: [Causeway.md](Causeway.md)

### VLA-Corrector — PiPER 사용
- 제목: *VLA-Corrector: Lightweight Detect-and-Correct Inference for Adaptive Action Horizon*
- 저자: Yi Pan 외 (Zhejiang University, Alibaba DAMO Academy)
- 링크: [arXiv 2607.01804](https://arxiv.org/abs/2607.01804) (2026-07-02), 코드 [ZJU-OmniAI/vla-corrector](https://github.com/ZJU-OmniAI/vla-corrector)
- 로봇: AgileX PiPER 6축, π0.5 (시뮬레이션에서는 SmolVLA도 사용)
- 물체·태스크 (4.3절, 부록 E 표 14): 그룹 3개 × 태스크 3개 × 20번
  - 집어 놓기: 블록을 표시 구역에 / 작은 서랍장 윗면에 / 정해진 그릇에
  - 정밀 맞추기: 블록을 서랍장 윗면 왼쪽 위 모서리에 / 작은 블록을 네모 구멍에 넣기 / 물체 가장자리 맞추기
  - 방해 회복: 실행 중 사람이 물체나 목표(파란 그릇)를 옮김
- 결과: 평균 55.6% → 73.3%

### PhysVLA — PiPER 사용
- 제목: *PhysVLA: Towards Physically-Grounded VLA for Embodied Robotic Manipulation*
- 저자: Namai Chandra, Shriram Damodaran, Lin Wang
- 링크: [arXiv 2606.13886](https://arxiv.org/abs/2606.13886) (2026-06-11)
- 로봇: AgileX PiPER 6축, OpenVLA
- 물체·태스크 (4.2.3절, 그림 6): 직육면체 스펀지 블록을 탁자에서 집어 도자기 접시에. 방식마다 20번, 45% → 95%

### Action with Visual Primitives — PiPER 2대
- 링크: [arXiv 2605.22183](https://arxiv.org/abs/2605.22183)
- 로봇: AgileX PiPER 2대 (밑동 간격 54.4cm)
- 물체·태스크: 장기말 옮기기, 도미노 놓기, 일반 물체 집어 놓기 (검색 요약 기준, 본문 미확인)

### SmolVLA — 우리가 쓰는 모델
- 제목: *SmolVLA: A Vision-Language-Action Model for Affordable and Efficient Robotics* (Hugging Face, 2025)
- 로봇: SO-100 / SO-101
- 물체·태스크: 색 블록 집어 놓기, 쌓기, 색 분류 (검색 요약 기준)

## 정리

- 전환을 다룬 논문(SwitchVLA, Causeway)은 그릇·접시·캐비닛/서랍·선반·버튼 같은 생활용품을 쓴다. LIBERO와 비슷하게 가면 비교가 쉽다.
- PiPER 논문은 블록·스펀지·그릇·접시처럼 잡기 쉬운 물체를 쓰고, 태스크마다 20번씩 잰다.

## 우리 구성 (안)

| 역할 | 물체 |
|---|---|
| 본 실험 (LIBERO와 같은 종류) | 가벼운 그릇, 테두리 있는 접시, 손잡이 달린 작은 서랍장, 손잡이 돌리는 장난감 스토브(또는 버튼), 빈 플라스틱 병, 작은 상자 |
| 일반화 시험 | 색 블록, 스펀지 |

PiPER 그리퍼 최대 폭은 약 7cm (MuJoCo Menagerie 모델: 손가락 2개 각 0~35mm). 잡는 부분이 그보다 작아야 한다.
