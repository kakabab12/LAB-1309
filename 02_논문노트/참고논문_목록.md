# 참고 논문 목록 — 어디에 무엇을 참고했나

연구에 실제로 가져다 쓴 논문만 모았습니다. 각 논문 노트에 자세한 내용이 있습니다.

## 한눈에

| 논문 | 연도·학회 | 참고한 곳 | 가져온 것 |
|---|---|---|---|
| [SmolVLA](SmolVLA.md) | 2025 | 전체 | 사용 모델, LoRA 대상 선택 근거 |
| [LIBERO](https://arxiv.org/abs/2306.03310) | 2023 NeurIPS D&B | 전체 | 시뮬레이션 벤치마크, BDDL goal 로 성공 판정 |
| [SwitchVLA](SwitchVLA.md) | 2025 | [연구주제.md](../연구주제.md), 9/16·9/17 일지 | 전환 시점을 접촉 전/중/후로 나누는 실험 설계. `advance`(기준 자세로 이동)를 금지해 차별점으로 삼음 |
| [ReSteer](ReSteer.md) | 2026-03 | `steerability.py`, 실패 원인 분석 | **조종 가능성을 CMI 로 재는 방법**. 같은 LIBERO-Goal. 전환 성공률 ≤ Pr[CMI≥τ] |
| [LIBERO-Plus](LIBERO-Plus.md) | 2025 | [자세 민감도](../04_실습/05_libero/pose_sensitivity/README.md) | 초기 상태 교란에 VLA 가 취약하다는 근거. 우리는 거리·각도 단위로 세분화 |
| [Real-Time Chunking](Real-Time-Chunking.md) | 2025 NeurIPS | `switch_experiment.py --strategy rtc` | 이전 chunk 를 guidance 로 주는 inpainting 방식 전환 |
| [DART](DART.md) | 2017 CoRL | `collect_robust_data.py --mode pose` | 일부러 벗어난 상태를 만들어 교정 데이터 수집 |
| [Reverse Curriculum](Reverse-Curriculum.md) | 2017 CoRL | LoRA 2차 교란 범위, 3차 계획 | 교란 범위를 단계적으로 넓히기, 성공률 구간으로 난이도 고르기 |
| [HER](HER.md) | 2017 NeurIPS | `collect_robust_data.py --mode hindsight` | 실패한 궤적에 실제로 달성한 태스크 이름표를 붙여 재활용 |
| [LoRA](LoRA-망각.md) | 2021 ICLR'22 | `train_lora.py` | 1080 Ti 에서 action expert 파인튜닝 |
| [LoRA Learns Less and Forgets Less](LoRA-망각.md) | 2024 TMLR | LoRA 2차 설정 | 망각 완화: rank 16→8, lr 낮춤, 리허설 |
| [Q-Planning](Q-Planning.md) | 2026 | LoRA 1차 실패 분석 | "성공만 재학습은 정체된다" — 우리 실패의 설명. 정책을 얼리고 후보 중 고르는 방향 |
| [V-GPS](V-GPS.md) | 2024 CoRL | `bon` 전략 구조 | 정책을 얼리고 가치 함수로 후보 재순위 → 가중치 안 바꿔 망각 없음 |
| [RoboMonkey](RoboMonkey.md) | 2025 CoRL | `bon` 전략 근거 | 여러 개 뽑고 검증 → **OOD 에서 +25%p**. 전환 순간은 OOD |
| [DSRL](DSRL.md) | 2025 CoRL | 다음 단계 후보 | 얼린 flow 정책의 **노이즈만 강화학습**으로 조종 (약 50만 파라미터). `bon` 의 학습 버전 |
| [DAgger](https://arxiv.org/abs/1011.0686) | 2011 AISTATS | 문제 정의 | 공변량 이동 개념. 전문가가 없어 그대로 쓰지는 못함 |
| [MemoryVLA](https://arxiv.org/abs/2508.19236) | 2025 | 후순위 검토 | 기억 모듈. 실패 원인이 기억이 아닌 자세라 보류 |
| [기억·재개 조사](기억과_재개_조사.md) | 2024~2026 | [연구주제.md](../연구주제.md) 위치 확인 | MEMOBench·RoboMemArena 등 최신 기억 벤치마크에도 **중단 후 재개가 없음** → 우리 자리 확인 |
| [Hi Robot](https://arxiv.org/abs/2502.19417) | 2025 ICML | 문제 정의 | 도중 개입·수정 지시 처리 (계층형) |

## 연구 흐름별로 보면

```
문제 정의        SwitchVLA, Hi Robot, DAgger(공변량 이동)
원인 규명        LIBERO-Plus (초기 상태에 취약) → 우리 자세 민감도·ablation
학습 없는 방법   Real-Time Chunking (rtc 전략), V-GPS·RoboMonkey·Q-Planning (bon 전략: 후보 중 고르기)
학습하는 방법    LoRA + DART(교란 데이터) + HER(이름표 바꾸기) + Reverse Curriculum(단계적 확장)
실패 분석        Q-Planning (성공만 재학습은 정체), LoRA 망각 논문 (rank·리허설)
다음 후보        DSRL (노이즈 공간 강화학습 — 망각 없고 실패에서도 배움), 작은 가치 함수 (V-GPS 식)
```
