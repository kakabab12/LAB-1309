# Beyond Imitation: Self-Improving Robot Policies via Off-Policy Q-Planning

- **연도**: 2026 / arXiv
- **링크**: https://arxiv.org/abs/2608.21204 · 프로젝트 https://q-planning.github.io/
- **읽은 날짜**: 2026-09-17 (본문 HTML 기준)

## 1. 문제

모방학습 정책은 실패에서 배울 수 없다. **성공한 궤적만 다시 학습(filtered SFT)하면 금방 정체된다.**

## 2. 핵심 아이디어

정책(BC)은 **얼려두고**, 작은 Q 함수만 스스로 모은 궤적(성공·실패 모두)으로 학습해서, 정책이 뽑은 후보 동작 중 좋은 것을 고른다.

## 3. 방법

- 매 계획 단계: 정책에서 동작 chunk 후보 N개 샘플 (N=32~64)
- Q 함수(DinoV2 + T5 + transformer, 약 1B)가 각 후보의 성공 가능성을 점수화 → softmax 가중 평균 chunk 실행
- 보상: 성공 시점에만 1, 나머지 0. **실패 궤적은 목표값 0 으로 그대로 학습에 사용**
- BC 정책 가중치는 한 번도 바꾸지 않음

## 4. 실험

| 방법 | LIBERO |
|---|---|
| 기반 정책 | 90% |
| Filtered SFT (성공만 재학습) | **93.5% 에서 정체** |
| Best-of-N | 95% 에서 정체 |
| Q-Planning (10회 반복) | **99%** |

- 학습: H200 4장, Q 추론 N=64 에서 640ms

## 5. 한계

- Q 함수가 1B 파라미터라 1080 Ti 에서는 그대로 못 씀

## 6. 내 연구와의 관계

- **LoRA 1차 실패를 설명한다.** 우리 방식이 바로 filtered SFT(성공만 재학습)였고, 논문도 같은 정체를 보고했다
- **가져올 수 있는 것**
  1. 실패 궤적도 버리지 않기 — 이미 1,700+ 에피소드의 성공/실패 기록이 있다
  2. 정책은 얼리고 **후보 여러 개 중 고르기** — SmolVLA 는 flow matching 이라 노이즈만 바꾸면 후보가 나온다
  3. 1080 Ti 용으로 줄인 작은 점수 함수 (SmolVLA 의 이미지 특징을 재사용하면 인코더를 따로 둘 필요가 없음)
- 전환 상황은 "초기 자세에서 먼 곳"이라 후보 대부분이 나쁠 수 있다 → Best-of-N 만으로 부족할 가능성, 실험으로 확인 필요
