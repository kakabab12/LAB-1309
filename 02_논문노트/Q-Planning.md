# Beyond Imitation: Self-Improving Robot Policies via Off-Policy Q-Planning

- **연도**: 2026 / arXiv
- **링크**: https://arxiv.org/abs/2608.21204 · 프로젝트 https://q-planning.github.io/
- **읽은 날짜**: 2026-09-17 (본문 HTML 기준)

## 📌 쉬운 말 요약

**한 줄로**: 로봇 정책은 그대로 두고, **"이 동작을 하면 성공할까?"를 점수 매기는 작은 심판**을 따로 학습시켜서, 정책이 내놓은 여러 후보 중 **점수가 높은 동작을 고르는** 방법입니다. 심판은 성공한 경험뿐 아니라 **실패한 경험에서도** 배웁니다.

**비유로**: 신입 요리사(정책)는 요리를 여러 방식으로 해볼 수 있지만 뭐가 맛있을지 잘 모릅니다. 옆에 **맛을 판단하는 선배(심판)** 를 두면, 신입이 떠올린 방법 여러 개 중 선배가 "이게 제일 낫겠다" 하는 걸 고릅니다. 선배는 **맛없었던 요리도 기억해서** "이렇게 하면 망한다"를 압니다.

**가장 중요한 발견**: **"성공한 것만 모아서 다시 학습시키는 방식(filtered SFT)은 금방 한계에 부딪힌다."** 실패에서 배울 수 없기 때문입니다.

**우리 연구와의 관계**: **LoRA 1차가 정확히 이 방식이었고, 정확히 이 이유로 실패했습니다.** 논문이 우리 실패를 설명해 줍니다.

## 1. 배경 — 모방학습 정책은 스스로 나아지지 못한다

모방학습(BC) 정책은 사람이 보여준 대로만 합니다. 실패해도 **왜 실패했는지 배울 방법이 없습니다.** 더 좋아지려면 사람 시연을 더 모아야 합니다.

흔히 쓰는 우회로가 두 가지 있습니다.

| 방법 | 방식 | 문제 |
|---|---|---|
| **Filtered SFT** | 로봇이 스스로 성공한 것만 골라 다시 학습 | **실패 정보를 버림** → 원래 못하는 건 영영 못함 |
| **Best-of-N** | 후보 N개를 뽑아 뭔가 기준으로 고름 | 기준이 약하면 효과 제한 |

## 2. 핵심 아이디어

1. **정책은 얼린다.** 한 번도 안 바꿈 → 원래 능력을 잃을 걱정이 없음
2. **작은 Q 함수(심판)만 학습한다.** "이 상황, 이 지시, 이 동작 묶음 → 결국 성공할 가능성"을 예측
3. 실행할 때 정책에서 **후보를 여러 개** 뽑고, **심판 점수로 골라** 실행
4. 실행 결과(성공이든 실패든)로 **심판만 다시 학습** → 반복

## 3. 작동 원리 — 단계별

### 3-1. 심판(Q 함수)의 구조

| 입력 | 인코더 |
|---|---|
| 카메라 이미지 | DinoV2 (약 3억) |
| 언어 지시 | T5 (약 2.2억) |
| 동작 묶음 (32스텝) | transformer 디코더가 위 둘을 참고 (약 5억) |

합계 **약 10억 파라미터**. 정책과 인코더를 공유하지 않습니다. 출력은 성공 가능성을 101칸으로 나눈 분포입니다 (HL-Gauss 방식, 회귀보다 안정적).

### 3-2. 실행할 때

```
현재 이미지 + 지시
      │
      ▼
정책에서 동작 묶음 후보 N개 뽑기 (N = 32~64, flow matching 3단계로 빠르게)
      │
      ▼
심판이 후보마다 점수 Q 매김
      │
      ▼
점수로 가중평균 (softmax) → 실행할 동작 묶음 1개
```

단순히 최고점 하나를 고르는 게 아니라 **점수 높은 것 위주로 섞습니다.** N=64 에서 한 번 계획에 약 640ms.

### 3-3. 심판을 학습할 때

- 보상: **성공한 순간에만 1**, 나머지 0
- **실패한 궤적은 목표값이 0으로 고정** → "이렇게 하면 실패한다"를 배움
- 다음 순간의 점수를 이용해 거꾸로 전파 (TD 학습, Q-chunking)
- 반복마다 태스크당 100 에피소드를 새로 모으고, 심판만 200 스텝 추가 학습 → **정책 전체를 다시 학습하는 것보다 훨씬 쌈**

## 4. 실험 결과

LIBERO

| 방법 | 성공률 | 추세 |
|---|---|---|
| 기반 정책 | 90.0% | - |
| **Filtered SFT** (성공만 재학습) | **93.5%** | **정체** |
| Best-of-N | 95% | 정체 |
| Q-Planning (학습만) | 93.0% | - |
| **Q-Planning (10회 반복)** | **99.0%** | 계속 오름 |

실물 양팔 로봇

| 과제 | Q-Planning (5회 반복) | 성공만 재학습 |
|---|---|---|
| 컵 쌓기 | 40% → **90%** | 55% 에서 정체 |
| 지갑 넣기 | 25% → **80%** | 30% 에서 정체 |

**Filtered SFT 가 정체한다**는 게 여러 환경에서 반복 확인됐습니다.

## 5. 한계

- 심판이 **10억 파라미터**, 학습에 **H200 4장** → 1080 Ti 에서는 그대로 못 씀
- 후보 N개를 매번 뽑아야 해서 추론이 무거움
- **정책이 좋은 후보를 하나도 못 내면** 심판이 골라도 소용없음

## 6. 내 연구와의 관계

### LoRA 1차 실패를 설명한다 ⭐

| | 논문 | 우리 LoRA 1차 |
|---|---|---|
| 방식 | Filtered SFT | 성공한 궤적만 모아 LoRA 학습 = **Filtered SFT** |
| 결과 | 93.5% 에서 정체 | 전환 **32% → 32%**, 못하던 쌍(1→5)은 데이터 0개 |
| 원인 | 실패 정보를 버림 | 실패 궤적을 전부 버림 |

우리가 겪은 일을 논문이 "구조적인 한계"라고 설명합니다. 우연히 운이 나빴던 게 아니라는 뜻입니다.

### 가져올 수 있는 것

1. **실패 궤적도 버리지 않기** — 이미 1,700개가 넘는 에피소드에 성공/실패 기록이 있음. 지금까지 전부 버리고 있었음
2. **정책은 얼리고 후보 중 고르기** — 망각 문제가 원천적으로 없음. SmolVLA 는 flow matching 이라 노이즈만 바꾸면 후보가 나옴
3. **1080 Ti 용 축소판 심판** — 논문은 인코더를 따로 두지만, **SmolVLA 가 이미 계산한 이미지·지시 특징을 재사용**하면 작은 헤드만 학습하면 됨

### 우리 상황에서의 우려

- 전환 순간 팔이 **학습 분포에서 12~27cm 벗어나** 있어서, 거기서 뽑은 후보가 **전부 나쁠 수 있음**. 그러면 고르기만으로는 부족 → LoRA(후보 자체를 좋게) + 심판(고르기)을 **같이** 써야 할 수도 있음
- 실험으로 확인할 계획: 먼저 **학습 없는 Best-of-N**(예: 후보 중 자세가 학습 분포에 가까워지는 것 고르기)으로 가능성을 보고, 효과가 있으면 작은 심판을 학습

## 7. 용어

| 용어 | 뜻 |
|---|---|
| Filtered SFT | 성공한 데이터만 골라 지도학습 |
| Best-of-N | 후보 N개를 뽑아 가장 좋은 것 선택 |
| Q 함수 | (상태, 동작) → 앞으로 받을 보상의 기대값. 여기선 "성공 가능성" |
| off-policy | 지금 정책이 아닌 과거 데이터로도 학습 가능 |
| TD 학습 | 다음 순간의 예측값을 이용해 현재 예측을 고치는 학습 |
| self-improvement | 사람 도움 없이 스스로 모은 경험으로 나아지기 |
