## 📌 쉬운 말 요약

**한 줄로**: 로봇에게 시범을 보여줄 때 **일부러 살짝 흔들어서** 길을 벗어나게 만들고, 거기서 **원래 길로 돌아오는 방법까지** 같이 가르치는 방법입니다.

**비유로**: 운전을 배울 때 교관이 늘 완벽하게만 운전해 보여주면, 학생은 "차선 한가운데서 똑바로 가는 법"만 봅니다. 그러다 실제로 차선을 조금 벗어나면 **어떻게 돌아와야 하는지 본 적이 없어서** 당황하고 점점 더 벗어납니다. DART 는 교관이 시범 중에 **일부러 핸들을 살짝 흔들고, 거기서 다시 차선으로 돌아오는 모습**까지 보여주는 방식입니다.

**우리 연구와의 관계**: 우리 로봇이 딱 이 문제로 실패합니다. 지시가 바뀌는 순간 팔이 학습 때 본 자세에서 12~27cm 벗어나 있고, 거기서 어떻게 할지 배운 적이 없습니다. 그래서 **팔을 일부러 틀어놓고 데이터를 모으는 방식**을 여기서 가져왔습니다.

## 1. 배경 — 모방학습의 고질적 문제, 공변량 이동

**Behavior Cloning(BC)** 은 "이 상황에서 전문가는 이렇게 했다"를 그대로 따라 하는 학습입니다. 문제는 이겁니다.

```
학습 데이터:  전문가가 지나간 상태들만 있음   ●──●──●──●──●  (좁은 길)
로봇 실행:    조금만 오차가 생겨도             ●──●──◐
              처음 보는 상태에 들어감                   ◯ ← 본 적 없음 → 더 틀림
                                                          ◯ ← 더 벗어남 → 실패
```

오차가 **눈덩이처럼 커집니다.** 이게 **공변량 이동(covariate shift)** 입니다. 학습 때 본 상태 분포와 실제 실행 때 만나는 상태 분포가 달라지는 현상입니다.

## 2. 기존 해결책 — DAgger 와 그 단점

**DAgger** (Ross 외, 2011) 는 이렇게 합니다.

1. 로봇이 직접 움직여 봄 → 벗어난 상태들을 만남
2. 그 상태마다 **전문가에게 "여기선 어떻게 해야 해?"라고 물어서** 정답을 받음
3. 데이터에 추가해 다시 학습

효과는 좋지만, **로봇이 헤매는 동안 사람이 계속 옆에서 정답을 알려줘야** 합니다. 로봇이 이상하게 움직이는 걸 보면서 동시에 올바른 동작을 알려주기는 매우 어렵습니다.

## 3. 핵심 아이디어 — 전문가 쪽에 노이즈를 넣자

DART 는 방향을 뒤집습니다. **로봇이 헤매게 두지 말고, 시범을 보이는 전문가 동작에 노이즈를 섞습니다.**

```
노이즈 없는 시범:   ●──●──●──●──●
노이즈 넣은 시범:   ●──◐──●──◐──●     ◐ = 살짝 벗어났다가
                        ╲╱    ╲╱       전문가가 다시 되돌림
```

- 전문가가 조금 벗어난 상태를 **직접 경험**하고, 거기서 **되돌아오는 교정 동작**을 보여줌
- 데이터가 "좁은 길"에서 "좀 더 넓은 길"로 넓어짐
- 사람 입장에서도 **자기가 운전하면서 흔들리는 걸 고치는 건 쉬움** (DAgger 보다 훨씬 편함)

## 4. 작동 원리 — 노이즈를 얼마나 넣나

노이즈가 너무 작으면 효과가 없고, 너무 크면 이상한 상태만 모입니다. DART 의 핵심은 **노이즈 크기를 로봇 정책의 실제 오차에 맞추는 것**입니다.

1. 노이즈를 넣어 시범 데이터 수집
2. 그걸로 로봇 정책 학습
3. 학습된 정책이 전문가와 **얼마나 다르게 움직이는지** 측정
4. **그 차이만큼** 다음 수집의 노이즈 크기를 정함
5. 반복

즉 "로봇이 실제로 이만큼 틀리니까, 시범도 그만큼 흔들어서 보여주자"입니다.

## 5. 실험 (논문)

- **MuJoCo 시뮬레이션**(알고리즘이 전문가 역할): on-policy 방법(DAgger)과 **비슷한 성능**을 더 적은 계산으로
- **실물 Toyota HSR 로봇**(사람이 전문가): 어수선한 곳에서 물건 집기에서 BC 보다 **크게 좋음**
- 이론적으로도 오차가 있는 로봇에 대해 BC 보다 공변량 이동을 더 줄인다는 분석 제시

## 6. 한계

- **좋은 전문가가 있어야 함.** 노이즈에서 되돌아오는 동작을 보여줄 누군가가 필요
- 벗어나는 방향이 노이즈로만 정해져서, 실제 로봇이 **특정 방향으로 크게 벗어나는** 경우는 못 다룰 수 있음

## 7. 내 연구와의 관계

### 우리 문제가 정확히 공변량 이동이다

| 측정 | 값 |
|---|---|
| 전환 순간 팔의 이탈 | **12~27cm** ([ablation](../04_실습/05_libero/retreat_ablation/README.md)) |
| 위치 10cm 벗어난 곳에서 시작하면 | 87% → **43%** ([자세 민감도](../04_실습/05_libero/pose_sensitivity/README.md)) |
| 손목 30도 돌린 채 시작하면 | 87% → **17%** |

### 참고해서 쓴 곳

- **자세 교란 데이터 수집** (`collect_robust_data.py --mode pose`)
  - DART 의 "일부러 벗어난 상태를 만든다"를 가져옴
  - 시작 자세를 무작위로 틀어놓고(1차 최대 8cm, 2차 8~20cm) 정책을 돌림
  - 스크립트로 자세를 만드는 구간은 **저장하지 않음** (그 동작을 배우면 안 되므로)

### DART 와 다른 점 — 그리고 그 때문에 생긴 문제

| | DART | 우리 |
|---|---|---|
| 전문가 | 사람 또는 좋은 알고리즘 | **없음** (모델 자신뿐) |
| 벗어난 상태에서의 정답 | 전문가가 보여줌 | 모델이 **스스로 성공한 것만** 골라 씀 |

우리에겐 전문가가 없어서, 벗어난 상태에서 **모델이 우연히 성공한 경우만** 데이터가 됩니다. 그래서 **모델이 원래 못하는 상황(1→5, 2→5 전환)은 데이터가 0개**였습니다 → [LoRA 1차 실패](../04_실습/05_libero/lora_v1/README.md). 이 한계는 [Q-Planning](Q-Planning.md) 논문이 정확히 지적한 부분입니다.

### 앞으로 쓸 계획

- **실행 중 동작 노이즈**: 시작 자세만 트는 게 아니라, 정책이 움직이는 동안 동작에 노이즈를 섞고 **성공한 에피소드에서 "노이즈 없는 정책 동작"을 정답으로** 저장 → 교정 동작 데이터
- DART 처럼 **노이즈 크기를 실제 이탈(12~27cm)에 맞추기**

## 8. 용어

| 용어 | 뜻 |
|---|---|
| Behavior Cloning (BC) | 전문가의 (상태 → 동작)을 지도학습으로 따라 하기 |
| 공변량 이동 (covariate shift) | 학습 때와 실행 때 만나는 상태 분포가 달라지는 것 |
| DAgger | 로봇이 헤맨 상태마다 전문가에게 정답을 물어 데이터를 늘리는 방법 |
| on-policy | 학습 중인 정책이 직접 움직여 데이터를 모으는 방식 |
| 노이즈 주입 (noise injection) | 일부러 무작위 흔들림을 섞는 것 |
