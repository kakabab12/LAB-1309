# Leave No Observation Behind: Real-time Correction for VLA Action Chunks (A2C2)

- **연도**: 2025-09
- **링크**: https://arxiv.org/abs/2509.23224
- **읽은 날짜**: 2026-10-02
- **우리 구현**: `a2c2.py` (gen / train / Corrector), `switch_experiment.py --a2c2`

## 한 줄로

큰 VLA가 만든 동작 묶음은 그대로 쓰되, 작은 보정 네트워크가 **매 스텝 최신 사진을 보고** 그 스텝 동작에 작은 보정값을 더한다.

## 왜 필요한가

VLA는 한 번 사진을 보고 여러 스텝을 눈 감고 따라간다. 계산이 0.56초 걸리면 그 사이 생긴 어긋남을 고칠 기회가 없다. 그릇 테두리처럼 1~2cm가 성패를 가르는 곳에서 특히 문제다.

## 방법 (논문의 LIBERO 설정)

| 항목 | 내용 |
|---|---|
| 입력 | 정면·손목 사진(ResNet-18, 512차원), 로봇 상태, VLA가 낸 이번 동작, 이번 동작이 묶음 몇 번째인지(sin, cos), VLA 내부 특징, 지시문 특징 |
| 구조 | 6층 트랜스포머 + 3층 MLP, 32M |
| 학습 목표 | 시범 동작 − VLA 동작 (MSE) |
| 학습 데이터 | 시범 데이터 위에서 VLA를 돌려 동작을 미리 계산 |
| 속도 | 스텝당 4.7ms (SmolVLA 101ms) |

## 결과 (논문)

| 조건 | 아무것도 안 함 | A2C2 |
|---|---|---|
| LIBERO-Spatial, 실행 40스텝, 지연 10 | 67% | 84% |
| 지연 0, 실행 50스텝 | 72.2% | 81.6% |

[다른 논문의 같은 조건 비교](https://arxiv.org/abs/2605.08168)에서도 SmolVLA·LIBERO, 지연 4 이상에서 가장 덜 무너졌다(지연 20에서 약 58%, 아무것도 안 하면 10%).

## 우리 구현에서 바꾼 것

| 항목 | 논문 | 우리 | 이유 |
|---|---|---|---|
| 사진 처리 | ResNet-18 | ResNet-18, GroupNorm, 128×128, 처음부터 학습 | 사전학습 가중치를 받지 않는다. 배치 크기에 덜 민감하도록 GroupNorm |
| VLA 내부 특징 | 씀 | 안 씀 | 단순하게. 대신 묶음의 이번 동작과 그 뒤 3개를 같이 넣는다 |
| 지시문 | SmolVLA 문장 특징 | 지시문별 학습 벡터 (10개) | LIBERO-Goal 지시문 10개. 실물 단계에서 문장 특징으로 바꾼다 |
| 크기 | 32M | 14.6M | |
| 묶음 위치 k | 0~H | 0~40 | 실제로 쓰는 범위(11~31)를 포함 |
| VLA 동작 미리 계산 | 데이터 전체 | 16스텝마다, 일부 | 1080 Ti 계산 시간 |

학습 때 지연 흉내내기 모델(v6c)에 붙일 때는, 미리 계산할 때도 앞 11스텝 정답을 고정해 넣는다. 실제로 쓸 때와 같게 하기 위해서다.

## 실제 로봇에서

카메라 2대 + 로봇 상태 + 지시문만 쓴다. 1080 Ti에서 VLA 계산과 같이 돌려도 스텝당 수 ms라 50ms 제어 주기 안에 들어간다.
