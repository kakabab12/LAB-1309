## 📌 쉬운 말 요약

**한 줄로**: LIBERO 에서 95% 넘게 성공하는 VLA 들을 **카메라 각도, 조명, 로봇 시작 자세 같은 걸 조금씩 바꿔서** 다시 시험해 봤더니, **30% 아래로 무너지는 경우가 많았다**는 논문입니다.

**비유로**: 시험 문제를 달달 외운 학생은 문제의 숫자만 바꿔도 못 풉니다. 높은 점수가 "이해"가 아니라 "암기"였던 거죠. 이 논문은 VLA 에게 **숫자만 바꾼 시험지**를 풀게 한 셈입니다.

**우리 연구와의 관계**: 우리가 찾은 원인("전환 순간 팔 자세가 학습 때와 달라서 실패")을 **다른 연구팀도 독립적으로 확인**했다는 근거가 됩니다. 특히 **로봇 초기 상태**를 흔들면 크게 무너진다는 결과가 우리와 같습니다.

## 1. 배경 — 높은 점수, 믿어도 될까?

LIBERO 벤치마크에서 요즘 VLA 들은 95% 넘는 점수를 냅니다. 그런데 평가 조건이 **학습 때와 거의 똑같습니다.**

- 같은 카메라 위치
- 같은 조명
- 같은 로봇 시작 자세
- 비슷한 물체 배치

이러면 **진짜로 일반화한 건지, 학습 장면을 외운 건지** 구분할 수 없습니다.

## 2. 핵심 아이디어 — 한 번에 하나씩 흔들어 보기

**7가지 축**으로 조건을 조금씩 바꾼 평가 세트를 만듭니다.

| 축 | 바꾸는 것 |
|---|---|
| 물체 배치 | 물건 위치 |
| 카메라 시점 | 카메라 각도·위치 |
| **로봇 초기 상태** | **관절 각도를 무작위로 흔들어 시작 자세 변경** |
| 언어 지시 | 같은 뜻, 다른 표현 |
| 조명 | 밝기·방향 |
| 배경 | 테이블·벽 질감 |
| 센서 노이즈 | 카메라 이미지 노이즈 |

각 축을 **정도별로** 나눠서 총 **10,030개** 평가 태스크를 만들었습니다. 한 번에 한 축만 바꾸니까, 무엇에 약한지 정확히 알 수 있습니다.

## 3. 결과

- **카메라 시점**과 **로봇 초기 상태**에 특히 취약
- 적당한 정도의 변화만으로도 **95% → 30% 미만**
- 결론: 높은 점수의 상당 부분이 **암기(memorization)** 에 가깝다

## 4. 한계

- 교란을 에피소드 **시작할 때** 한 번 줌. 수행 **도중에** 자세가 틀어지는 상황은 다루지 않음
- 관절 각도를 흔드는 방식이라, 끝단이 **몇 cm, 몇 도** 벗어났는지와 직접 연결하기 어려움

## 5. 내 연구와의 관계

### 우리 결과와 같은 현상

| | LIBERO-Plus | 우리 |
|---|---|---|
| 무엇을 바꿨나 | 시작 시 관절 각도 무작위 | 끝단 위치 cm / 손목 회전 도 |
| 결과 | 95% → 30% 미만 | 위치 10cm: 87% → 43%, 손목 30도: 87% → 17% |
| 해석 | 암기에 가까움 | 학습 시작 자세의 궤적을 외운 상태에 가까움 |

### 참고해서 쓴 곳

- **자세 민감도 실험** 설계 근거 → [9/16 자세 민감도](../04_실습/05_libero/pose_sensitivity/README.md)
- "전환 실패 원인 = 자세 분포 이탈"이라는 해석의 외부 근거 → [9/16 일지](../03_일지/2026-09-16.md)

### 우리가 더한 것

1. **거리·각도 단위로 세분화** — "몇 cm 부터, 몇 도부터 무너지나"를 곡선으로 그림
2. **위치 vs 회전 분리** — 둘을 따로 재서 **실제 전환에서는 위치 이탈(12~27cm)이 지배적**임을 [ablation](../04_실습/05_libero/retreat_ablation/README.md)으로 확인
3. **더 현실적인 상황** — 사람이 교란을 넣는 게 아니라, **로봇이 태스크를 하다가 스스로 그 자세에 도달**한 상태(전환 순간)를 다룸

## 6. 용어

| 용어 | 뜻 |
|---|---|
| 강건성 (robustness) | 조건이 조금 바뀌어도 성능을 유지하는 능력 |
| 교란 (perturbation) | 일부러 조건을 흔드는 것 |
| 일반화 | 학습 때 못 본 상황에서도 잘하는 것 |
| 암기 (memorization) | 학습 장면을 외워서만 잘하는 것 |
