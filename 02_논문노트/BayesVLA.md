- **링크**: https://arxiv.org/html/2512.11218
- **읽은 날짜**: 2026-09-21 (본문 확인)

## 📌 쉬운 말 요약

**한 줄로**: VLA 가 언어를 무시하는 이유를 **데이터의 불균형**으로 보고, 정책을 **"볼 줄 아는 부분"과 "말을 듣는 부분"으로 쪼개서** 학습시키는 논문입니다.

**왜 무시하나 (이 논문의 진단)**:
학습 데이터에서 **지시문은 가짓수가 적은데 장면과 동작은 훨씬 다양합니다.**
그러면 모델은 **지시문을 보는 것보다 장면을 보는 것이 이득**이라 그쪽으로 기울어집니다
(지름길 학습, shortcut learning).

```
학습 데이터:
   지시문   "그릇을 접시에"  "그릇을 접시에"  "그릇을 접시에"  …   ← 가짓수가 적다
   장면     조금씩 다 다름                                      ← 가짓수가 많다
   동작     조금씩 다 다름                                      ← 가짓수가 많다

   → 장면만 봐도 동작을 꽤 맞출 수 있다  →  지시문을 안 보게 된다
```

---

## 1. 방법 — 정책을 둘로 쪼갠다

베이즈 규칙으로 정책을 두 조각으로 나눕니다.

```
π(동작 | 장면, 지시문)  ∝  π_prior(동작 | 장면)  ×  L(지시문 | 장면, 동작)
                            ↑ "무엇을 할 수 있나"    ↑ "그중 무엇이 이 지시에 맞나"
                            (보고 아는 부분)         (말을 듣는 부분)
```

| 조각 | 하는 일 | 학습 순서 |
|---|---|---|
| **Vision-Action Prior** `π_p(a\|v)` | 장면만 보고 **가능한 동작 여러 개**를 낸다 | 1단계 |
| **Language Likelihood** `L(ℓ\|v,a)` | 그중 **지시문에 맞는 것**을 고른다 | 2단계 |

**핵심 아이디어**: 언어를 "동작을 만드는 데" 쓰지 말고 **"고르는 데"** 쓰자.
그러면 지시문 가짓수가 적어도 그 역할이 사라지지 않습니다.

또 하나: **접촉 전(pre-contact)과 접촉 후(post-contact)를 나눠서** 다룹니다.
접촉 전은 잡을 자세를 예측하고, 접촉 후는 확산 모델로 궤적을 만듭니다.

## 2. ⭐ 우리 발견과의 관계 — 가깝지만 다르다

이 논문은 **접촉 전/후를 구조적으로 나눕니다.** 우리도 접촉(=쥐는 순간)을 경계로 봅니다.
그런데 **결정적으로 다른 점**이 있습니다.

| | BayesVLA | **우리** |
|---|---|---|
| 접촉 전/후를 나누나 | ✅ 모델 구조로 | ✅ 측정으로 |
| **쥔 뒤에 언어 영향력이 떨어지는 것을 쟀나** | ❌ **안 쟀다** | ✅ **0.719 → 0.284** |
| 왜 나누나 | 문제의 성질이 다르니까 (설계 직관) | **측정해 보니 거기서 귀가 닫혀서** |
| 해결 방식 | 새 구조로 **다시 학습** | 기존 정책을 **추론 때만** 바꿈 |

**중요**: 이 논문은 접촉 전/후를 나누는 것이 좋다고 **직관적으로** 설계했지만,
**"쥔 뒤에 언어 영향력이 실제로 얼마나 떨어지는지"는 측정하지 않았습니다.**
우리 CMI 측정이 그 직관에 **숫자를 붙여 준 셈**입니다.

## 3. 우리가 이 논문에서 가져올 것

**① 진단이 우리 것과 맞물린다.**
"지시문 가짓수가 적어 장면 지름길로 기운다" → LIBERO-Goal 은 **같은 장면에 10태스크**라
장면만으로는 태스크를 못 정합니다. 그런데도 쥐면 CMI 가 떨어진다는 것은,
지름길이 **장면 전체**가 아니라 **"쥐고 있다"는 상태 자체**일 수 있음을 시사합니다.
→ 쥐면 "들고 가서 놓는다"는 운동 패턴이 자동 실행되는 셈입니다.

**② 우리 [LoRA 실패](../04_실습/05_libero/lora_v2/README.md)를 설명한다.**
LoRA 1·2·3차가 전부 안 움직인 이유가 여기 있을 수 있습니다 —
우리는 **동작을 모방**시켰지, **언어의 역할**을 바꾸지 않았습니다.
데이터를 아무리 모아도 모델은 계속 장면 지름길을 씁니다.

**③ 우리 방법과 대비된다.**
BayesVLA 는 **구조를 바꿔 다시 학습**합니다 (비싸고, 새 모델이 됩니다).
우리 [지시문 증폭](../04_실습/05_libero/steerability/README.md)은 **추론 때만** 바꿉니다
(공짜, 기존 모델 그대로). 같은 진단에 대한 두 가지 처방입니다.

## 4. 한계 (이 논문의)

- **접촉 후에 언어 영향력이 떨어진다는 것을 직접 재지 않았습니다** — 우리가 잰 것
- 구조를 바꾸므로 **기존 사전학습 모델을 그대로 쓸 수 없습니다**
- 2단계 학습이라 비용이 큽니다

## 5. 한 줄 정리

**진단은 우리와 같은 방향(언어가 밀려난다)이지만,
"쥔 뒤에 얼마나 밀려나는지"는 재지 않았고, 처방도 다릅니다(재학습 vs 추론 개입).**
