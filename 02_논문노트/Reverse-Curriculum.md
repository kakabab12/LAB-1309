# Reverse Curriculum Generation for Reinforcement Learning

- **저자 / 연도 / 학회**: Carlos Florensa, David Held, Markus Wulfmeier, Michael Zhang, Pieter Abbeel / 2017 / CoRL 2017
- **링크**: https://arxiv.org/abs/1707.05300
- **읽은 날짜**: 2026-09-17 (초록 기준)

## 1. 문제

목표에서 먼 곳에서 출발하면 성공을 한 번도 못 해서 배울 신호가 없다.

## 2. 핵심 아이디어

**목표 근처에서 시작하는 법부터** 배우고, 시작 위치를 조금씩 멀리 넓혀간다. 너무 쉽지도 어렵지도 않은 시작점만 고른다.

## 3. 방법

- 이미 성공하는 시작점에서 무작위로 조금 움직여 새 시작점 후보를 만듦
- 성공률이 정해진 구간(예: 10~90%) 안에 드는 후보만 다음 학습에 사용

## 6. 내 연구와의 관계

- **LoRA 1차 실패와 같은 문제**: 1→5, 2→5 전환은 성공률이 0~17% 라 배울 데이터가 0개였다
- **가져온 것**: 자세 교란 범위를 한 번에 넓히지 않고 **단계적으로** 넓히는 커리큘럼. 2차는 8~20cm, 이후 성공률이 오르면 더 넓힘. "성공률 구간 필터"도 교란 크기 선택에 적용 예정
- 우리는 "목표에서 먼 시작점" 대신 **"초기 자세에서 먼 시작점"** 을 점점 넓힌다는 점이 다름
