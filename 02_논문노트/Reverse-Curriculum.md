## 📌 쉬운 말 요약

**한 줄로**: 어려운 목표를 배울 때, **목표 바로 앞에서 시작하는 것부터** 연습하고 성공하면 시작점을 **조금씩 뒤로** 물리는 방법입니다.

**비유로**: 퍼즐 마지막 한 조각만 끼우는 연습부터 하고, 그게 되면 두 조각, 세 조각 남긴 상태에서 연습합니다. 처음부터 1000조각을 맞추라고 하면 한 번도 성공을 못 해서 뭘 잘하고 있는지조차 모릅니다. 또는 농구 슛을 골대 바로 앞에서 연습하고, 들어가기 시작하면 한 걸음씩 뒤로 가는 것과 같습니다.

**핵심 규칙**: **너무 쉽지도, 너무 어렵지도 않은** 시작점만 골라서 연습합니다.

**우리 연구와의 관계**: LoRA 1차가 실패한 이유가 바로 이 논문이 푸는 문제였습니다. 1→5 전환은 성공률이 0%라 **배울 거리가 하나도 안 생겼습니다.** 그래서 팔 위치를 한 번에 크게 틀지 않고 **조금씩 넓혀가는** 방식을 가져왔습니다.

## 1. 배경 — 성공을 한 번도 못 하면 배울 수 없다

강화학습은 "성공하면 보상"을 받아 배웁니다. 그런데 목표가 어려우면

```
시작 ──────────────────────────────────────── 목표
       무작위로 움직여서 여기까지 올 확률 ≈ 0
```

**성공을 한 번도 못 해서 보상이 0만 나오고**, 뭘 잘했는지 알 방법이 없습니다. 이걸 **희소 보상(sparse reward)** 문제라고 합니다. 보통은 사람이 "목표에 가까워지면 조금씩 점수" 같은 보상을 설계해 주는데, 이게 어렵고 잘못 설계하면 엉뚱한 행동을 배웁니다.

## 2. 핵심 아이디어 — 거꾸로 배우기

목표 상태는 **최소 하나는 알고 있다**고 가정합니다 (예: 열쇠가 자물쇠에 꽂힌 상태). 그러면

1. **목표 바로 옆**에서 시작 → 거의 매번 성공 → 배움
2. 시작점을 **조금 더 멀리** → 가끔 성공 → 배움
3. 계속 멀리 → 결국 원래 시작점에서도 성공

```
단계 1:                                  ●→◎
단계 2:                            ●───────→◎
단계 3:                 ●──────────────────→◎
최종:   ●──────────────────────────────────→◎
```

## 3. 작동 원리 — 시작점을 어떻게 고르나

### 3-1. 새 시작점 만들기

이미 괜찮은 시작점에서 **무작위로 조금씩 움직여서**(random walk) 주변 상태들을 새 후보로 만듭니다. 이렇게 하면 물리적으로 가능한 상태만 후보가 됩니다.

### 3-2. "딱 좋은 난이도"만 남기기 ⭐

각 후보에서 몇 번 시도해서 **성공률**을 잽니다.

| 성공률 | 판단 |
|---|---|
| 90% 초과 | 너무 쉬움 → 버림 (이미 할 줄 앎) |
| **10~90%** | **딱 좋음 → 학습에 사용** |
| 10% 미만 | 너무 어려움 → 버림 (배울 게 없음) |

이 구간(논문에서는 최소·최대 보상 기준)이 핵심입니다. **"할락 말락 하는 곳"에서 가장 많이 배우기** 때문입니다.

### 3-3. 반복

좋은 시작점으로 학습 → 정책이 좋아짐 → 성공률이 바뀜 → 다시 딱 좋은 곳을 고름 → 시작점이 자연스럽게 목표에서 멀어짐.

## 4. 실험 (논문)

- 열쇠를 자물쇠에 꽂기, 고리를 막대에 끼우기, 미로 찾기 같은 목표 지향 과제
- **사람이 보상을 설계하지 않고**, 목표 상태 하나만 주고도 학습 성공

## 5. 한계

- 원하는 시작점에 **로봇을 가져다 놓을 수 있어야** 함 (시뮬레이션에서는 쉽고, 실물에서는 어려움)
- 성공률을 재기 위해 **시도를 많이** 해야 함

## 6. 내 연구와의 관계

### LoRA 1차 실패를 그대로 설명한다

| 전환 쌍 | 원래 성공률 | 모인 성공 데이터 | 결과 |
|---|---|---|---|
| 8→7, 4→7 | 30~70% (딱 좋은 난이도) | 11~17개 | 잡은 직후 50→70%, 30→60% ✅ |
| 1→5, 2→5 | **0~17% (너무 어려움)** | **0개** | 0% ❌ |

논문 표현대로 **"너무 어려운 곳에서는 배울 게 없다"** 가 그대로 나왔습니다.

### 참고해서 쓴 곳

- **LoRA 2차 교란 범위** (`run_pipeline_v2.sh`)
  - 1차 최대 8cm → 2차 **8~20cm**. 실제 전환 이탈(12~27cm)을 향해 단계적으로 넓힘
- **우리 방식으로 바꾼 점**: 논문은 "목표에서 먼 시작점"으로 넓히지만, 우리는 **"초기 자세에서 먼 시작점"** 으로 넓힘. 목표는 태스크 성공, 멀어지는 방향은 팔 위치

### 앞으로 쓸 계획 — 3차

1. 교란 크기를 여러 단계(4, 8, 12, 16, 20, 24cm)로 나눠 **단계별 성공률 측정**
2. **성공률 10~90% 인 단계만** 데이터 수집
3. 학습 → 성공률이 오르면 다음 단계가 "딱 좋은" 구간으로 들어옴 → 반복
4. 최종적으로 **실제 전환 이탈 27cm** 에서도 성공하게

## 7. 용어

| 용어 | 뜻 |
|---|---|
| 커리큘럼 학습 | 쉬운 것부터 어려운 순서로 배우기 |
| 희소 보상 (sparse reward) | 성공했을 때만 보상이 있고 중간 점수가 없는 것 |
| random walk | 무작위로 조금씩 움직이기 |
| 목표 지향 과제 (goal-oriented) | 특정 목표 상태에 도달하면 성공인 과제 |
