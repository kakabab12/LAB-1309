## 📌 쉬운 말 요약

**한 줄로**: 이미 학습된 로봇 정책이 동작 후보를 여러 개 내놓으면, **따로 학습한 "가치 함수"가 점수를 매겨 가장 좋은 걸 고르는** 방법입니다. 정책 가중치는 **건드리지도, 볼 필요도 없습니다.**

**비유로**: 여러 식당 요리사(서로 다른 정책)가 각자 요리를 여러 접시 만들면, **한 명의 음식 평론가(가치 함수)** 가 맛을 보고 제일 좋은 접시를 손님에게 냅니다. 평론가 한 명으로 **어느 식당이든** 요리 수준을 올릴 수 있습니다.

**우리 연구와의 관계**: 우리 `bon` 전략이 이 구조입니다 — 후보 N개를 뽑아 점수로 고르기. V-GPS 는 점수를 **학습한 가치 함수**로 매기고, 우리는 1080 Ti 에 맞게 **성공 궤적과의 거리**로 매깁니다. [Q-Planning](Q-Planning.md) 의 선배 격 연구입니다.

## 1. 문제

범용 로봇 정책(Octo, OpenVLA 등)은 다양한 데이터로 학습했지만, 데이터 품질이 들쭉날쭉해서 **실행하면 미숙한 동작**을 자주 냅니다. 성능을 올리려면 보통 파인튜닝이 필요한데

- 비용이 크고
- 가중치에 접근 못 하는 모델도 있고
- 다른 정책마다 따로 해야 합니다

## 2. 핵심 아이디어

**"정책은 후보를 내고, 가치 함수가 고른다."**

```
현재 이미지 + 지시
      │
      ▼
정책에서 동작 후보 K개 샘플
      │
      ▼
가치 함수 Q(이미지, 지시, 동작) 로 점수
      │
      ▼
가장 높은 동작 실행
```

## 3. 작동 원리

### 3-1. 가치 함수 학습 — offline RL

- 이미 있는 로봇 데이터셋(성공·실패 섞임)으로 학습
- **Cal-QL** 이라는 오프라인 강화학습 방법 사용 — 데이터에 없는 동작을 과대평가하지 않도록 보수적으로 학습
- 언어 지시를 입력으로 받아 **여러 태스크를 하나의 가치 함수**로

### 3-2. 실행할 때

- 정책에서 후보를 여러 개 뽑기만 하면 되므로 **정책 내부를 몰라도 됨** (black-box)
- 같은 가치 함수를 **다른 정책에 그대로** 붙일 수 있음

## 4. 실험

- **5개의 서로 다른 범용 정책**(구조·학습 데이터가 다 다름)에 같은 가치 함수를 붙여 모두 성능 향상
- 여러 로봇 플랫폼, 총 12개 태스크에서 일관된 향상

## 5. 한계

- 정책이 **좋은 후보를 하나도 못 내면** 골라도 소용없음
- 가치 함수 학습에 성공·실패가 섞인 데이터가 필요

## 6. 내 연구와의 관계

| | V-GPS | 우리 `bon` |
|---|---|---|
| 후보 뽑기 | 정책에서 K개 | SmolVLA 에서 N개 (노이즈만 다르게) |
| 점수 | **학습한 가치 함수** (Cal-QL) | **성공 궤적과의 거리** (학습 없음) |
| 정책 가중치 | 안 건드림 | 안 건드림 |
| 망각 | 없음 | 없음 |

### 참고해서 쓴 곳

- `switch_experiment.py --strategy bon` 의 구조 — "정책을 얼리고 후보 중 고르기"
- [LoRA 1차 망각](../04_실습/05_libero/lora_v1/README.md) 을 피하는 방향의 근거 — 가중치를 안 바꾸면 원래 능력을 잃지 않음

### 앞으로

`bon` 에서 거리 점수가 효과를 보이면, 우리가 모은 **1,700+ 에피소드(성공·실패 기록 있음)** 로 V-GPS 처럼 **작은 가치 함수를 학습**해서 점수를 바꿀 수 있음. SmolVLA 가 이미 계산한 이미지·지시 특징을 재사용하면 1080 Ti 에서도 가능.

## 7. 용어

| 용어 | 뜻 |
|---|---|
| 가치 함수 (value function) | 상태(와 동작)의 "앞으로 얼마나 좋을지" 점수 |
| offline RL | 새로 실험하지 않고 이미 모은 데이터로만 강화학습 |
| Cal-QL | 데이터에 없는 동작을 과대평가하지 않게 보정한 오프라인 Q 학습 |
| re-ranking | 후보들의 순위를 다시 매기기 |
| black-box | 내부 구조나 가중치를 몰라도 입력·출력만으로 쓰는 것 |
