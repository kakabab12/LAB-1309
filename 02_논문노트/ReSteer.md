## 📌 쉬운 말 요약

**한 줄로**: 로봇 정책이 **말을 듣는 정도(steerability, 조종 가능성)** 를 숫자로 재는 방법을 만들고, 말을 안 듣는 상태를 골라내 그 지점의 데이터를 만들어 다시 학습시키는 논문입니다.

**비유로**: 일에 푹 빠진 사람에게 옆에서 "그거 말고 이거 해줘" 하면 못 듣는 순간이 있습니다. ReSteer 는 먼저 **"어떤 순간에 말이 안 들리는지"를 측정**하고, 그 순간들만 골라 연습시킵니다.

**우리 연구와의 관계**: [SwitchVLA](SwitchVLA.md) 다음으로 가까운 논문입니다. **같은 LIBERO-Goal**, 같은 "실행 중 지시 변경" 문제입니다. 결정적으로, 우리가 9/17 에 실패했던 "왜 전환이 안 되는가"라는 질문에 **쓸 수 있는 측정 도구(CMI)** 를 줍니다.

## 1. 핵심 개념 — 조종 가능성을 어떻게 재나

### 1-1. 조건부 상호정보량 (CMI)

어떤 상태 `s` 에서, **지시문을 알면 동작의 불확실성이 얼마나 줄어드는가**를 잽니다.

```
I(A ; L | S=s) = H(A | S=s) − H(A | S=s, L)
                 ↑ 지시를 모를 때      ↑ 지시를 알 때
                 동작이 흩어진 정도    동작이 흩어진 정도
```

- **CMI 가 크다** = 지시에 따라 동작이 확 달라진다 → 말이 통하는 상태
- **CMI 가 0 에 가깝다** = 지시가 뭐든 같은 동작을 한다 → **"지시를 못 보는(instruction-blind)" 상태**

**쉽게 말하면**: 같은 자리에서 지시문만 10가지로 바꿔 동작을 뽑아봅니다. 뽑힌 동작들이 지시별로 뚜렷이 다르면 CMI 가 크고, 다 비슷하면 CMI 가 0 입니다.

### 1-2. SCR (Steerability Coverage Ratio)

실제로 전환에 성공하는 상태의 비율입니다. 논문은 **CMI 가 SCR 의 필요조건**임을 증명합니다.

```
SCR(π) ≤ Pr[ I(s) ≥ τ ]
```

**읽는 법**: "지시가 동작에 영향을 주지 못하는 상태에서는, 애초에 전환이 성공할 수 없다." 그래서 **굴려보지 않고 CMI 만 재도** 전환 성능의 상한을 알 수 있습니다. 수천 번 굴리지 않아도 된다는 게 실용적인 장점입니다.

### 1-3. 왜 지시를 못 보게 되나

논문의 진단: **학습 데이터에서 태스크별 궤적 분포가 서로 겹치지 않기 때문**입니다.

```
태스크 A 궤적:  ●━━━●━━━●
태스크 B 궤적:        ○━━━○━━━○
                 ↑
        A 궤적 위의 이 상태는 B 데이터에 없음
        → 이 자리에서 B 지시를 줘도 모델은 B 를 모름
```

물체를 쥐고 A 를 수행 중인 상태는 **B 의 학습 데이터에 존재하지 않습니다.** 그래서 B 지시를 줘도 동작이 안 바뀝니다. 이게 "태스크 집착(task commitment)"의 정체입니다.

## 2. 방법 — 세 부분

| 부분 | 하는 일 |
|---|---|
| **조종 가능성 추정기** | CMI 로 "말이 안 통하는 상태"를 굴려보지 않고 찾아냄 |
| **SteerGen (데이터 생성기)** | 그 상태에서 시작하는 전환 동작을 합성 |
| **SRBC (자기 개선 학습)** | 합성 데이터로 성공한 것만 모아 반복 재학습 |

### 2-1. SteerGen — 어떻게 전환 동작을 만드나

1. **단계 분할**: 상태를 `잡기 전 / 옮기는 중 / 놓기` 로 자동 분류 (끝단 거리, 그리퍼 열림, 물체 높이 같은 운동학 신호로)
2. **목표 상태 고르기**: 지금 상태 `s` 와 **같은 단계**에 있는, **다른 태스크 시연의 상태** `s'` 를 최단 경로 비용으로 고름
3. **궤적 합성**: `s → s'` 를 **단순 선형 보간**으로 잇고, 그 뒤부터는 목표 지시문으로 정책이 직접 굴러감

즉 "지금 상태"와 "B 데이터에 있는 상태"를 **다리로 이어주는** 방식입니다. 보간으로 B 분포 안에 들어가게 만든 뒤, 나머지는 원래 정책이 합니다.

### 2-2. SRBC — 자기 개선 반복

```
① 전환 rollout 수집 → ② 성공한 것만 남김 → ③ 데이터에 합쳐 다시 학습 → ①로
```

손실은 평범한 behavior cloning 입니다. 특별한 건 **어디서 데이터를 모으는지**(= CMI 가 낮은 상태들) 뿐입니다.

## 3. 실험

- 시뮬레이션: **LIBERO-Goal** (10 태스크, 한 장면) — 우리와 같음. **rollout 18,000회**
- 실물: DROID 플랫폼, 주방 태스크 4개

## 4. 한계

**논문이 인정한 것**
- 같은 장면에서만 분석. 장면이 바뀌는 상황은 미검증
- 실물에서는 SRBC(재학습)를 돌리지 못함 (비용)
- 다양한 환경으로의 확장성 미검증

**내가 보기에**
- **초기 자세 복귀 이야기가 없음** — 물체를 쥔 상태에서 어떻게 처리하는지(내려놓기)도 명시적으로 다루지 않음. 단계 매칭으로 "옮기는 중 → 다른 태스크의 옮기는 중"으로 이으므로, **물체를 계속 쥔 채 다른 태스크로 갈 수도** 있음
- **자연스러움 지표가 없음** — 선형 보간으로 만든 동작을 배우면 사람스럽지 않을 수 있음
- **추론 지연 논의 없음**
- **재개(A 로 돌아오기) 없음**

## 5. 내 연구와의 관계

### 5-1. 이 논문이 우리 막힌 곳을 풀어준다

우리는 9/17 에 "전환 실패의 원인"을 찾다가 막혔습니다.

| 우리가 시험한 설명 | 결과 |
|---|---|
| 전환 시점의 팔 위치가 멀어서? | **아님** (r = +0.14) |
| 후보 동작 중 좋은 걸 못 골라서? | **아님** (판정기 Q−V = 0.0003) |
| 장면(태스크 쌍)이 어려워서? | 16~31% 만 설명 |

ReSteer 의 설명은 **"그 상태에서는 지시문 자체가 동작에 영향을 못 준다"** 입니다. 우리 측정과 모순되지 않고, **오히려 판정기 결과와 정확히 맞습니다**: 지시가 동작을 못 가르면, 어떤 후보를 골라도 결과가 같습니다 (= Q 가 V 를 못 넘음).

### 5-2. 참고해서 쓸 곳

- **`steerability.py` (새로 만듦)**: 전환 시점의 CMI 를 측정. 같은 상태에서 지시문 10개 × 후보 8개를 뽑아 **지시 사이의 차이 ÷ 같은 지시 안의 흔들림** 을 계산. 굴리지 않으니 싸다
  - 측정 지점: ① 에피소드 시작 ② 잡은 직후 ③ 들고 이동 중 → **"쥐면 지시가 안 들린다"는 가설을 직접 검증**
- **SmolVLA 의 조종 가능성 숫자**를 위 표에 추가 (아직 아무도 안 쟀음)
- SteerGen 의 **단계 매칭** 발상 → 우리 rollback 이 "잡기 전 단계로 되돌리는 것"과 같은 원리임을 설명할 수 있음

### 5-3. 차별점

| | ReSteer | 우리 |
|---|---|---|
| 전환 처리 | 다른 태스크 시연 상태로 **선형 보간해서 잇기** | ⛔ 초기 자세 복귀 금지 + **자연스러움 지표로 검증** |
| 물체를 쥔 상태 | 명시적으로 다루지 않음 | **핵심 상황** (잡은 직후 / 들고 이동 중) |
| 중단한 A | 없음 | **B 후 A 재개** |
| 추론 지연 | 없음 | **실측 0.56초** 반영 |
| 정책 | π0.5 (3B급), OpenVLA-OFT, MolmoACT | **SmolVLA 0.45B, LoRA, 1080 Ti** |
| 학습 | 반복 BC (rollout 18,000회) | 1080 Ti 로는 불가능한 규모 → **더 싼 방법을 찾아야 함** |

**우리에게 주는 경고**: ReSteer 는 18,000 rollout 을 썼습니다. 우리 1080 Ti 로는 1 rollout 이 약 10초라 18,000회는 **50시간**입니다. 같은 방식을 그대로 따라할 수 없으니, **측정(CMI)은 가져오고 개선 방법은 더 싼 것을 찾는** 전략이 맞습니다.

## 6. 용어

| 용어 | 뜻 |
|---|---|
| steerability (조종 가능성) | 실행 중에 새 지시로 방향을 바꿀 수 있는 정도 |
| CMI (조건부 상호정보량) | 지시를 알 때 동작 불확실성이 줄어드는 양 |
| instruction-blind | 지시가 뭐든 같은 동작을 하는 상태 |
| task commitment (태스크 집착) | 하던 태스크를 계속하려는 성향 |
| SCR | 전환에 성공할 수 있는 상태의 비율 |
| behavior cloning (BC) | 시연의 관측→동작을 그대로 흉내 내도록 학습 |
