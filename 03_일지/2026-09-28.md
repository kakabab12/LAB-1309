## 1. ❌ LoRA 4차 — 학습한 태스크마저 망가뜨렸다

추석 연휴 동안 돈 LoRA 4차(단계적 확장, 교란된 자세에서 집기)의 결과입니다.

| T8 그릇→접시 | 0cm | 12cm | 20cm | 27cm |
|---|---|---|---|---|
| 원래 정책 | **90%** | 30% | 22% | 11% |
| 4차 1단계 | 40% | 10% | 0% | 0% |
| 4차 2단계 | **10%** | 0% | 0% | 0% |

**학습시킨 바로 그 태스크가, 교란 없는 상태에서도 90% → 10% 로 무너졌습니다.**
교란된 자세의 집기도 전부 나빠졌고, 전환도 그대로 0% 입니다.

### 왜 실패했나

| | 2차 | 4차 |
|---|---|---|
| 에피소드 | 442개 | **158개** |
| 태스크 | 10개 전부 | **3개에 몰림** |
| 검증 손실 | 0.05 대, 내려감 | **0.13 대, 거의 안 내려감** (0.1295 → 0.1286) |

그리고 더 근본적인 이유가 있습니다.

## 2. ⭐ 네 번의 LoRA 가 같은 이유로 실패했다

| 차수 | 무엇을 따라하게 했나 | 결과 |
|---|---|---|
| 1차 | 정책의 성공 궤적 | 32% → 32%, 망각 |
| 2차 | 임의 교란에서 정책의 성공 | 32% → 31% |
| 3차 | 전환 자세에서 정책의 성공 + hindsight | 32% → 30% |
| 4차 | 교란된 자세에서 **다시 뽑아** 모은 정책의 성공 | **학습한 태스크가 90% → 10%** |

**네 번 모두 정책 자신의 성공을 따라하게 했습니다** (self-imitation).

그런데 정책은 교란된 자세에서 **거의 성공하지 못합니다.** 따라할 좋은 예가 없습니다.
다시 뽑기로 억지로 모은 성공은 **운 좋은 노이즈 덕**이라, 따라하면 오히려 망가집니다.

> **정책이 못하는 것은 정책의 데이터로 가르칠 수 없습니다. 더 나은 선생이 필요합니다.**

📚 로봇 학습에서 교란된 상태 문제(covariate shift)는 **전문가가 학습자가 실제로 가는 상태에서
시범을 보이는** 방식으로 풉니다 — DAgger (Ross et al., 2011), DART (Laskey et al., 2017).

## 3. ✅ 스크립트 전문가를 만들었다 — 해낸다

시뮬레이터는 **물체의 정확한 위치를 압니다.** 그걸로 어디서 시작하든 물체로 가서 집는 스크립트를 만들었습니다.

### 집는 자세는 추측하지 않았다

원래 정책이 **성공할 때** 그릇을 어떻게 집는지 쟀습니다 (8회):

| | 그릇 중심 기준 손 위치 |
|---|---|
| 평균 | **[0.6, 4.0, 4.6] cm** (테두리) |
| 퍼짐 | [0.3, 0.1, 1.0] cm — **매우 일정** |

놓는 위치도 같은 방식으로 쟀습니다 (퍼짐 1~2cm):

| 태스크 | 놓는 위치 (cm) |
|---|---|
| T1 스토브 | [−22.8, 20.4, 93.3] |
| T4 찬장 위 | [−0.3, −22.2, 113.0] |
| T8 접시 | [6.1, −2.9, 91.1] |

### 결과

| 상황 | 원래 정책 | **스크립트 전문가** |
|---|---|---|
| 정상 시작 (T8) | 90% | **100%** (6/6) |
| **27cm 교란** (T8) | 11% | **80%** (8/10) |
| 전환 후 방향 틀기 (A8→B1·B4, A1→B8) | 90~100% | **100%** (15/15) |

### 만들면서 잡은 버그 세 개 — 전부 **재서** 찾았다

| 증상 | 원인 | 어떻게 찾았나 |
|---|---|---|
| 기울어진 그릇에서 **0/10** | 그릇은 바로 서 있어도 **z축으로 90도 돌아가 있다** — 절대 방향으로 돌리면 어긋난다 | 에피소드 시작 때 그릇 방향을 찍어 봄 |
| 테두리 다른 점을 집으면 헛잡음 | 집는 위치만 돌리고 **그리퍼 방향은 그대로** 뒀다 | 평행 그리퍼는 벽을 가로질러 쥐어야 함 |
| 방향 틀기에서 A1→B8 이 100% → **0%** | 쥐었는지 판정 기준(2.5cm)이 너무 빡빡 — 실제로 쥐고 있는데(2.2~2.4cm 따라옴) 놓친 것으로 보고 **멀쩡한 그릇을 놓았다** | 넘겨받는 순간 손·그릇 높이를 찍어 봄 |

그리고 **넘겨받는 순간의 손−그릇 관계는 [−2.6, 4.8, 1.5]cm** 로, 들어 올린 뒤 잰 집기 오프셋과
**3cm 씩 달랐습니다.** 가정한 값 대신 **그 순간 실제로 잰 값**을 쓰도록 바꿨습니다.

## 4. ⚠️ 정정 — "무조건 놓는 반사"는 틀렸다

9/23 에 **"지시가 바뀌면 일단 놓는다가 학습된 반사"** 라고 썼습니다. **과한 일반화였습니다.**

B 를 넓혀 보니 정책은 **내용에 따라** 판단합니다 (전환 뒤 3초 안에 그리퍼가 열리는지):

| B 가 요구하는 것 | 3초 안에 놓음 | B 성공 |
|---|---|---|
| **같은 그릇을 다른 곳에** (B1·B4·B8) | **0~1/10 — 계속 쥔다** | **90~100%** |
| 서랍 열기 (B0) | 7/10 — 놓는다 | 60% |
| 스토브 켜기 (B7) | 1/10 | 50% |
| 서랍 열고 그릇 넣기 (B3) | 4/10 | 0% |
| 접시 밀기 (B5) | 10/10 — 놓는다 | 0% |
| **다른 물체** (와인병, B9) | **0/10 — 안 놓는다** | 0% |

- 그릇이 필요하면 **쥐고**, 손이 필요하면 **놓습니다.** 상황을 보고 있습니다
- 오히려 B9 에서는 **그릇을 안 놓고** 와인병 일을 하려다 실패합니다
- 9/23 의 "10/10 놓음"은 **B 구간 전체**(300스텝)에서 센 값이라 목적지에 도착해 놓는 것까지 포함됐습니다

> **정정된 그림**: 정책이 실패하는 것은 **"들고 있던 것을 내려놓고 다른 조작을 해야 할 때"** 뿐입니다.
> **목적지만 바뀌는 전환은 원래 정책이 이미 90~100% 해냅니다** (새로 잰 6쌍 중 5쌍 확인).

## 4-2. ⭐⭐ 연구의 두 번째 목표(A 재개)가 **처음으로 제대로 된다**

목적지만 바뀌는 6쌍에서, B 를 해낸 뒤 **원래 하던 일(A)로 돌아가는지**도 쟀습니다.

| 쌍 | B 성공 | **A 재개 (진짜)** |
|---|---|---|
| A1(스토브) → B4(찬장 위) | 100% | **80%** |
| A4(찬장 위) → B1(스토브) | 100% | **70%** |
| A8(접시) → B1(스토브) | 90% | 0% |
| A8(접시) → B4(찬장 위) | 100% | 0% |
| A1(스토브) → B8(접시) | 90% | 0% |
| A4(찬장 위) → B8(접시) | 100% | 0% |

**스토브 ↔ 찬장 사이는 양방향으로 "하던 일 → 끼어든 일 → 원래 일로 복귀" 가 70~80% 됩니다.**
우연(A2 가 0스텝)은 0% 라 **전부 진짜 재개**입니다.

지금까지 모든 전략·모든 쌍에서 진짜 재개는 **0.6%** 였습니다 (9/23 감사).
원래 정책이 이 연구의 **전체 사이클**(중단 → 다른 일 → 복귀)을 해내는 것을 처음 확인했습니다.

### 접시가 끼면 0% — 왜

| | 결과 |
|---|---|
| 그릇이 **접시 위**에서 재개 시작 (A1→B8, A4→B8) | 0% — 접시 위 그릇을 못 집는다 |
| 재개 목적지가 **접시** (A8→B1, A8→B4) | 0% — 다른 곳에서 접시로 못 가져간다 |

접시 위에 놓인 그릇은 **접시에 파묻힌 모양**이라 집는 자세가 달라지는 것으로 보입니다 (추측, 미확인).

### ⚠️ 지표에 대해

이 쌍들은 **"A 와 B 둘 다 성공"이 정의상 불가능**합니다 — 같은 그릇을 스토브 위와
찬장 위에 동시에 둘 수 없습니다. A 를 재개하면 B 는 풀립니다.
그래서 의미 있는 지표는 **"B 를 해낸 뒤 A 로 돌아갔는가"** 입니다.
(지금까지 쓴 `both_success` 는 **서로 다른 물체**를 다루는 쌍에서만 의미가 있습니다.)

## 5. 연휴 동안 돈 나머지 두 실험 — 둘 다 효과 없음

| 개입 | 물체 B (A8→B3, A4→B9) | 서랍 열기 (A8→B0) |
|---|---|---|
| 기준 | 0% | 60% |
| 덜 끊기 (20스텝마다 재추론) | 0% | 70% |
| 덜 끊기 (50스텝마다) | 0% | 50% |
| **손목 보정** k=0.15 | 0% | **0%** ← 망가뜨림 |

- **손목 정렬은 원인이 아니었습니다.** 보정해도 물체 B 는 그대로 0%
- 손목 보정은 그리퍼 유지처럼 **서랍 열기를 망가뜨렸습니다** (60% → 0%)
- 덜 끊기는 **동작을 부드럽게** 합니다(jerk 7.1 vs 기준 8~9) — 성공률 차이는 표본 잡음 수준

**물체를 다루는 B 는 지금까지 시도한 어떤 개입에도 0% 입니다**
(지시문 증폭, 토큰 반복, 그리퍼 유지, 덜 끊기, 손목 보정, LoRA 4번).

## 6. ⏳ 진행 중 — 내려놓기를 도와주면 정책이 B 를 할 수 있나

실패가 "내려놓고 다른 조작을 할 때"라면: **전문가가 깔끔하게 내려놓아 주면, 그 다음은 정책이 할 수 있을까?**

| 쌍 | 원래 (정책이 스스로 놓음) | 전문가가 바로 세워 놓아 줌 |
|---|---|---|
| A8→B5 접시 밀기 | 0% | **20%** (2/10, 바로 섬 10/10) |
| A8→B9 와인병 | 0% | ⏳ |
| A8→B7 스토브 | 50% | ⏳ |

조금 오르지만 부족해 보입니다. 정책은 **교란된 자세에서** 무너지므로,

그 자세는 **초기 자세가 아니라 작업 대상 근처**라 제약에 맞습니다.
