> **한 줄 요약**: 모델을 10.8M 으로 키우자 1600 스텝부터 검증 loss 가 올라가는 과적합이 선명하게 나왔다. 조기 종료가 필요하다.

## 이 일지에서 새로 나오는 말

| 말 | 뜻 |
|---|---|
| **과적합** | 학습 데이터만 잘 맞추고 안 본 데이터에서는 나빠지는 것 |
| **조기 종료 (early stopping)** | 검증 loss 가 더 안 좋아지면 멈추고 가장 좋았던 모델을 씀 |
| **일반화 격차** | 학습 loss 와 검증 loss 의 차이. 커질수록 외우는 중 |
| **weight decay** | 가중치가 커지지 않게 억제해 과적합을 줄이는 기법 |

## 알게 된 것

### 1. 1600 스텝부터 외우기 시작

![학습 곡선](../../04_실습/02_transformer/results/shakespeare_big_loss.png)

| 스텝 | 학습 loss | 검증 loss | 차이 |
|---|---|---|---|
| 1000 | 1.25 | 1.51 | 0.27 |
| **1600** | 1.11 | **1.48 ← 최저** | 0.37 |
| 3000 | 0.80 | 1.62 | 0.82 |
| 5000 | 0.58 | 1.79 | **1.21** |

- 작은 모델(1.83M)은 차이 0.08 로 과적합이 거의 없었는데, **6배 키우니** 같은 1MB 데이터에서 외울 여유가 생김
- 5000 스텝 모델은 최적 시점보다 검증 loss 가 0.31 나쁨

### 2. 생성은 꽤 그럴듯

- `ROMEO:` 로 시작하면 MERCUTIO·BENVOLIO 같은 **같은 작품 인물**, 대사 형식, 고어체(`thou speak'st`)까지 따라 함. 뜻은 안 통함
- 온도 0.5: 반듯·반복적 / 1.0: 다양·엉킴 / top-k 20: 중간

### 3. 연구와의 연결

- **"loss 가 내려간다 ≠ 잘 배웠다"** — 검증 loss 를 같이 봐야 함
- 반대 사례가 연구 쪽에 있었음: LoRA 1차는 검증 loss 는 멀쩡했는데 **로봇 성공률은 안 올랐다**. 로봇에서는 loss 와 별도로 **태스크 성공률**을 재야 함
