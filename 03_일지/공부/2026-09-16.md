# 2026-09-16 [공부] 작은 Transformer 직접 구현 (Colab)

> 한 줄 요약: 문자 단위 Transformer를 직접 만들어 문장을 생성했는데, 알고 보니 문장 하나를 외운 것이었다. 데이터를 tiny shakespeare로 바꾸자 검증 loss가 함께 내려가며 제대로 배우기 시작했다.

## 새로 나온 말

| 말 | 뜻 |
|---|---|
| causal mask | 뒤에 올 글자를 미리 보지 못하게 가리는 마스크 (아래 삼각형 행렬) |
| pre-LN | 어텐션과 MLP 앞에 LayerNorm을 두는 구조. 학습이 안정적이다 |
| 위치 임베딩 | 어텐션은 순서를 모르므로, 몇 번째 글자인지 따로 더해 주는 벡터 |
| 자기회귀 생성 | 만든 글자를 다시 입력에 붙여 다음 글자를 만드는 방식 |
| 검증 loss | 학습에 쓰지 않은 데이터에서 잰 loss. 외웠는지 배웠는지 가를 수 있다 |
| register_buffer | 학습하지 않는 텐서(마스크 등)를 모델에 등록하는 방법 |
| temperature, top-k | 생성의 다양성 조절. 온도가 낮으면 무난하고 높으면 다양하다. top-k는 상위 k개 중에서만 고른다 |

## 알게 된 것

### 구현은 맞았다

`"hel"`을 넣으면 `"hello transformer! building a mini transfor"`가 나온다. 어텐션 스케일(`head_dim ** -0.5`), softmax 전 마스킹, 생성할 때 컨텍스트 자르기(`[:, -block_size:]`)를 모두 맞게 했다.

### 하지만 외운 것이었다

학습 데이터가 문장 하나였다. loss 0.09와 원문 그대로의 생성은 배운 게 아니라 외운 것이다. 9/15 MNIST 학습 정확도 99.7%와 같은 함정이다.

### 큰 데이터로 바꾸니 제대로 배운다

| 스텝 | 학습 loss | 검증 loss |
|---|---|---|
| 1 | 4.19 | 4.19 |
| 600 | 2.25 | 2.25 |
| 1800 | 1.97 | 2.04 |

- 시작 loss 4.19는 ln(65) = 4.17과 거의 같다. 65개 글자 중 아무거나 찍는 수준에서 출발한다
- 검증 loss가 학습 loss를 따라 내려간다. 안 본 데이터에서도 좋아지고 있으니 배우는 중이다

### 연구와의 연결

- 직접 만든 `CausalSelfAttention`과 pre-LN 블록이 SmolVLA의 action expert와 같은 구조다. LoRA를 붙이는 `q/k/v/o_proj` 자리가 바로 여기다
- 글자는 하나씩 만들지만 SmolVLA는 동작 50스텝을 한꺼번에 만든다(action chunk). 전환할 때 "남은 동작을 어떻게 할까" 문제가 여기서 생긴다
