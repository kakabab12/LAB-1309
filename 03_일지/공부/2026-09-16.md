> **한 줄 요약**: 문자 단위 Transformer 를 직접 만들어 문장을 생성했지만 문장 하나를 외운 것이었고, tiny shakespeare 로 바꾸자 검증 loss 가 같이 내려가며 진짜로 배우기 시작했다.

## 이 일지에서 새로 나오는 말

| 말 | 뜻 |
|---|---|
| **causal mask** | 뒤에 올 글자를 미리 못 보게 가리는 마스크 (아래 삼각형 행렬) |
| **pre-LN** | 어텐션·MLP **앞에** LayerNorm 을 두는 구조. 학습이 안정적 |
| **위치 임베딩** | 어텐션은 순서를 모르므로, 몇 번째 글자인지 따로 더해주는 벡터 |
| **auto-regressive 생성** | 만든 글자를 다시 입력에 붙여 다음 글자를 만드는 방식 |
| **검증 loss** | 학습에 안 쓴 데이터에서 잰 loss. 외웠는지 배웠는지 구분 |
| **register_buffer** | 학습 안 하는 텐서(마스크 등)를 모델에 등록 |
| **temperature / top-k** | 생성 다양성 조절. 온도↓ 안전, 온도↑ 다양. top-k 는 상위 k 개만 |

## 알게 된 것

### 1. 구현은 맞았다

`"hel"` → `"hello transformer! building a mini transfor"`. 어텐션 스케일(`head_dim ** -0.5`), softmax 전 마스킹, 생성 시 컨텍스트 자르기(`[:, -block_size:]`)를 모두 맞게 했다.

### 2. 하지만 외운 것이었다

학습 데이터가 문장 **하나**. loss 0.09 와 원문 그대로의 생성은 **암기**다. 9/15 MNIST 학습 정확도 99.7% 와 같은 함정.

### 3. 큰 데이터로 바꾸니 진짜 학습

| 스텝 | 학습 loss | 검증 loss |
|---|---|---|
| 1 | 4.19 | 4.19 |
| 600 | 2.25 | 2.25 |
| 1800 | 1.97 | 2.04 |

- 시작 loss 4.19 ≈ ln(65) = 4.17 → 65개 글자 중 아무거나 찍는 수준에서 출발
- **검증 loss 가 학습 loss 를 따라 내려감** → 안 본 데이터에서도 좋아짐 = 배우는 중

### 4. 연구와의 연결

- 직접 만든 `CausalSelfAttention`·pre-LN 블록이 **SmolVLA 의 action expert 와 같은 구조**. LoRA 를 붙이는 `q/k/v/o_proj` 자리가 바로 여기
- 글자는 **하나씩** 생성, SmolVLA 는 동작 **50스텝을 통째로** 생성 (action chunk) → 전환할 때 "남은 동작을 어떻게 할까" 문제가 여기서 생김
