# 지금까지 한 일 — 보고용 요약 (2026-10-03 새벽 기준)

> 검증한 사실만 적었다. 숫자 옆 괄호는 측정 조건.
> 용어: **시범 프로그램** = 시뮬레이터의 정확한 물체 좌표로 팔을 움직여 학습용 시범을 만드는 프로그램(실물에서는 못 씀). **학생 모델** = SmolVLA, 카메라 2장 + 로봇 상태 + 지시문만 보고 움직이는 모델.

## 1분 판

로봇이 A 일을 하다가 물건을 쥔 상태에서 새 지시 B를 받으면, 쥔 물건을 아무 데나 내려놓고 B를 한 뒤 다시 그 물건을 집어 A를 마치게 하는 연구다. 처음 자세로 돌아가지 않고, 연구실 1080 Ti 같은 저사양 GPU에서 실시간으로 돌아가는 것이 조건이다. 모델은 SmolVLA(0.45B), 실험은 LIBERO-Goal 시뮬레이터.

9월에는 실패 원인을 분석했다. 물건을 쥐는 순간 모델이 지시를 덜 따르게 되고, 1080 Ti 계산 지연(0.56초)이 들어가면 성공률이 무너진다. 이후 시범 프로그램을 만들었고(측정한 항목 대부분 95~100%), 이 시범으로 SmolVLA를 학습시키며 논문의 지연 대응 학습과 매 스텝 보정 네트워크를 직접 구현해 넣었다. 보정 네트워크는 일부 태스크를 30%에서 100%로 올렸다. 중간에 평가 장면이 학습 데이터와 겹치는 문제를 발견해 학습에 안 쓴 새 배치로 평가를 바꿨고, 깨끗한 조건의 첫 성적표가 10/3 오전에 나온다. 목표는 28개 항목 각각 95%, 10/10까지 반복 개선 후 실물 로봇(PiPER)으로 간다.

## 1. 주제와 차별점

| | SwitchVLA (2025) | Causeway (2026-09) | 우리 |
|---|---|---|---|
| 쥔 채 전환 | 부분적 | 있음 | 있음 |
| 원래 일로 돌아가기(재개) | 없음 | 없음 | **있음** |
| 처음 자세 | 기준 자세로 보냄 | B 시작 자세로 끌어당김 | 7cm 안으로 안 들어감을 수치로 확인 |
| 모델·하드웨어 | 큰 모델 | 3B급, 추론 2.5배 느려짐 | 0.45B, 1080 Ti, 추론 비용 그대로 |

## 2. 원인 분석 (9월, 검증함)

| 발견 | 수치 |
|---|---|
| 원래 SmolVLA 전환 성공률 | 18~39% (처음 자세로 되돌리면 82~92%지만 제약 위반) |
| 쥐는 순간 지시 반영도 하락 | 0.72 → 0.28 (CMI) |
| 실패 모습 | 대부분 같은 자리를 맴돌다 시간 초과 |
| 1080 Ti 지연 0.56초 | 와인병 태스크 100% → 0% (v6b) |

## 3. 방법

- 시범 프로그램: 10개 태스크 + 전환 + 내려놓기 + 재개. 측정한 항목 대부분 95~100% (장면 30개). 새 배치 100장면 측정 중 (T0, T1 100/100)
- 학생 모델 학습 + 논문 기법 직접 구현: 학습 때 지연 흉내내기(Training-Time RTC), 매 스텝 보정 네트워크(A2C2), 교정 시범 수집(DAgger), 가중치 이동평균
- A2C2 효과: T1 30→100%, T4 50→90%, T8 0→60% (장면 10개)

## 4. 발견하고 고친 문제

| 문제 | 조치 |
|---|---|
| 평가 장면 누수: LIBERO 시작 배치가 번호 % 50이라 평가 장면이 학습 데이터에 있었다 | 학습에 안 쓴 무작위 배치(장면 1000번대)로 평가 |
| 잘못된 교정 시범 267개: 쥔 물건을 바로 놓는 시범 → 모델이 그릇을 집자마자 놓음 | 시범 격리, 넘겨받기 규칙 수정, 다시 학습(v6c2) |
| 동작 정규화가 사람 시범 기준이라 손 위치 정밀도를 덜 봄 | 학습 데이터 기준으로 다시 잼 |
| 시범 프로그램 약점 (접시 밀기, 서랍 앞 그릇, 처음 자세 근처 통과) | 고쳐서 해당 항목 30/30 |

## 5. 현재와 계획

- 학생 모델은 아직 목표 미달. 깨끗한 조건 첫 성적표는 10/3 오전
- 10/10까지 반복: 95% 미만 항목 교정 시범 → 다시 학습 → 평가
- 최종 평가: 항목마다 새 배치 100장면, 95번 이상 성공
- 다음 단계: 실물 로봇 PiPER (원격 조종 시범 + 사람이 넘겨받는 교정)
