# 새 서버에 Ubuntu 설치하고 연구 환경 만들기

> **대상**: RTX 2080 Ti ×2, SSH 원격 접속만 쓰는 서버
> **목표**: 지금 돌아가는 환경(Ubuntu 22.04 + Python 3.10 + torch cu126)을 그대로 재현
> **걸리는 시간**: 설치 40분 + 환경 30분

---

# 0. 먼저 알아둘 것

## 0-1. 왜 22.04 인가

| | Ubuntu 22.04 LTS | Ubuntu 24.04 LTS |
|---|---|---|
| 기본 파이썬 | **3.10** ← 우리가 쓰는 것 | 3.12 |
| 우리 환경 검증 | ✅ **9일간 문제없이 돌아감** | ❌ 안 해봄 |
| 2080 Ti 지원 | ✅ 문제없음 | ✅ 문제없음 |

`uv` 가 파이썬을 알아서 받아오긴 하지만, **지금 잘 돌아가는 조합을 그대로 쓰는 게 안전**합니다.
새 서버에서 환경 문제로 시간을 쓰는 것이 가장 아깝습니다.

→ **Ubuntu Server 22.04.5 LTS** 를 받으세요.
https://releases.ubuntu.com/22.04/ 에서 `ubuntu-22.04.5-live-server-amd64.iso`

## 0-2. ⭐ 2080 Ti 2장이라 좋은 점

지금은 GPU 1장이라 실험을 **한 줄로 세워** 돌리고 있습니다 (하나 끝나야 다음 시작).
2장이면 **동시에 2개**를 돌릴 수 있어 **실험 시간이 절반**이 됩니다.

```bash
CUDA_VISIBLE_DEVICES=0 ./run_실험A.sh &
CUDA_VISIBLE_DEVICES=1 ./run_실험B.sh &
```

⚠️ 단, **추론 시간을 재는 실험은 반드시 혼자** 돌려야 합니다 (2026-09-18 교훈).

## 0-3. ⚠️ 2080 Ti 는 bf16 이 안 됩니다

| GPU 세대 | bf16 | fp16 텐서코어 |
|---|---|---|
| Pascal (1080 Ti) | ❌ | ❌ |
| **Turing (2080 Ti)** | ❌ | ✅ |
| Ampere 이상 (30/40 시리즈) | ✅ | ✅ |

bf16 은 못 쓰지만 **fp16 텐서코어가 있어 1080 Ti 보다 학습이 빠릅니다.**
지금 코드는 fp32 로 도니 그대로 돌아가고, 나중에 fp16 을 켜면 더 빨라질 수 있습니다.

# 1. 설치 USB 만들기

다른 PC(윈도우/맥/리눅스)에서 합니다. USB 8GB 이상.

| OS | 도구 |
|---|---|
| 윈도우 | [Rufus](https://rufus.ie) — ISO 고르고 "DD 이미지 모드"로 쓰기 |
| 맥·리눅스 | [balenaEtcher](https://etcher.balena.io) |

리눅스 명령어로 하려면 (⚠️ `of=` 장치를 틀리면 **그 디스크가 날아갑니다**. `lsblk` 로 꼭 확인):

```bash
lsblk                      # USB 가 어느 장치인지 확인 (예: sdc)
sudo dd if=ubuntu-22.04.5-live-server-amd64.iso of=/dev/sdc bs=4M status=progress conv=fsync
```

# 2. BIOS 설정

서버를 켜고 `Del` 또는 `F2` 를 연타해서 BIOS 로 들어갑니다.

| 항목 | 설정 | 왜 |
|---|---|---|
| Boot Mode | **UEFI** | 요즘 표준 |
| Secure Boot | **Disabled** | ⭐ NVIDIA 드라이버가 막힙니다 |
| Above 4G Decoding | Enabled | GPU 2장 쓸 때 필요할 수 있음 |
| Restore on AC Power Loss | **Power On** | 정전 후 자동으로 켜짐 (서버라 중요) |
| Boot Priority | USB 를 1순위 | |

**Secure Boot 를 끄는 것이 가장 중요합니다.** 켜져 있으면 드라이버 설치 후에도
GPU 를 못 잡고, 원인을 찾기 어렵습니다.

# 3. Ubuntu Server 설치

USB 로 부팅하면 파란 화면의 설치 마법사가 나옵니다. 방향키와 Enter 로 진행합니다.

| 단계 | 선택 |
|---|---|
| Language | English (한글은 콘솔에서 깨질 수 있습니다) |
| Keyboard | Korean 또는 English(US) |
| Type of install | **Ubuntu Server** (Minimized 아님) |
| Network | 아래 3-1 참고 |
| Proxy | 비워둠 |
| Mirror | 그대로 (`kr.archive.ubuntu.com` 이면 좋음) |
| Storage | 아래 3-2 참고 ⭐ |
| Profile | 아래 3-3 참고 |
| **SSH Setup** | ⭐ **Install OpenSSH server 체크** |
| Snaps | 아무것도 고르지 않음 |

## 3-1. 네트워크 — 고정 IP 로 하세요

서버는 IP 가 바뀌면 접속을 못 합니다. 설치 중에 고정 IP 를 주는 게 좋습니다.

`Network connections` 에서 유선 랜을 고르고 → `Edit IPv4` → `Manual`:

```
Subnet   : 192.168.0.0/24      ← 연구실 대역에 맞추세요
Address  : 192.168.0.50        ← 안 쓰는 번호
Gateway  : 192.168.0.1         ← 공유기 주소
Nameservers: 8.8.8.8,1.1.1.1
```

**모르면** 연구실에서 쓰는 다른 PC 에서 확인하세요:

```bash
ip route | grep default      # Gateway 가 나옵니다
ip -4 addr                   # 대역을 알 수 있습니다
```

## 3-2. ⭐ 디스크 나누기 — `/home` 을 따로 만드세요

기본값(`Use an entire disk`)으로 하면 전부 한 덩어리가 됩니다.
그러면 **나중에 우분투를 다시 깔 때 연구 결과가 같이 날아갑니다.**

`Custom storage layout` 을 골라 이렇게 나누세요 (디스크 1TB 기준):

| 파티션 | 크기 | 마운트 | 형식 |
|---|---|---|---|
| EFI | 1GB | `/boot/efi` | FAT32 |
| root | 200GB | `/` | ext4 |
| **home** | **나머지 전부** | **`/home`** | ext4 |
| swap | 32GB (RAM 만큼) | swap | swap |

**이렇게 해두면 다음에 재설치할 때 `/home` 만 "포맷하지 않음" 으로 두면
연구 결과가 그대로 남습니다.**

> 우리 실험 결과는 지금 **5GB** 이고 다시 만들려면 **수십 시간**이 듭니다.
> 이 한 번의 설정이 그걸 지켜 줍니다.

## 3-3. 계정

```

Your server's name : lab1309        ← 짧게. 나중에 ssh lab1309 로 씁니다
Pick a username: user               ← 지금 PC 와 같게 하면 경로가 같아 편합니다
Password       : (기억할 수 있는 것)
```

설치가 끝나면 **USB 를 뽑고** 재부팅합니다.

# 4. 첫 접속과 기본 설정

## 4-1. SSH 로 들어가기

개인 PC 에서:

```bash
ssh user@192.168.0.50
```

⚠️ 안 되면 서버에 모니터를 잠깐 연결해 `ip a` 로 IP 를 확인하세요.

## 4-2. 비밀번호 없이 접속하기 (권장)

매번 비밀번호를 치지 않아도 됩니다. **개인 PC 에서**:

```bash
ssh-keygen -t ed25519          # 이미 있으면 건너뜀 (그냥 Enter 세 번)
ssh-copy-id user@192.168.0.50
```

그리고 `~/.ssh/config` 에 적어두면 `ssh lab` 만으로 접속됩니다:

```
Host lab
    HostName 192.168.0.50
    User user
```

## 4-3. 업데이트와 기본 도구

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential git curl wget htop tmux
```

## 4-4. ⭐ tmux — 접속이 끊겨도 실험이 계속 돌게

SSH 로 실험을 돌리다 연결이 끊기면 **실험도 같이 죽습니다.**
`tmux` 안에서 돌리면 끊겨도 계속 돕니다.

```bash
tmux new -s lab      # 'lab' 이라는 작업 공간 만들기
# ... 실험 실행 ...
# Ctrl+b 누르고 d  → 빠져나오기 (실험은 계속 돔)

tmux attach -t lab   # 다시 들어가기
```

# 5. NVIDIA 드라이버 (GPU 2장)

## 5-1. 설치

```bash
sudo apt install -y ubuntu-drivers-common
ubuntu-drivers devices          # 추천 드라이버 확인
sudo ubuntu-drivers install     # 추천 버전 자동 설치
sudo reboot
```

수동으로 지정하려면 (지금 PC 는 580 을 씁니다):

```bash
sudo apt install -y nvidia-driver-580
```

## 5-2. 확인

```bash
nvidia-smi
```

**GPU 2장이 모두 보여야 합니다:**

```
| 0  NVIDIA GeForce RTX 2080 Ti    ...  11264MiB |
| 1  NVIDIA GeForce RTX 2080 Ti    ...  11264MiB |
```

### 안 보이면

| 증상 | 원인 | 해결 |
|---|---|---|
| `NVIDIA-SMI has failed` | **Secure Boot 가 켜져 있음** | BIOS 에서 끄고 드라이버 재설치 |
| 1장만 보임 | 슬롯 접촉 / 보조전원 | 서버를 열어 확인 |
| 부팅이 멈춤 | 드라이버 충돌 | 복구 모드 → `sudo apt purge nvidia-*` → 재설치 |

## 5-3. ⭐ 헤드리스 렌더링 확인 (LIBERO 에 꼭 필요)

모니터가 없어도 LIBERO 가 화면을 그려야 합니다. **EGL** 이라는 방식을 씁니다.
드라이버를 깔면 자동으로 되지만, **확인해 두면 나중에 헤맬 일이 없습니다.**

```bash
ls /usr/share/glvnd/egl_vendor.d/
```

**`10_nvidia.json` 이 있어야 합니다.** 없으면:

```bash
sudo apt install -y libegl1 libglvnd0 libgl1 libglx-mesa0
```

> 우리 코드는 `switch_experiment.py` 등에서 `MUJOCO_GL=egl` 을 자동으로 설정하므로
> 따로 환경변수를 잡을 필요는 없습니다.

# 6. 연구 환경 만들기

```bash
# uv 설치 (pip 보다 빠르고 충돌을 알아서 풉니다)
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env

mkdir -p ~/smolVLA && cd ~/smolVLA
uv venv --python 3.10

uv pip install torch --index-url https://download.pytorch.org/whl/cu126
uv pip install "lerobot[smolvla]==0.4.4"
uv pip install git+https://github.com/Lifelong-Robot-Learning/LIBERO.git
uv pip install robosuite==1.4.1 matplotlib scipy imageio imageio-ffmpeg
```

## 6-1. 실험 코드 가져오기

```bash
cd ~
git clone https://github.com/kakabab12/LAB-1309.git
cp LAB-1309/04_실습/05_libero/코드/*.py ~/smolVLA/
cp LAB-1309/04_실습/05_libero/코드/*.sh ~/smolVLA/
chmod +x ~/smolVLA/*.sh
```

## 6-2. 확인

```bash
cd ~/smolVLA
.venv/bin/python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.device_count())"
```

**기대 출력**: `2.10.0+cu126 True 2`   ← 마지막 `2` 가 GPU 2장

그리고 실제로 한 판 돌려 봅니다 (모델·에셋을 받느라 첫 실행은 몇 분 걸립니다):

```bash
.venv/bin/python switch_experiment.py --task-a 8 --task-b 7 \
  --switch-at grasp:3 --strategy flush --episodes 2 --out outputs/test
```

마지막에 `SUMMARY A8_B7_grasp3_flush {...}` 가 나오면 성공입니다.
