# 연구실 PC에서 걸리는 시간, 최신 하드웨어라면 (2026-10-02)

연구실 PC에서 **실제로 잰 값**과, 최신 하드웨어에서의 **추정값**을 나눠 적는다. 추정은 아래에 적은 근거에서 계산한 것이고, 직접 재기 전까지는 가능성일 뿐이다.

## 1. 연구실 PC 사양

| 부품 | 사양 | 출시 |
|---|---|---|
| CPU | Intel Core i7-7700K, 4코어 8스레드, 4.2GHz | 2017 |
| GPU | GeForce GTX 1080 Ti, 11GB (Pascal) | 2017 |
| 메모리 | 31GB, 스왑 없음 | |
| 저장 장치 | 2.7TB 하드디스크 (회전식) | |

GTX 1080 Ti는 bf16과 텐서코어가 없다. 그래서 SmolVLA를 fp32로 돌린다. 최신 GPU가 빠른 가장 큰 이유가 텐서코어와 bf16인데, 이 PC는 둘 다 쓸 수 없다.

## 3. 최신 하드웨어라면 (추정)

### 근거로 쓴 값

| 근거 | 값 | 종류 |
|---|---|---|
| SmolVLA 계산 1번, RTX 5080 노트북 GPU | **0.101초** | 실측 ([A2C2 논문](https://arxiv.org/abs/2509.23224)) |
| π0(3B, SmolVLA의 약 7배) 계산 1번, bf16 | RTX 4090 31ms, A100 16ms | 모델로 계산한 예측, 실측의 73~83% 수준으로 검증 ([VLA-Perf](https://arxiv.org/abs/2602.18397)) |
| A2C2 보정 네트워크 학습 (20만 스텝) | H200에서 약 4시간 | 실측 (A2C2 논문) |
| GPU 계산 성능 (공개 사양) | 1080 Ti fp32 11.3 TFLOPS, 텐서코어 없음 / RTX 4090 fp32 82.6, bf16 텐서 165 / A100 bf16 312 / H100 bf16 989 | 제조사 사양 |

### 추정

| 작업 | 1080 Ti (실측) | RTX 4090급 (추정) | H100급 (추정) |
|---|---|---|---|
| SmolVLA 계산 1번 | 0.56초 (11스텝) | 0.05~0.1초 (1~2스텝) | 0.02~0.05초 (1스텝 이하) |
| v6c 학습 24,000스텝 | 5.8시간 | 0.5~1시간 | 15~30분 |
| 데이터 한 바퀴 | 45시간 | 5~8시간 | 2~3시간 |
| 28개 항목 평가 | 2~3시간 | 1~1.5시간 | 1시간 안팎 |
| 사진 특징 미리 계산 | 약 27시간 | 3~5시간 | 1~2시간 |

추정 방법
- 계산 1번: RTX 5080 노트북 실측(0.101초)을 기준으로 잡았다. 데스크톱 4090은 그보다 계산 성능이 높아 0.05~0.1초로 봤다. H100은 π0 예측값의 비율을 따랐다.
- 학습: bf16 텐서코어 이론 성능은 1080 Ti fp32의 15배(4090)와 90배(H100)다. 실제로는 메모리 대역폭과 작은 배치 때문에 이론의 절반 이하로 보고 6~10배, 20~30배를 잡았다.
- 평가: 시뮬레이터는 CPU에서 돈다. 그래서 GPU가 빨라져도 절반 정도만 줄어든다고 봤다.

## 4. 이게 연구에 뜻하는 것

| | 1080 Ti | 최신 GPU |
|---|---|---|
| 지연 | 11스텝. 아무 대책이 없으면 성공률이 무너진다(v6b: T2 100% → 0%) | 1~2스텝(추정). 지연 문제가 거의 사라진다 |
| 학습 | 데이터를 한 바퀴도 못 돈다. 하루에 한 번 학습·평가하는 정도 | 하루에 여러 번 고치고 다시 학습할 수 있다 |

- 최신 GPU에서는 지연 없이 잰 성적이 실제와 가깝다(추정).
- 우리가 1080 Ti 지연 11스텝을 기준으로 삼는 것은 **가장 어려운 저사양 조건**에서 쓸 수 있는 모델을 만들겠다는 뜻이다. 여기서 되면 더 좋은 하드웨어에서도 된다.
- 반대로, 최신 GPU에서 잰 다른 논문 수치를 우리 수치와 바로 비교하면 안 된다.

검증 계획: RTX 2080 Ti 서버(텐서코어 있음, fp16)가 들어오면 같은 `bench_inference.py`와 학습 1스텝 시간을 재서 이 표의 추정을 실측으로 바꾼다.
