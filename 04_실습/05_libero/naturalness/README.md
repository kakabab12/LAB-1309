# 자연스러움 지표 — 전환이 얼마나 사람처럼 이어지나 (2026-09-17)

## 📌 쉬운 말 요약

**왜?** 연구 제약이 "사람처럼 자연스럽게"입니다([연구주제.md](../../../연구주제.md)). 느낌으로는 비교가 안 되니 숫자로 바꿨습니다.

**결과 한 줄**: 원위치로 돌아가는 `retreat` 은 성공률은 높지만 **38cm 더 돌아가고 멈춤도 2배**입니다. 반대로 LoRA 1차 모델은 성공했을 때 **가장 곧게** 갑니다.

## 지표

전환 순간부터 B 성공까지의 끝단 궤적으로 잽니다.

| 지표 | 계산 | 좋은 값 |
|---|---|---|
| **경로 길이** | 끝단이 실제로 움직인 거리 | 짧을수록 |
| **우회 비율** | 경로 길이 ÷ 직선 거리 (직선 거리 최소 5cm) | 1에 가까울수록 곧게 감 |
| **소요 시간** | 전환 → B 성공 (20스텝 = 1초) | 짧을수록 |
| **멈춤 횟수** | 속도 0.1cm/스텝 미만이 0.25초 이상 이어진 구간 | 적을수록 (stop-and-go 가 없음) |
| **되돌아감** | 전환 직후 1초 동안 B 목표에서 오히려 멀어진 거리 | 작을수록 |

멈춤 기준 0.1cm/스텝은 실제 궤적의 속도 분포에서 정했습니다. 움직일 때는 0.5~1.2cm/스텝, 거의 정지는 0.1 아래입니다.

## 해석

- **성공률과 자연스러움이 반대로 간다.** retreat 은 89% 로 가장 잘 되지만 가장 부자연스럽다. 이게 "초기 자세 복귀 금지" 제약이 필요한 이유를 숫자로 보여준다
- **LoRA 1차가 가장 곧다** (1.45). 성공률은 못 올렸지만 방향은 맞다 — 리셋 없는 데이터로 학습해서 돌아가지 않고 바로 간다
- keep 이 flush 보다 조금 더 돌아간다 (1.72 vs 1.52). 남은 chunk 를 다 쓰는 동안 A 방향으로 가다가 꺾기 때문
- **되돌아감 지표는 구분력이 없었다.** 모든 전략에서 1cm 안팎. 전환 직후 1초는 너무 짧거나, B 목표까지 거리가 커서 차이가 안 드러나는 것 같다. 다른 정의가 필요
