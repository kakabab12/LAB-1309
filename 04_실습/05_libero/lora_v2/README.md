# LoRA 2차 — 데이터 균형을 맞춘 재학습

> **결론: 망각은 고쳤지만 전환은 하나도 나아지지 않았다.** 전환 B 성공률 32% → **31%** (짝 비교 7 : 9, p ≈ 0.80).
> 자기 궤적을 다시 따라 배우는 방식(self-imitation)으로는 전환이 안 된다는 뜻입니다.

[LoRA 1차](../lora_v1/README.md)가 데이터 편향으로 실패해서, 원인별로 대응을 넣어 다시 학습했습니다.

| 1차 문제 | 2차 대응 |
|---|---|
| 원래 잘하던 태스크를 잊음 (태스크 1: 100% → 60%) | 10개 태스크의 교란 없는 **정상 궤적** 추가 (rehearsal) |
| 교란 범위(최대 8cm)가 실제 전환 이탈(12~27cm)보다 좁음 | 위치 교란 **8~20cm** |
| 못하는 쌍(1→5, 2→5)은 성공 데이터가 0개 | **hindsight relabeling** (실패해도 실제로 이룬 목표로 지시문을 바꿔 저장) |
| "turn on the stove" 가 데이터의 40% | 지시문별 **균형 샘플링** (`WeightedRandomSampler`) |
| 망각이 큼 | LoRA r 16 → 8, lr 1e-4 → 5e-5 |

참고 논문: [LoRA Learns Less and Forgets Less](../../../02_논문노트/LoRA-Learns-Less-Forgets-Less.md) (r 을 낮추면 망각이 줄어든다), [HER](../../../02_논문노트/HER.md) (hindsight relabeling), [DART](../../../02_논문노트/DART.md) (교란된 상태에서의 회복 학습)

## 학습 설정

| 항목 | 값 |
|---|---|
| 데이터 | 442 에피소드 = 정상·교란 궤적 323 + 전환 궤적 36 + **hindsight 47** + 먼 교란 36 |
| 스텝 | 2500 (batch 4 × grad accum 2) |
| LoRA | r=8, alpha=16, lr 5e-5, 대상 = action expert 의 q/k/v/o·gate/up/down proj |
| VRAM | 2.64GB (1080 Ti 11GB) |
| loss | 0.091 → 0.079 (학습), val 0.053 |
| 학습 시간 | 약 100분 |

실행: `run_pipeline_v2b.sh` — 1차 v2 실행은 **코드 수정 중 옵션 누락 버그**로 먼 교란 4개 + hindsight 8개 작업이 조용히 죽은 채 학습됐습니다 ([그 교훈](../../../03_일지/2026-09-18.md)).

| 조건 | 원본 | LoRA 1차 | **LoRA 2차** |

| 교란 없는 기본 성능 (태스크 7·1·5 평균) | 86.7% | **73.3%** ⬇ | **90.0%** ✅ |
| 태스크 1 (bowl→stove) 교란 없음 | 100% | **60%** ⬇ | **100%** ✅ |
| 손목 20° (태스크 7) | 60% | 70% | **90%** ✅ |

- **rehearsal + r 낮추기 + 균형 샘플링으로 망각을 되돌렸습니다** (태스크 1이 60% → 100%)
- 태스크 7 에서는 손목 회전에 더 강해졌습니다 (20° 에서 60 → 90%)
- 다만 태스크 1·5 의 교란 조건은 원본보다 조금 낮아서, 18조건 평균은 여전히 원본이 낫습니다

## 왜 전환이 안 늘었나

1. **가르친 내용이 전환이 아니다.** 우리 데이터는 "교란된 자세에서 태스크 수행" + "성공한 전환의 재현"입니다. 이미 성공하는 것을 더 잘하게 만들 뿐, **실패하는 상황(1→5, 2→5)에 대한 정답 동작이 데이터에 없습니다.** hindsight 로 지시문을 바꿔 넣어도, 그건 "우연히 이룬 다른 목표"라서 원하는 목표의 해법을 가르치지 않습니다.
2. **[Q-Planning](../../../02_논문노트/Q-Planning.md)이 예측한 그대로** — 자기 성공 궤적만 걸러 다시 배우는 filtered SFT 는 곧 한계에 부딪힙니다. 정책이 이미 할 수 있는 것 안에서만 도니까요.
3. **전환 실패의 원인이 자세가 아니다.** [가설 검증](../hypothesis_check/README.md)에서 팔 위치 거리와 성공은 상관이 거의 없었습니다 (r = +0.14). 그래서 "교란된 자세에서 회복하기"를 가르쳐도 전환이 안 늘어납니다.
