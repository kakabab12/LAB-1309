# LoRA 2차 — 데이터 균형을 맞춘 재학습 (진행 중)

[LoRA 1차](../lora_v1/README.md)가 데이터 편향으로 실패해서, 원인별로 대응을 넣어 다시 학습합니다.

| 1차 문제 | 2차 대응 |
|---|---|
| 원래 잘하던 태스크를 잊음 (태스크 1: 100% → 60%) | 10개 태스크의 교란 없는 **정상 궤적** 추가 |
| 교란 범위(최대 8cm)가 실제 전환 이탈(12~27cm)보다 좁음 | 위치 교란 **8~20cm** |
| 못하는 쌍(1→5, 2→5)은 성공 데이터가 0개 | **hindsight relabeling** |
| "turn on the stove" 가 데이터의 40% | 지시문별 **균형 샘플링** |
| 망각이 큼 | LoRA r 16 → 8, lr 1e-4 → 5e-5 |

실행: `run_pipeline_v2.sh` ([lora_v1 폴더](../lora_v1/)에 있음)

결과가 나오면 이 문서를 채웁니다.
