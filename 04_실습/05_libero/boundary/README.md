# 어디까지 교란해도 작동하나 — 그리고 "전환"은 무엇을 더하는가 (2026-09-18)

## 📌 쉬운 말 요약

**질문 1**: 팔을 초기 자세에서 얼마나 옮겨 놓아도 정책이 태스크를 해낼까? (학습 데이터를 모을 수 있는 범위)

**질문 2**: 전환 시점은 초기 위치에서 27cm 떨어져 있다. **그냥 27cm 옮겨 놓은 것과 전환이 다른가?**

**답**: 쉬운 쌍에서는 **다르지 않습니다.** 전환의 어려움은 **팔이 27cm 떨어져 있다는 것이 거의 전부**입니다.

---

## 1. 위치를 얼마나 옮겨도 되나 (태스크 7, 조건당 10회)

| 초기 위치에서 | 성공률 |
|---|---|
| 0cm | 100% |
| 4cm | 100% |
| 8cm | 90% |
| 12cm | 80% |
| 16cm | 60% |
| **20cm** | **50%** |

**완만하게 떨어집니다.** 20cm 에서도 절반은 해냅니다 →
**20cm 까지는 자기 궤적으로 학습 데이터를 모을 수 있습니다** (역커리큘럼에 필요).

(0~8cm 은 [2026-09-16 자세 민감도](../pose_sensitivity/README.md) 측정값)

## 2. ⭐ "전환"은 팔 위치 말고 무엇을 더하는가

전환 시점의 실제 이탈은 **위치 27cm, 회전 8도**입니다.
위 곡선을 27cm 로 늘여 보면 **약 50%** 가 됩니다. 실제 전환과 비교하면:

| 쌍 | 실제 전환 B 성공 | 깨끗한 장면 27cm 예측 | 차이 |
|---|---|---|---|
| 8→7 | 55% | 50% | **+5%p** |
| 4→7 | 50% | 50% | **0%p** |
| 9→7 | 0% | 50% | −50%p |

**8→7 과 4→7 은 예측과 거의 같습니다.**

즉 그 쌍들에서는
- 지시가 바뀐 것 → 추가 부담 **없음**
- 쥐었던 물체가 옮겨진 것 → 추가 부담 **없음** (B 가 그 물체를 안 쓰므로)
- **팔이 27cm 떨어져 있는 것 → 이것이 전부**

**9→7 만 0% 로 크게 벗어납니다** — 그 쌍에는 위치 말고 다른 어려움이 있습니다
(A 가 와인병이고, [오라클에서도 어떤 노이즈로도 안 됐습니다](../oracle_bon/README.md)).

## 3. 이것이 바꾸는 것

우리는 "태스크 전환"을 하나의 새로운 문제로 다뤘습니다. 그런데 쉬운 쌍에서는
**이미 알려진 문제(초기 자세 의존성)의 한 사례**일 뿐입니다.

| 지금까지의 틀 | 바뀐 틀 |
|---|---|
| "전환은 어렵다" | **"정책이 초기 자세에서 멀면 어렵다. 전환은 팔을 27cm 옮겨 놓는 일이다"** |

이는 [회복 실험](../recovery/README.md)의 결론(**팔 자세가 지배 변수**)과 정확히 맞물립니다.
그리고 **왜 [LoRA 2차](../lora_v2/README.md)가 실패했는지**도 다시 봐야 합니다 —
그때 8~20cm 교란으로 학습했는데 전환이 안 늘었습니다. 전환이 27cm 라면 **학습 범위가 부족했던 것**일 수 있습니다.

> ⚠️ **한계**: 깨끗한 장면 곡선은 **태스크 7 하나**에서 잰 것이고, 27cm 는 20cm 까지의 값에서 **늘여 본 것**입니다.
> 그리고 전환 쌍마다 A 가 달라 장면 상태가 완전히 같지는 않습니다.
