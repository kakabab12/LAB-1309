## 3. Windows 에서 원고만 고칠 때 (가장 흔한 경우)

- **Word 로 `논문/paper_v2.docx` 를 직접 고치는 것이 가장 간단합니다.** 양식(HY신명조 9pt, 2단)이 그대로 들어 있습니다.
- 코드로 다시 만드는 것(`코드/paper/build_paper.py`)은 연구실 PC 의 `results/` 폴더와 양식 파일 경로를 읽으므로 **연구실 PC 에서만** 동작합니다. Windows 에서 Word 로 고친 뒤 연구실 PC 에서 다시 빌드하면 Word 수정이 덮어써지니 둘 중 하나만 쓰세요.
- 수치를 바꿔야 하면 [최종 수치 표](#최종-수치-논문에-들어간-값) 와 `결과/수치/` 의 JSON 을 근거로 하세요. 측정하지 않은 수치는 쓰지 않습니다.

## 4. 실험을 다시 돌리려면 (연구실 PC 권장)

| 항목 | 값 |
|---|---|
| OS / GPU | Ubuntu 22.04, GTX 1080 Ti 11 GB |
| Python 패키지 | Python 3.10.12, torch 2.7.1+cu126, mujoco 3.3.5, lerobot 0.3.3, numpy 2.2.6, opencv 5.0, h5py 3.16, safetensors 0.8, lxml 6.1, Pillow 12.3, matplotlib 3.10 |
| 렌더링 | `MUJOCO_GL=egl` (화면 없이). Windows 에서는 EGL 이 없어 `glfw` 창 모드로만 됨 (미검증) |
| 무거운 작업 | `systemd-run --user -p MemoryMax=…` 유닛으로만 (RAM 31 GB, 다른 프로그램 보호) |

주요 스크립트 (`코드/` 에 사본):

| 스크립트 | 하는 일 |
|---|---|
| `stack_env.py`, `expert.py`, `factory.py` | 시뮬레이션 셀, 스크립트 전문가(세 시연 규칙), 공장형 장면 |
| `gen_data.py` / `gen_pallet.py` | 시연 생성 (`--dr` 무작위화, `--factory` 공장형) / 팔레트 칸별 시연 (`PALLET_IK_POS=1` 위치 우선 IK) |
| `train_act.py` | ACT 학습 (`--state-noise` 관절 잡음, `--init CKPT --step0 N` 이어 학습) |
| `eval_act.py`, `clutter_eval.py`, `pallet_eval.py` | 연속 평가 (첫 실패에서 시퀀스 종료), 잡동사니·공장형 조건, 팔레트 8칸 (`이름@스텝`) |
| `demo_audit.py`, `demo_audit_general.py` | 학습 전 시연 점검 (손목 각도 빈 구간) |
| `orchestrate.py`, `health_check.py` | 학습·평가 대기열 (GPU 동시 4개, 여유 3 GB), 1시간 감시 |
| `publish.sh`, `sync_repo.sh` | 그림·원고 빌드 → 이 저장소로 복사 → 커밋·푸시 |
| `paper/content.py`, `paper/content_v2.py`, `paper/build_paper.py`, `paper/build_review.py` | 원고 본문(v1·v2)과 빌더, 심사용 4쪽 |

팔레트 스크립트는 배치 환경변수를 꼭 줍니다: `PALLET_X0=0.20 PALLET_Y0=0.017 PALLET_GAP_Y=0.014 PALLET_VIA=far ACT_DESIGN=v4` (없으면 예전 v1 배치).
