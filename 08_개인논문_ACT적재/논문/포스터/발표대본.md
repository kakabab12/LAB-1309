# 포스터 발표 대본 (11/28 토 09:00 포스터 세션 5, 07번)

> 약 1분 반 분량 (11/16 줄인 뒤 제안 2 설명을 자세히). 괄호 안은 그때 가리킬 포스터 칸이다. 숫자는 모두 포스터·논문과 같다.

## 대본

(제목) 안녕하세요, 계명대학교 이지용입니다. ACT 모방학습으로 적재함을 세 단계로 쌓을 때, 시연의 일관성이 성공률에 주는 영향을 분석했습니다.

(배경) 순차 적재는 앞 단계의 작은 오차가 다음 단계로 쌓입니다. 그래서 모델은 그대로 두고 시연만 바꿨습니다. 실제 로봇팔이 파손되어, 캡스톤 시스템을 MuJoCo로 그대로 재현해 실험했습니다.

(제안 1, 결과) 규칙은 여유 두고 잡기, 늘 같은 곳 잡기, 놓고 물러나기 세 가지입니다. 연속 성공률이 28%에서 99.0%로 올랐고, 무게 확인 재시도까지 넣으면 200번 모두 성공했습니다. 반면 가까운 벽 시연은 200개로 늘려도 36%였습니다. 시연은 양보다 일관성이었습니다.

(제안 2) 이런 시연은 학습하기 전에 찾을 수 있습니다. 시연 100번마다 집게가 닫히는 순간 로봇 손목이 몇 도 돌아가 있었는지 재서 작은 순서로 늘어놓습니다. 잡는 벽이 바뀌면 손목 각도도 크게 달라집니다. 규칙 시연은 늘 같은 벽을 잡아서 각도가 촘촘히 이어지고, 이웃한 두 시연의 차이가 가장 커도 3°입니다. 가까운 벽 시연은 앞벽 74번과 옆벽 26번으로 나뉘어, 두 무리 사이 51° 동안 시연이 하나도 없습니다. 이렇게 크게 빈 곳이 있으면 잡는 방식이 섞였다는 뜻이라, 학습하기 전에 다시 만듭니다.

(결론) 다만 시뮬레이션 결과라서, 실제 로봇으로 검증할 예정입니다. 감사합니다.

## 짧게 (30초, 시간이 없을 때)

ACT 모방학습으로 적재함을 세 단계로 쌓을 때, 모델은 그대로 두고 시연 규칙 세 가지만 바꿔 연속 성공률을 28%에서 99.0%로 올렸습니다. 가까운 벽 시연은 늘려도 36%로 떨어져, 시연은 양보다 일관성이 중요했습니다. 또 손목 각도의 빈 간격으로 이런 시연을 학습 전에 찾는 방법을 제안했습니다.

## 예상 질문

| 질문 | 답 |
|---|---|
| 왜 시뮬레이션인가요? | 실제 로봇팔이 고장 나서 실측 기록이 없습니다. 같은 SO-101 모델, 카메라 위치, 적재함 크기·무게로 MuJoCo 에 재현했고, 무게 인식만 실제 장치에서 쟀습니다. |
| 96% 와 99.0% 는 뭐가 다른가요? | 같은 모델입니다. 규칙끼리 비교는 50개 장면, 최종 모델만 200개 장면으로 다시 쟀습니다 (198/200, 95% 신뢰구간 96.4~99.7%). |
| 가까운 벽 시연은 뭔가요? (논문의 "사람식 시연") | 사람처럼 그때그때 가까운 벽을 잡도록 스크립트로 만든 시연입니다. 사람이 직접 한 시연은 아닙니다. 적재함이 약 +10° 넘게 돌면 옆벽으로 바꿔 잡습니다. |
| 컵은 시연을 늘렸는데요? | 규칙 시연으로 20 → 46% 가 됐고, 그다음 시연 300회와 관절 노이즈로 88% 가 됐습니다. 일관성을 맞춘 뒤에는 양도 도움이 됐습니다. |
| 빈 간격 G 는 몇 도 넘으면 나쁜가요? | 정해진 기준값은 아닙니다. 같은 물체·조건에서 시연 묶음끼리 비교하는 진단 지표입니다. |
| 성공 기준은요? | 위치 15mm, 높이 8mm, 기울기 10° 안이고, 먼저 놓은 적재함이 10mm 넘게 밀리지 않으면 성공입니다. |
| 빈 각도가 정확히 뭔가요? | 시연 100번의 손목 각도를 작은 순서로 줄 세웠을 때, 바로 옆 시연과 각도가 가장 많이 벌어진 곳의 크기입니다. 사람을 키 순서로 세우면 어른만 있을 때는 키가 고르게 이어지지만, 어린이와 어른이 섞이면 두 무리 사이에 키가 확 뛰는 큰 틈이 생기는 것과 같습니다. 큰 틈 = 잡는 방식이 섞였다는 표시입니다. |
| 왜 손목 각도를 보나요? | 어느 벽을 잡느냐에 따라 손목을 돌리는 방향이 크게 달라져서, 잡는 방식이 손목 각도에 그대로 드러나기 때문입니다. 학습 없이 시연 데이터만으로 계산할 수 있습니다. |
| mAP50 86.3% 는 뭔가요? | 저울 표시창의 7-세그먼트 숫자(0~9)를 하나씩 찾는 YOLOv8n 모델의 점수입니다. 찾은 상자가 정답 상자와 50% 이상 겹치면 맞은 것으로 치는 평균 정밀도이고, 학습 때 검증 이미지로 잰 값입니다 (정밀도 85.4%, 재현율 80.8%). 실제로 무게를 읽어 118g 기준으로 나눈 정확도는 실제 장치 60회에서 91.7% 입니다. |
| ACT 는 어떤 모델인가요? | 카메라 두 대 화면과 관절값을 보고 앞으로 100스텝의 관절 목표를 한 번에 내는 모방학습 모델입니다. 1층·옆·2층마다 따로 학습했습니다. |
