# 포스터 발표 대본 (11/28 토 09:00 포스터 세션 5, 07번)

> 약 2분 분량. 괄호 안은 그때 가리킬 포스터 칸이다. 숫자는 모두 포스터·논문과 같다.

## 대본

(제목) 안녕하세요, 계명대학교 컴퓨터공학전공 이지용입니다. ACT 모방학습으로 적재함을 1층, 옆, 2층 순서로 쌓을 때, 시연의 일관성이 성공률에 어떤 영향을 주는지 분석했습니다.

(연구 배경) 순차 적재는 앞 단계에서 놓은 적재함이 다음 단계의 출발점이라, 작은 오차와 시연마다 다른 동작이 단계를 거치며 쌓입니다. 그래서 모델은 그대로 두고 시연만 바꿨습니다.

(캡스톤 시스템) 캡스톤에서 YOLOv8 저울 숫자 인식과 SO-101 로봇팔을 Jetson Orin Nano로 연결했고, 118g 기준 분류는 실제 장치에서 91.7%였습니다. 로봇팔이 고장 나서, 적재 실험은 같은 조건을 MuJoCo로 재현해 진행했습니다.

(제안 1) 시연 규칙은 세 가지입니다. 벽에서 9mm 여유를 두고 잡기, 늘 같은 곳 잡기, 놓은 뒤 집게를 벌리고 5mm 물러났다가 올라가기입니다.

(실험 결과) 규칙을 하나씩 더할 때마다 세 단계 연속 성공률이 28%에서 62, 82, 96%로 올랐습니다. 같은 모델을 200개 장면에서 평가하면 99.0%이고, 저울로 실패를 확인해 다시 하면 200번 모두 성공했습니다. 반대로 잡는 곳이 갈리는 시연은 200개로 늘려도 36%로 떨어졌습니다. 시연은 양보다 일관성이 중요했습니다.

(제안 2) 이런 시연을 학습 전에 찾는 방법도 제안했습니다. 그때그때 가까운 벽을 잡는 시연은 앞벽 74번, 옆벽 26번으로 갈려서, 집게가 닫힐 때의 손목 각도 사이가 51° 비어 있습니다. 규칙 시연은 100번 모두 앞벽이라 빈 곳이 3°뿐입니다. 이 빈 각도만 보면 학습 전에 고칠 시연을 찾을 수 있습니다.

(검증, 결론) 잡동사니, 공장형 장면, 손잡이 컵, 직사각형 상자, 8칸 팔레트에서도 88~100%였습니다. 다만 로봇 조작은 시뮬레이션 결과라서, 앞으로 실제 로봇과 사람이 조작한 시연으로 검증하겠습니다. 감사합니다.

## 짧게 (30초, 시간이 없을 때)

ACT 모방학습으로 적재함을 세 단계로 쌓을 때, 모델은 그대로 두고 시연 규칙 세 가지만 바꿔 연속 성공률을 28%에서 99.0%로 올렸습니다. 잡는 곳이 갈리는 시연은 늘려도 36%로 떨어져, 시연은 양보다 일관성이 중요했습니다. 또 손목 각도의 빈 간격으로 이런 시연을 학습 전에 찾는 방법을 제안했습니다.

## 예상 질문

| 질문 | 답 |
|---|---|
| 왜 시뮬레이션인가요? | 실제 로봇팔이 고장 나서 실측 기록이 없습니다. 같은 SO-101 모델, 카메라 위치, 적재함 크기·무게로 MuJoCo 에 재현했고, 무게 인식만 실제 장치에서 쟀습니다. |
| 96% 와 99.0% 는 뭐가 다른가요? | 같은 모델입니다. 규칙끼리 비교는 50개 장면, 최종 모델만 200개 장면으로 다시 쟀습니다 (198/200, 95% 신뢰구간 96.4~99.7%). |
| 가까운 벽 시연은 뭔가요? (논문의 "사람식 시연") | 사람처럼 그때그때 가까운 벽을 잡도록 스크립트로 만든 시연입니다. 사람이 직접 한 시연은 아닙니다. 적재함이 약 +10° 넘게 돌면 옆벽으로 바꿔 잡습니다. |
| 컵은 시연을 늘렸는데요? | 규칙 시연으로 20 → 46% 가 됐고, 그다음 시연 300회와 관절 노이즈로 88% 가 됐습니다. 일관성을 맞춘 뒤에는 양도 도움이 됐습니다. |
| 빈 간격 G 는 몇 도 넘으면 나쁜가요? | 정해진 기준값은 아닙니다. 같은 물체·조건에서 시연 묶음끼리 비교하는 진단 지표입니다. |
| 성공 기준은요? | 위치 15mm, 높이 8mm, 기울기 10° 안이고, 먼저 놓은 적재함이 10mm 넘게 밀리지 않으면 성공입니다. |
| ACT 는 어떤 모델인가요? | 카메라 두 대 화면과 관절값을 보고 앞으로 100스텝의 관절 목표를 한 번에 내는 모방학습 모델입니다. 1층·옆·2층마다 따로 학습했습니다. |
