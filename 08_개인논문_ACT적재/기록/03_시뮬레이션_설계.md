# 03 시뮬레이션 설계 (2026-10-06)

실제 로봇이 파손되어 ACT 정량 평가를 MuJoCo 로 다시 한다. 실제 셀과 다른 점은 이 문서에 모두 적는다.

## 구성

| 항목 | 값 | 실제와의 관계 |
|---|---|---|
| 시뮬레이터 | MuJoCo 3.3.5 (EGL 렌더링) | — |
| 로봇 | `so101_new_calib_camera.xml` (TheRobotStudio/SO-ARM100 공식, 손목 카메라 마운트 포함), STS3215 위치 서보 파라미터 | 같은 로봇 |
| 카메라 | `front` 손목(카메라 모듈 위치, fovy 78°), `top` 위쪽 고정 (z 0.62m) / **160×120** | 실제 이름·배치와 같음. 해상도는 실제 경량 추론 설정(`act_floor1_test.py`: 160×120)과 같음 |
| 제어 | 관절 목표값 6차원(그리퍼 포함), **30Hz** (물리 600Hz × 20) | 실제 원격조작 30Hz |
| 분류 통 | 바깥 64×64×52mm, 벽 2mm, 통 33g + 큐브 9개×10g = **123g** | 크기는 출력 무게·영상으로 추정 (아래) |
| 저울 | 140×124×25mm, 중심 (0.205, −0.140) | 영상 배치 참고 |
| 적재 목표 | A (0.190, 0.100), B = A 옆 (+72mm), C = A 위 | 사용자 확인 순서 |
| 무작위화 | 저울 위 통 ±2cm·±20°, 먼저 쌓인 통 ±8mm·±5° | PiPER 일지 10/6 교훈 반영(좁으면 물체를 안 보고 평균 자리로 감) |

### 통 크기 추정

- 출력판 이름이 "Sorting Bin (print 3)", 3개에 PLA 99g → 1개 33g
- 미리보기 그림에서 같은 투영의 정육면체(큐브)와 비교한 높이/너비 ≈ 0.87
- 얇은 벽(약 1.6~2mm)을 거의 채워 출력한다고 보면 바깥 60~70mm 에서 33g 이 나옴 → 64mm, 높이 52mm 로 정함
- STL 직접 확인은 MakerWorld 로그인이 필요해 하지 못함 (사용자가 STL 을 주면 바로 바꿀 수 있게 상수로 둠)

## 스크립트 전문가 (시연 생성)

| 단계 | 내용 |
|---|---|
| 잡을 벽 | 로봇 쪽을 향한 벽. 고정 집게는 벽 바깥, 움직이는 집게는 통 안쪽 |
| 궤적 | 경유점 8개(접근 → 내려가기 → 쥐기 → 들기 → 옮기기 → 내려놓기 → 놓기 → 빠지기), 최소 저크 보간, 역기구학(감쇠 최소제곱)으로 관절값 |
| 사람다움 | 구간 속도 ±10%, 경유점 위치 흔들림(최대 ±6mm) |
| 길이 | 270스텝(9초) |
| 보관 | 성공한 시연만 (실패한 원격조작 녹화를 버리는 것과 같음) |

## 막힌 것과 해결

| # | 문제 | 원인 | 해결 | 확인 |
|---|---|---|---|---|
| 1 | `mujoco.Renderer` 없음 | MuJoCo 3.15 API 변경 | 3.3.5 로 고정 | 렌더링 정상 |
| 2 | 팔이 위로 뻗음 | 수직으로 내려 잡는 자세가 z ≤ 5cm 에서만 가능 (손목 관절 한계) | 높이에 따라 접근 방향을 0°(z≤8cm) → 30°(z=14cm) 기울임 | 아래 표 |
| 3 | 손목 카메라 화면이 검은 원 | 카메라가 카메라 부품 메쉬 안에 있음 | 시선 방향으로 22mm 앞으로 | 화면 정상 |
| 4 | 상자를 못 집음 | 기준점(`gripperframe`)이 두 집게 가운데가 아니라 **고정 집게 안쪽 면** | 잡을 위치를 그만큼 옮김 | 잡기 성공 |
| 5 | 잡으면 상자가 기울어 미끄러짐 (1층 6/10) | 고정 집게 충돌 형상이 부품 전체의 볼록 껍질이라 집게 끝(z=0)과 몸체(z=38mm) 사이가 **사선 면** | 집게 부분만 실제 집게 크기의 상자형 충돌체(패드)로 바꿈 | 큐브 10/10, 오차 2~3mm |
| 6 | 2mm 통 벽을 못 쥠 | 닫힘 한계(−0.1745 rad)에서도 패드 사이 4mm 가 남음 | 움직이는 집게 패드를 9mm 두껍게 (실제 그리퍼는 완전히 닫힘) | 통 5/5 |
| 7 | 데이터 생성 3개 동시 실행 시 충돌 | 같은 임시 파일 이름 | 프로세스별 이름 + 원자적 쓰기 | 정상 |

### 수직 접근 가능 범위 (기울기 0°, 역기구학 오차 1mm 미만이면 ok)

| 높이 z | x=0.14 | 0.18 | 0.22 | 0.26 |
|---|---|---|---|---|
| 0.06 | ok | ok | ok | ok |
| 0.08 | 4mm | ok | ok | 12mm |
| 0.10 | 28mm | 13mm | 16mm | 47mm |
| 0.12 | 57mm | 41mm | 49mm | 75mm |

30° 기울이면 z=0.14 까지 x ≥ 0.18 에서 모두 ok.
