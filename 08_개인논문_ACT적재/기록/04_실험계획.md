# 04 실험 계획 (2026-10-06)

## 무엇을 보이려 하나

1. 팀이 실제로 한 조건(단계별 모델, 시연 100회 / 200회)을 시뮬레이션에서 재현했을 때 단계별 성공률
2. 1층 → 옆 → 2층을 **이어서** 했을 때 앞 단계 오차가 뒤 단계에 얼마나 쌓이는가
3. 팀 조건보다 나아간 개선: 시연 잡음 주입(DART), 시간 앙상블(ACT 원 논문)
4. ACT 가 카메라로 통을 실제로 따라가는가 (쥔 위치 ↔ 통 위치 기울기, PiPER 10/6 분석 방식)

## 조건

| 이름 | 시연 | 학습 | 추론 | 비고 |
|---|---|---|---|---|
| `n100` | 단계별 100 | ACT 기본값 | 청크 100 그대로 실행 | 팀 1차 재현 |
| `n200` | 단계별 200 | ACT 기본값 | 같음 | 팀 2차 재현 |
| `n200+TE` | `n200` 모델 | — | 시간 앙상블 (매 스텝 추론, 계수 0.01) | 학습 없이 추론만 바꿈 |
| `dart200` | 단계별 200, 실행 동작에 상관 잡음을 넣고 정답은 원래 궤적 | ACT 기본값 | 청크 100 | 개선안 |

ACT 기본값 (LeRobot 0.3.3, 실제 시스템과 같음): ResNet18(ImageNet 사전학습), d_model 512, 인코더 4층, 디코더 1층, CVAE 잠재 32, KL 가중치 10, chunk 100, AdamW lr 1e-5, weight decay 1e-4, 배치 8.

## 평가

| 프로토콜 | 내용 | 횟수 |
|---|---|---|
| 단계별 | 앞 단계 통을 목표 ±8mm 에 미리 두고 해당 단계 모델만 실행 | 단계당 50 |
| 연속 | 1층 → 옆 → 2층 모델을 같은 장면에서 이어서 실행, 실행 뒤마다 홈 복귀 (실제 RETURN_HOME 과 같음) | 50 시퀀스 |

- 평가 시드 500000번대, 시연 시드(1000번대 + 단계×100000)와 겹치지 않음
- 실행 길이 270스텝(9초) → 홈 복귀 1초 → 안정화 0.5초 → 판정
- 성공 기준: [03_시뮬레이션_설계.md](03_시뮬레이션_설계.md) 마지막 절
- 기록: 성공/실패, 위치 오차, 기울기, 밀린 통, 추론 시간, 처음 3회 GIF

## 장비 조건

- PC: GTX 1080 Ti 11GB. **같은 PC 에서 PiPER 실험이 GPU 를 함께 씀** → 제 작업은 `nice` 로 낮은 우선순위, 영상은 디스크에서 읽어 메모리 절약 (사용자 결정 10/6)
- 그래서 학습 속도는 공유 상태 기준 약 3.2 스텝/초. 추론 시간 수치는 공유 GPU 값이라 논문에 그대로 쓰지 않는다
