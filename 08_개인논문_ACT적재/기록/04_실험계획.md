# 04 실험 계획 (2026-10-06, 같은 날 갱신)

## 무엇을 보이려 하나

1. 팀이 실제로 한 조건(단계별 모델, 시연 100회 / 200회)을 시뮬레이션에서 재현했을 때의 단계별 성공률
2. **팀보다 나아가기 ①** 시연을 500·1000회로 늘리면 얼마나 좋아지는가 (사용자 제안 10/6)
3. 1층 → 옆 → 2층을 **이어서** 했을 때 앞 단계 오차가 뒤 단계에 얼마나 쌓이는가
4. **팀보다 나아가기 ②** 시연 잡음 주입(DART), 시간 앙상블(ACT 원 논문)
5. ACT 가 카메라로 통을 실제로 따라가는가 (쥔 위치 ↔ 통 위치 기울기, PiPER 10/6 분석 방식)

## 모방학습인가?

그렇다. 바뀐 것은 시연자뿐이다.

| | 실제 시스템 | 시뮬레이션 |
|---|---|---|
| 시연자 | 사람이 리더암 조작 | 스크립트 전문가 (시뮬레이터의 통 위치를 알고 역기구학으로 계획) |
| 기록 | 팔로워 관절값 + 손목·상단 영상 + 동작 | 같음 |
| 학습 | LeRobot 0.3.3 ACT | 같음 |
| 평가 때 제어 | ACT 만 | ACT 만 (스크립트 개입 없음, 통 위치를 모름) |

실제 원격조작 데이터는 남아 있지 않다 (Hugging Face 의 팀원·사용자 계정에 공개 데이터셋 0개, 10/6 확인).

## 조건

| 이름 | 시연 (단계별) | 학습 | 추론 | 비고 |
|---|---|---|---|---|
| `n100` | 100 | ACT 기본값, 30,000스텝 | 청크 100 그대로 | 팀 1차 재현 |
| `n200` | 200 | 같음 | 같음 | 팀 2차 재현 |
| `n500` | 500 | 같음 | 같음 | 확장 |
| `n1000` | 1000 | 같음 | 같음 | 확장 |
| `n200_te` | `n200` 모델 | — | 시간 앙상블 (매 스텝 추론, 계수 0.01) | 추론만 바꿈 |
| `n100_k25` 등 | 학습된 모델 | — | 25스텝마다 다시 계획 | 추론만 바꿈 (n100: 효과 없음) |
| `dart1000` | 1000, 실행 동작에 OU 잡음(σ=0.005rad), 정답은 원래 궤적 | 같음 | 청크 100 | **최종 제안** (10/7 추가) |
| `dart200` | 200, 같은 잡음 | 같음 | 청크 100 | 데이터가 적을 때 DART 효과 |

- 시연 집합은 겹쳐 쓴다: 100 ⊂ 200 ⊂ 500 ⊂ 1000 (데이터 양만 달라지게)
- 학습 스텝은 모두 30,000 으로 같다 (같은 계산량에서 데이터 양 비교). 10,000·20,000 스텝 체크포인트도 평가해 학습 곡선을 본다
- ACT 기본값 (실제 시스템과 같음): ResNet18(ImageNet 사전학습), d_model 512, 인코더 4층, 디코더 1층, CVAE 잠재 32, KL 10, chunk 100, AdamW lr 1e-5, weight decay 1e-4, 배치 8

## 평가

| 프로토콜 | 내용 | 횟수 |
|---|---|---|
| 단계별 | 앞 단계 통을 목표 ±8mm 에 미리 두고 해당 단계 모델만 실행 | 단계당 50 |
| 연속 | 1층 → 옆 → 2층 모델을 같은 장면에서 이어서, 실행마다 홈 복귀 (실제 RETURN_HOME 과 같음) | 50 시퀀스 |

- 평가 시드 500000번대 (시연 시드 1000·3000·5000번대와 겹치지 않음)
- 실행 270스텝(9초) → 홈 복귀 1초 → 안정화 0.5초 → 판정
- 성공 기준: [03_시뮬레이션_설계.md](03_시뮬레이션_설계.md) 마지막 절
- 기록: 성공/실패, 위치 오차, 기울기, 밀린 통, 추론 시간, 쥔 위치(따라가기 기울기), 처음 3회 GIF

## 장비 조건

- GTX 1080 Ti 11GB 를 **PiPER 학습과 함께 사용** → 제 작업은 `nice` 로 낮은 우선순위 (사용자 결정 10/6)
- `/home` 이 하드디스크라, 학습은 시연 48개를 메모리에 올려 두고 2스텝마다 하나씩 순차로 바꿔 읽는다
- 공유 GPU 라 추론 시간 수치는 논문에 쓰지 않는다
