# 포스터 로고

| 파일 | 내용 | 출처 |
|---|---|---|
| `ieie_logo_white.png` | 대한전자공학회 정식 로고, 흰색, 투명 배경, 2080 × 510 | 학회 공식 브로셔 표지 (https://www.theieie.org/download/brochure_kor_20260109.pdf), 401 × 85 px 부분을 5배로 매끄럽게 키움 |
| `kmu_signature_kor.png` | 계명대학교 교표(방패형) 시그니처 기본형, 좌우 조합, 한글, 1654 × 295 | 계명대 홈페이지 → 학교소개 → 계명상징 → 로고마크 자료실, "교표(방패형) 시그니춰 기본형(좌우조합) 한글" 2000 px JPG 에서 흰 여백만 잘라 냄 |

- 만들기: `python3 -I ../logos_prep.py <브로셔 표지 JPEG> <계명대 JPG> . <미리보기 폴더>`
  (브로셔 표지 JPEG 는 `pdfimages -j -f 1 -l 1 brochure_kor_20260109.pdf cover` 로 꺼냄)
- 두 로고 모두 학회 발표용 포스터에만 씀. 계명대 자료실 안내: 상업적 무단 사용 금지.
- 학회 로고를 더 선명하게 하려면 학회 사무국에 원본(AI) 파일을 요청할 수 있음.
