# 결과물

모델과 성공률을 한곳에 모았다. 실험 과정은 [03_일지](../03_일지/README.md), 코드 사본은 [04_실습/05_libero/코드](../04_실습/05_libero/코드).

| 폴더 | 내용 | 상태 |
|---|---|---|
| [PiPER](PiPER/README.md) | 연구실 실물 팔(WeGo Robotics 공급 AgileX PiPER)의 디지털 트윈. 색 블록 장면 (10/4 ~ 10/24), 여러 모양·N개 장면 (10/24 ~) | **진행 중** (모든 설정에서 95% 가 목표) |
| [Panda](Panda/README.md) | LIBERO 시뮬레이터의 Franka Panda. 모델 v1~v6c3, 항목별 성공률, 시범 프로그램 100장면 | 기록용으로 끝 (최종 모델 v6c3, 10/3) |

성공률은 모두 **학습에 안 쓴 새 배치**(장면 1000번대) 기준이 정식 값이다. 그 전 값(장면 20~49)은 학습 배치와 겹쳐 부풀려진 값이라 따로 표시했다.
