# Franka Emika Panda 제원

시뮬레이션(LIBERO-Goal)에서 지금까지 쓴 로봇팔이다. 연구실에는 없다.

## 공식 사양 (Franka Emika PANDA Datasheet, 2019-05)

출처: [Panda Datasheet PDF](https://www.wiredworkers.io/wp-content/uploads/2019/12/Panda_FrankaEmika_ENG.pdf) (본문에서 직접 확인)

| 항목 | 값 |
|---|---|
| 자유도 | 7 (관절 7개, 모두 회전) |
| 가반하중 | 3 kg |
| 최대 도달 거리 | 855 mm |
| 무게 | 약 17.8 kg (움직이는 부분 약 12.8 kg) |
| 반복 정밀도 | ±0.1 mm 이내 (ISO 9283) |
| 경로 오차 | ±1.25 mm 이내 |
| 손끝 최대 속도 | 2 m/s |
| 관절 속도 한계 | A1~A4 150 °/s, A5~A7 180 °/s |
| 힘 감지 | 7개 관절 모두 토크 센서 |
| 제어 주기 | 1 kHz |
| 설치 | 바로 세움, 플랜지 DIN ISO 9409-1-A50 |
| 소비 전력 | 최대 약 350 W (보통 약 60 W) |

관절 범위 (데이터시트)

| 관절 | 범위 |
|---|---|
| A1, A3, A5, A7 | −166° ~ +166° |
| A2 | −101° ~ +101° |
| A4 | −176° ~ −4° |
| A6 | −1° ~ +215° |

그리퍼 (Franka Hand): 두 손가락 평행 그리퍼, 벌어지는 폭 80 mm (손가락 하나당 40 mm). 시뮬레이터 모델에서도 손가락 범위 0~40 mm로 확인했다.

## 우리 연구에서 Panda 때문에 생긴 것들

- 손목 관절(A7) 한계 ±166° 때문에 그릇을 다시 집을 때 손목이 한계에 걸린 적이 있다 → 시범 프로그램이 그리퍼의 180° 대칭을 이용해 덜 도는 쪽을 고른다 (`task_experts._aim`)
- 팔이 길어(855 mm) LIBERO 책상의 모든 물체·캐비닛·선반에 손이 닿는다
