# 부록. 텐서플로우 (TensorFlow) 기초부터

> **먼저 알아둘 것**: 로봇 VLA 연구는 대부분 **PyTorch**로 되어 있습니다(LeRobot, SmolVLA, OpenVLA, pi0의 PyTorch 포팅 등).
> 그래도 텐서플로우를 알아야 하는 이유가 있습니다.

| 이유 | 설명 |
|---|---|
| **수업·과제** | 학교 강의나 기업 과제에서 여전히 많이 씀 |
| **로봇 데이터 형식** | **Open X-Embodiment(OXE)** 데이터가 **RLDS/TFDS**(텐서플로우 데이터셋) 형식 |
| **일부 모델** | RT-1, RT-2, Octo 계열은 TensorFlow/JAX 기반 |
| **배포** | TensorFlow Lite로 엣지 기기에 올리기 쉬움 |
| **취업** | 실무에서 TF를 쓰는 회사가 많음 |

## 2. 핵심 개념

### 2-1. 텐서 (Tensor)

```python
import tensorflow as tf

a = tf.constant([[1., 2.], [3., 4.]])   # 변하지 않는 값
b = tf.Variable([[1., 1.], [1., 1.]])   # 학습되는 값 (가중치)

print(a.shape)     # (2, 2)
print(a.dtype)     # float32
print(a @ b)       # 행렬곱
print(tf.reduce_mean(a))   # 평균
```

**PyTorch와 비교**

| 항목 | PyTorch | TensorFlow |
|---|---|---|
| 텐서 생성 | `torch.tensor([1,2])` | `tf.constant([1,2])` |
| 학습 파라미터 | `nn.Parameter` | `tf.Variable` |
| 차원 순서(이미지) | (B, **C**, H, W) | (B, H, W, **C**) ← **다름! 주의** |
| GPU 이동 | `.to('cuda')` | 자동 배치 |
| 평균 | `x.mean()` | `tf.reduce_mean(x)` |

> ⭐ **채널 순서가 다릅니다.** PyTorch는 채널이 앞(NCHW), TF는 채널이 뒤(NHWC). 두 프레임워크 사이에 데이터를 옮길 때 가장 많이 하는 실수입니다.

### 2-2. 자동 미분 — GradientTape

PyTorch의 `backward()`에 해당합니다.

```python
x = tf.Variable(3.0)

with tf.GradientTape() as tape:
    y = x ** 2 + 2 * x          # y = x^2 + 2x

grad = tape.gradient(y, x)      # dy/dx = 2x + 2 = 8
print(grad)
```

**PyTorch와 비교**

```python
# PyTorch
loss.backward()
optimizer.step()
optimizer.zero_grad()

# TensorFlow
with tf.GradientTape() as tape:
    loss = compute_loss()
grads = tape.gradient(loss, model.trainable_variables)
optimizer.apply_gradients(zip(grads, model.trainable_variables))
```

### 2-3. 즉시 실행 vs 그래프

| 모드 | 설명 |
|---|---|
| **Eager (즉시 실행)** | TF2의 기본. 파이썬처럼 한 줄씩 실행되어 디버깅이 쉬움 |
| **Graph (`@tf.function`)** | 함수를 그래프로 컴파일해 **훨씬 빠름** |

```python
@tf.function          # 이 한 줄로 속도가 크게 오름
def train_step(x, y):
    with tf.GradientTape() as tape:
        pred = model(x, training=True)
        loss = loss_fn(y, pred)
    grads = tape.gradient(loss, model.trainable_variables)
    optimizer.apply_gradients(zip(grads, model.trainable_variables))
    return loss
```

⚠️ `@tf.function` 안에서는 **파이썬 print나 조건문이 예상과 다르게 동작**할 수 있습니다. 디버깅할 때는 잠시 빼고 확인하세요.

## 3. Keras — 모델 만들기

TF2에서는 **Keras**가 공식 고수준 API입니다. PyTorch의 `nn.Module`에 해당합니다.

### 3-1. Sequential (가장 간단)

```python
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),
    layers.Conv2D(32, 3, activation='relu'),
    layers.MaxPooling2D(),
    layers.Flatten(),
    layers.Dense(128, activation='relu'),
    layers.Dense(10),
])
model.summary()
```

### 3-2. 함수형 API (분기가 있을 때)

```python
inputs = keras.Input(shape=(224, 224, 3))
x = layers.Conv2D(32, 3, activation='relu')(inputs)
x = layers.GlobalAveragePooling2D()(x)
outputs = layers.Dense(7)(x)          # 동작 7차원 출력
model = keras.Model(inputs, outputs)
```

### 3-3. 서브클래싱 (PyTorch와 가장 비슷)

```python
class ActionHead(keras.Model):
    def __init__(self, action_dim=7):
        super().__init__()
        self.fc1 = layers.Dense(256, activation='relu')
        self.fc2 = layers.Dense(action_dim)

    def call(self, x, training=False):
        x = self.fc1(x)
        return self.fc2(x)
```

### 3-4. 학습 — 두 가지 방법

**방법 1: `fit()` (간단)**

```python
model.compile(optimizer='adam',
              loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
              metrics=['accuracy'])
model.fit(train_ds, epochs=5, validation_data=val_ds)
model.evaluate(test_ds)
```

**방법 2: 직접 루프 (PyTorch 방식과 동일, 연구에 유리)**

```python
optimizer = keras.optimizers.Adam(1e-4)
loss_fn = keras.losses.MeanAbsoluteError()      # 로봇 동작은 L1을 자주 씀

@tf.function
def train_step(x, y):
    with tf.GradientTape() as tape:
        pred = model(x, training=True)
        loss = loss_fn(y, pred)
    grads = tape.gradient(loss, model.trainable_variables)
    optimizer.apply_gradients(zip(grads, model.trainable_variables))
    return loss

for epoch in range(10):
    for x, y in train_ds:
        loss = train_step(x, y)
    print(f"epoch {epoch} loss {float(loss):.4f}")
```

### 3-5. 콜백과 저장

```python
callbacks = [
    keras.callbacks.ModelCheckpoint('best.keras', save_best_only=True),
    keras.callbacks.EarlyStopping(patience=5),
    keras.callbacks.TensorBoard(log_dir='./logs'),
]
model.save('my_model.keras')
loaded = keras.models.load_model('my_model.keras')
```


## 4. tf.data — 데이터 파이프라인

⭐ **로봇 데이터를 다룰 때 실제로 쓰게 되는 부분입니다.**

```python
ds = tf.data.Dataset.from_tensor_slices((images, actions))
ds = (ds
      .shuffle(1000)
      .map(preprocess, num_parallel_calls=tf.data.AUTOTUNE)
      .batch(32)
      .prefetch(tf.data.AUTOTUNE))      # 학습 중에 다음 배치를 미리 준비
```

| 함수 | 역할 |
|---|---|
| `map` | 전처리 (크기 조정, 정규화) |
| `shuffle` | 섞기 (버퍼 크기 주의) |
| `batch` | 배치 묶기 |
| `prefetch` | 미리 읽어두기 → **GPU가 노는 시간 감소** |
| `cache` | 메모리/디스크에 캐시 |
| `interleave` | 여러 파일을 번갈아 읽기 |

**TFRecord** — TF의 표준 저장 형식(대용량 데이터에 사용)

```python
raw = tf.data.TFRecordDataset(['data-00000.tfrecord'])
```

## 5. ⭐ 로봇 데이터와 TensorFlow — RLDS / TFDS

**Open X-Embodiment(OXE)** 같은 대규모 로봇 데이터셋이 **RLDS** 형식으로 배포되고, 이건 **TFDS(TensorFlow Datasets)** 위에 만들어져 있습니다. 그래서 **PyTorch로 연구해도 데이터를 읽을 때 TF가 필요할 수 있습니다.**

```python
import tensorflow_datasets as tfds

ds = tfds.load('bridge', split='train')      # 데이터셋 이름은 예시
for episode in ds.take(1):
    for step in episode['steps']:
        image = step['observation']['image']
        action = step['action']
        instruction = step['language_instruction']
```

**RLDS의 구조**

```
dataset
└─ episode (에피소드 한 번의 시연)
   └─ steps (시간 순서)
      ├─ observation : image, state
      ├─ action      : 로봇 동작
      ├─ reward, is_terminal
      └─ language_instruction : "빨간 블록을 컵에 넣어"
```

**실습**: OXE 데이터셋 하나를 받아서 **에피소드 1개를 뜯어보고**, 이미지 몇 장을 저장하고 동작 값의 범위를 확인해보세요. 로봇 데이터가 어떻게 생겼는지 감이 잡힙니다.

## 7. PyTorch ↔ TensorFlow 대조표

| 개념 | PyTorch | TensorFlow |
|---|---|---|
| 모델 정의 | `class Net(nn.Module)` | `class Net(keras.Model)` |
| 순전파 함수 | `forward()` | `call()` |
| 학습 모드 | `model.train()` | `training=True` 인자 |
| 미분 | `loss.backward()` | `tape.gradient(loss, vars)` |
| 갱신 | `optimizer.step()` | `optimizer.apply_gradients()` |
| 기울기 초기화 | `optimizer.zero_grad()` | 불필요 (tape가 매번 새로) |
| 데이터 | `DataLoader` | `tf.data.Dataset` |
| 저장 | `torch.save(state_dict)` | `model.save('m.keras')` |
| 이미지 차원 | (B, C, H, W) | (B, H, W, C) |
| 속도 최적화 | `torch.compile` | `@tf.function` |
| 시각화 | TensorBoard / W&B | TensorBoard |

## 8. 실습 과제

1. **텐서 연습** — 생성, 형변환, 브로드캐스팅, `reduce_*` 함수들
2. **GradientTape로 선형회귀** — `y = 2x + 3`의 계수를 찾기
3. **MNIST 분류기** — `fit()` 버전과 **직접 루프** 버전 둘 다 작성
4. **`@tf.function` 유무 속도 비교** — 몇 배 차이나는지 측정
5. **tf.data 파이프라인** — `prefetch` 유무에 따른 학습 시간 비교
6. ⭐ **OXE/RLDS 데이터 열어보기** — 에피소드 구조 출력, 이미지 저장, 동작 범위 확인
7. **동작 회귀 모델** — 이미지를 넣으면 7차원 동작이 나오는 작은 CNN 만들기 (VLA의 축소판)
8. **TFLite 변환** — 모델 크기와 추론 시간 비교
