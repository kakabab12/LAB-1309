## 1. 영어 논문 읽기

### 현실적인 방법

1. **초록은 원문으로** 읽기 (5~6문장뿐입니다)
2. 본문은 **번역기와 원문을 나란히** 놓고
3. 모르는 단어는 그때그때 [용어사전](../용어사전.md)에 추가
4. 하루 **초록 1개**씩만 해도 3개월이면 90개

### 논문에 자주 나오는 표현

| 표현 | 뜻 |
|---|---|
| We propose / We introduce | 우리는 ~을 제안한다 |
| To the best of our knowledge | 우리가 아는 한 (= 최초라는 주장) |
| state-of-the-art (SOTA) | 현재 최고 성능 |
| baseline | 비교 대상이 되는 기존 방법 |
| ablation study | 구성 요소를 하나씩 빼보는 실험 |
| We observe that | 실험해보니 ~이더라 |
| This suggests that | 이는 ~을 시사한다 |
| However / Nevertheless | 그러나 (여기서 한계를 말함) |
| in-domain / out-of-distribution | 학습한 범위 안 / 밖 |
| zero-shot / few-shot | 학습 없이 / 몇 개만 보고 |
| We leave this to future work | 이건 안 했다 (= **연구 아이디어 창고**) |

⭐ **"Limitation"과 "Future work"가 논문에서 가장 값진 부분**입니다. 여기에 다음 연구 주제가 있습니다.

### 논문 찾는 곳

| 사이트 | 용도 |
|---|---|
| **arXiv** | 최신 논문 (심사 전 포함) |
| **Google Scholar** | 인용 수, 관련 논문 |
| **Semantic Scholar** | AI 요약, 인용 관계 그래프 |
| **Papers with Code** | 논문 + 코드 + 벤치마크 순위 |
| **OpenReview** | 심사 의견까지 볼 수 있음 (ICLR 등) |
| **Hugging Face Papers** | 매일 화제 논문 |
| **awesome-* GitHub 목록** | 분야별 논문 모음 (예: Awesome-VLA-Papers) |

## 3. LaTeX / Overleaf

논문·보고서는 거의 전부 LaTeX으로 씁니다. **Overleaf**(웹)로 시작하면 설치가 필요 없어요.

### 최소한 알아야 할 문법

```latex
\documentclass{article}
\usepackage{kotex}          % 한글
\usepackage{graphicx, booktabs, amsmath}

\begin{document}
\title{태스크 도중 지시 전환}
\author{이지용}
\maketitle

\section{서론}
본문입니다. 인용은 이렇게 합니다~\cite{smolvla}.

\subsection{수식}
인라인 수식은 $y = Wx + b$ 이고, 따로 쓰면:
\begin{equation}
    \text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V
\end{equation}

\subsection{그림과 표}
\begin{figure}[t]
    \centering
    \includegraphics[width=0.8\linewidth]{figure1.pdf}
    \caption{전체 구조.}
    \label{fig:overview}
\end{figure}

그림~\ref{fig:overview}에서 보듯이...

\begin{table}[t]
\centering
\begin{tabular}{lcc}
\toprule
방법 & 성공률 & 저크 \
\midrule
그냥 교체 & 0.42 & 2116 \
블렌딩 & \textbf{0.71} & \textbf{302} \
\bottomrule
\end{tabular}
\caption{전환 방법 비교.}
\end{table}

\bibliographystyle{plain}
\bibliography{refs}
\end{document}
```

**연습 과제**: 이번 주 주간 일지를 LaTeX으로 써보기. 표 1개, 수식 1개, 그림 1개 넣기.

## 4. 그림 그리기

**논문에서 그림 1장이 본문 1쪽보다 중요합니다.**

| 용도 | 도구 |
|---|---|
| 구조도, 흐름도 | **draw.io**(무료, 웹), Inkscape, PowerPoint |
| 그래프 | **matplotlib**, seaborn |
| 로봇 궤적 | matplotlib 3D |
| 영상 캡처 편집 | GIMP, ffmpeg |

**그래프 규칙**
- 축 이름 + 단위 반드시
- 폰트 크기는 본문과 비슷하게 (논문에 넣으면 작아짐)
- **흑백 인쇄해도 구분되게** (색 + 선모양 같이)
- 벡터 형식(PDF, SVG)으로 저장 → 확대해도 안 깨짐

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(4, 3))
ax.plot(delays, success_wait,  'o-',  label='그냥 교체')
ax.plot(delays, success_blend, 's--', label='블렌딩')
ax.set_xlabel('추론 지연 (ms)'); ax.set_ylabel('전환 성공률')
ax.legend(); fig.tight_layout()
fig.savefig('result.pdf')        # 벡터로 저장
```

## 6. 재현성 — 나중의 나를 위한 것

**3개월 뒤의 나는 지금의 나를 기억하지 못합니다.**

| 할 것 | 방법 |
|---|---|
| 난수 고정 | `seed`를 코드에 인자로 |
| 환경 고정 | `pip freeze > requirements.txt` |
| 코드 버전 | 실험 결과에 **git commit 해시** 기록 |
| 실험 기록 | Weights & Biases 또는 TensorBoard |
| 실행 명령 | 로그 파일 맨 앞에 명령어 그대로 저장 |

```python
import subprocess, json, time

def save_run_info(args, path='run_info.json'):
    info = {
        'time': time.strftime('%Y-%m-%d %H:%M'),
        'git': subprocess.getoutput('git rev-parse --short HEAD'),
        'args': vars(args) if hasattr(args, '__dict__') else args,
    }
    json.dump(info, open(path, 'w'), indent=2, ensure_ascii=False)
```

## 7. Git 협업

혼자 쓸 때와 다릅니다.

```bash
git checkout -b feature/blend-strategy    # 브랜치 만들고 작업
git add -p                                 # 바뀐 부분을 골라서 담기
git commit -m "전환 블렌딩 구현"
git push -u origin feature/blend-strategy  # 올리고 PR 만들기
```

**커밋 메시지**: "무엇을 왜 바꿨는지" 한 줄. `수정`, `ㅇㅇ` 같은 건 나중에 자기가 못 알아봅니다.

**.gitignore에 꼭 넣을 것**

```

*.pt
*.ckpt
outputs/
data/
wandb/
```

⚠️ **큰 파일(모델, 데이터)을 git에 올리지 마세요.** 저장소가 망가집니다.
