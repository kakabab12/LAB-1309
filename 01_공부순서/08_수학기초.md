## 1. 선형대수

### 알아야 할 것

| 개념 | 이해할 수준 | VLA/로봇 어디에 쓰이나 |
|---|---|---|
| 벡터, 행렬 | 덧셈, 스칼라배 | 모든 데이터 |
| **행렬곱** | 차원이 맞는 규칙 `(a,b) @ (b,c) = (a,c)` | attention, 모든 신경망 층 |
| 전치 | 행과 열 바꾸기 | `k.transpose(-2,-1)` |
| **내적(dot product)** | 두 벡터가 얼마나 같은 방향인가 | attention 점수 = Q와 K의 내적 |
| **노름(norm)** | L1(절대값 합), L2(제곱합 루트) | 손실 함수, 거리 계산 |
| 역행렬, 의사역행렬 | 개념만 | 역기구학 풀이 |
| **직교행렬** | 회전행렬은 직교행렬 | 로봇 회전 표현 |
| 고유값, SVD | 개념만 | PCA, 차원 축소 |
| **야코비안** | 관절 속도 → 끝단 속도 변환 | 로봇 제어, 특이점 |

### 실습

`math01_linalg.py`

```python
import numpy as np

# 행렬곱 차원 규칙 (딥러닝 버그의 90%가 여기)
A = np.random.randn(4, 3)
B = np.random.randn(3, 5)
print((A @ B).shape)        # (4, 5)

# 내적 = 방향의 유사도
a = np.array([1, 0]); b = np.array([1, 0]); c = np.array([0, 1])
print(a @ b, a @ c)          # 1(같은 방향), 0(수직)

# 코사인 유사도 (CLIP이 이미지와 텍스트를 비교하는 방식)
def cos_sim(x, y):
    return (x @ y) / (np.linalg.norm(x) * np.linalg.norm(y))
print(cos_sim(np.array([1., 1.]), np.array([2., 2.])))    # 1.0

# 노름
v = np.array([3., -4.])
print(np.abs(v).sum(), np.linalg.norm(v))       # L1=7, L2=5

# 회전행렬은 직교행렬: R @ R.T = I, det(R) = 1
th = np.pi / 6
R = np.array([[np.cos(th), -np.sin(th)], [np.sin(th), np.cos(th)]])
print((R @ R.T).round(6))          # 단위행렬
print(np.linalg.det(R).round(6))   # 1.0
```

**attention과 연결해서 이해하기**

```
scores = Q @ K^T     <- 모든 토큰 쌍의 "내적" = 유사도 행렬
       / sqrt(d)     <- 차원이 커지면 내적 값이 커져서 나눠줌
softmax              <- 유사도를 확률로
@ V                  <- 확률로 가중평균
```

## 2. 확률과 통계

### 알아야 할 것

| 개념 | 어디에 쓰이나 |
|---|---|
| 확률변수, 분포 | 모델 출력이 분포일 때 |
| **기대값, 분산, 표준편차** | 실험 결과 보고 |
| **가우시안(정규분포)** | diffusion의 노이즈, 초기화 |
| 조건부확률, 베이즈 | 정책 = p(동작 \| 관측, 지시) |
| **최대우도(MLE)** | MSE 손실이 왜 그 형태인지의 근거 |
| KL divergence | 분포 간 거리 (VAE, 정책 학습) |
| **표준오차, 신뢰구간** | ⭐ **"몇 번 반복해야 하나"의 답** |

### ⭐ 실험 설계에 바로 쓰는 통계

`math02_stats.py`

```python
import numpy as np

def success_rate_ci(successes, trials, z=1.96):
    """성공률의 95% 신뢰구간 (정규 근사)."""
    p = successes / trials
    se = np.sqrt(p * (1 - p) / trials)
    return p, (max(0, p - z*se), min(1, p + z*se))

for n in [10, 30, 100, 400]:
    p, (lo, hi) = success_rate_ci(int(0.8*n), n)
    print(f"{n:4d}회 시도, 성공률 80% -> 95% 신뢰구간 [{lo:.2f}, {hi:.2f}]  폭 {hi-lo:.2f}")
```

출력 예시

```
  10회 시도, 성공률 80% -> 95% 신뢰구간 [0.55, 1.00]  폭 0.45
  30회 -> 폭 0.29
 100회 -> 폭 0.16
 400회 -> 폭 0.08
```

⭐ **이게 "에피소드를 몇 번 돌려야 하나"의 답입니다.**
두 방법의 성공률 차이가 5%p라면, 10번 돌려서는 **절대 구분할 수 없습니다.** 최소 수백 번이 필요해요.

### 가우시안과 diffusion

```python
# diffusion은 "정답에 가우시안 노이즈를 섞고, 거꾸로 걷어내는 법"을 배운다
x0 = np.array([0.5, -0.2, 0.1])            # 정답 동작
for t in [0.0, 0.3, 0.7, 1.0]:
    noisy = (1-t) * x0 + t * np.random.randn(3)     # 점점 노이즈로
    print(f"t={t}: {noisy.round(2)}")
```

⭐ **flow matching**은 이 "노이즈 → 정답" 경로를 **직선에 가깝게** 만들어 적은 단계로 복원하는 방식입니다.

## 3. 미적분

| 개념 | 이해할 수준 |
|---|---|
| 미분 | 순간 변화율, 접선의 기울기 |
| **연쇄법칙** | ⭐ 역전파의 전부 |
| 편미분 | 여러 변수 중 하나만 볼 때 |
| 기울기(gradient) | 가장 가파르게 증가하는 방향 |
| 2차 미분 | 가속도. 3번 미분하면 **저크** |

`math03_calculus.py`

```python
import numpy as np

# 수치미분 vs 자동미분 비교
def f(x): return x**3 + 2*x

x0, h = 2.0, 1e-5
num = (f(x0+h) - f(x0-h)) / (2*h)      # 수치미분
ana = 3*x0**2 + 2                       # 손으로 푼 답
print(f"수치 {num:.6f}  해석 {ana:.6f}")

import torch
xt = torch.tensor(2.0, requires_grad=True)
(xt**3 + 2*xt).backward()
print(f"자동미분 {xt.grad.item():.6f}")     # 같은 값

# 연쇄법칙: y = (3x+1)^2  ->  dy/dx = 2(3x+1)*3
xt2 = torch.tensor(1.0, requires_grad=True)
y = (3*xt2 + 1)**2
y.backward()
print(f"연쇄법칙 {xt2.grad.item()} (손계산 {2*(3*1+1)*3})")
```

## 4. 최적화

| 개념 | 내용 |
|---|---|
| **경사하강법** | 기울기 반대 방향으로 조금씩 이동 |
| 학습률 | 얼마나 크게 움직일지. 크면 발산, 작으면 느림 |
| 모멘텀 | 이전 방향을 관성처럼 유지 |
| **Adam/AdamW** | 파라미터마다 학습률을 자동 조절. 기본값으로 씀 |
| 국소 최소 | 진짜 최솟값이 아닌 곳에 갇힘 |
| 학습률 스케줄 | warmup 후 cosine으로 감소 (VLA 학습에 거의 항상 사용) |

`math04_optim.py`

```python
import numpy as np

def f(x): return x**2          # 최솟값은 x=0
def grad(x): return 2*x

for lr in [0.01, 0.1, 0.9, 1.1]:
    x = 5.0
    for _ in range(30):
        x = x - lr * grad(x)
    print(f"lr={lr:4.2f} -> x={x:.4f}  {'발산!' if abs(x) > 10 else ''}")
```

⭐ **lr=1.1에서 발산하는 것**을 눈으로 보세요. 학습이 NaN이 되는 이유가 이겁니다.
