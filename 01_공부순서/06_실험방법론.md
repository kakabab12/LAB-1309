# 6단계. 실험 방법론 (계속 반복)

> 논문이 되려면 **"제대로 비교했는가"**가 핵심입니다. 결과보다 **방법이 공정한가**를 먼저 보게 됩니다.

## 6-1. 좋은 실험의 조건

| 조건 | 뜻 |
|---|---|
| **재현 가능** | 같은 seed, 같은 설정으로 다시 하면 같은 결과 |
| **공정한 비교** | 비교하는 방법들끼리 **한 가지만 다름** |
| **충분한 반복** | 우연이 아님을 보일 만큼 반복 |
| **정직한 보고** | 잘 된 것만 고르지 않기 |

## 6-2. 변수 통제

**바꾸는 것(독립변수)은 한 번에 하나만**

| 종류 | 예시 |
|---|---|
| 독립변수 | 전환 방법(그냥 교체 / 블렌딩 / 학습), 전환 시점, 추론 지연 |
| 종속변수 | 성공률, 반응 시간, jerk, 낙하율 |
| 통제변수 | seed, 초기 물체 배치, 모델 체크포인트, `n_action_steps`, 카메라 설정 |

⚠️ 흔한 실수: 방법도 바꾸고 설정값도 같이 바꿔서 **무엇 때문에 좋아졌는지 모르게 되는 것**

## 6-3. seed와 초기 상태

- 시뮬레이션은 **초기 물체 위치가 매번 다릅니다**
- 두 방법을 비교하려면 **같은 초기 상태**에서 각각 돌려야 공정합니다
- LIBERO는 초기 상태를 고정하는 옵션(`--env.init_states=true`)이 있습니다
- 시드는 최소 **3개 이상**으로 돌려 평균과 편차를 보고

## 6-4. 반복 횟수

| 태스크당 에피소드 | 신뢰도 |
|---|---|
| 3회 | 작동 확인용 |
| 10회 | 표준 (LIBERO 권장) |
| 20~50회 | 차이가 작을 때 |

- 성공률 차이가 5%p 이내면 **반복을 늘려야** 의미가 있습니다
- 평균만 쓰지 말고 **표준편차나 신뢰구간**을 같이 보고하세요

## 6-5. ablation study (제거 실험)

**"내가 만든 것 중 어느 부분이 실제로 효과가 있나"**를 보이는 실험입니다.

예시:

| 조건 | 블렌딩 | 전환 데모 학습 | 성공률 |
|---|---|---|---|
| 기본 (그냥 교체) | ❌ | ❌ | ? |
| + 블렌딩만 | ✅ | ❌ | ? |
| + 학습만 | ❌ | ✅ | ? |
| 전체 | ✅ | ✅ | ? |

이 표가 있으면 **기여가 분명해집니다.**

## 6-6. 실패 분석 (⭐ 이 연구에서 특히 중요)

성공률만 보고하면 정보가 적습니다. **어떻게 실패했는지 분류**하세요.

| 실패 유형 | 설명 |
|---|---|
| 지시 무시 | 이전 태스크를 계속함 |
| 얼어붙음 | 아무것도 안 함 |
| 물체 낙하 | 들고 있던 것을 떨어뜨림 |
| 급격한 동작 | 튀거나 진동 |
| 잘못된 대상 | 다른 물체를 잡음 |
| 시간 초과 | 완료하지 못함 |

→ 영상을 보면서 라벨을 붙이고 **막대그래프**로 만들면 좋은 그림이 됩니다.

## 6-7. 실험 기록

**남겨야 할 것**

```
실험 ID, 날짜
├─ 환경: GPU, PyTorch/LeRobot 버전, 커밋 해시
├─ 설정: 모델 경로, n_action_steps, seed, 에피소드 수
├─ 결과: 성공률, 반응 시간, jerk, 실패 유형 분포
└─ 산출물: 로그 파일, 영상, 그래프
```

**도구**
- **Weights & Biases** 또는 **TensorBoard**: 학습 곡선과 지표 자동 기록
- `git commit` 해시를 실험 기록에 남기기 → 코드 버전 추적
- 표는 CSV로 저장 → 나중에 그래프 자동 생성

> 인턴 때 개발 일지를 쓰셨던 방식이 그대로 강점이 됩니다. **"측정하고 기록한다"**가 연구의 기본입니다.

## 6-8. 그래프 그리기

| 상황 | 그래프 종류 |
|---|---|
| 방법별 성공률 비교 | 막대그래프 (오차막대 포함) |
| 지연에 따른 성능 변화 | 선그래프 |
| 실패 유형 분포 | 누적 막대 |
| 궤적 비교 | 시계열 선그래프 (전환 시점에 세로선) |

**규칙**: 축 이름과 단위를 반드시 쓰기, 비교 대상은 같은 색 체계로, 흑백으로 인쇄해도 구분되게

## 6-9. 논문/보고서 구조

```
1. Introduction   문제와 왜 중요한가
2. Related Work   기존 연구와 무엇이 다른가
3. Method         내 방법 (그림 1이 제일 중요)
4. Experiments    설정 → 결과 표 → ablation → 실패 분석
5. Conclusion     한계와 다음 단계
```
