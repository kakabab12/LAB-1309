# 2단계. 로봇 기초 (2~3주)

> 논문에 나오는 로봇 용어를 모르면 방법 부분이 안 읽힙니다. 수학을 깊게 팔 필요는 없고, **개념과 용어**를 확실히 잡으세요.

## 2-1. 로봇팔의 구조

| 용어 | 뜻 |
|---|---|
| **링크(link)** | 팔의 마디 |
| **조인트(joint)** | 관절. 회전형(revolute)이 대부분 |
| **자유도(DOF)** | 독립적으로 움직일 수 있는 축의 수 |
| **엔드 이펙터(end-effector)** | 팔 끝에 달린 도구. 여기서는 그리퍼 |
| **베이스(base)** | 고정된 밑판. 좌표계의 기준 |
| **페이로드(payload)** | 들 수 있는 무게 |
| **반복 정밀도** | 같은 자세로 돌아오는 정확도 |

**우리 로봇: AgileX PiPER**
- **6축 + 그리퍼**
- 6축 = 관절 6개 → 관절값 6개 + 그리퍼 1개 = **동작 7차원**

**왜 6축인가**: 3차원 공간에서 물체의 위치(x, y, z)와 방향(roll, pitch, yaw)을 정하려면 **최소 6개**가 필요합니다. 7축(예: Franka)은 하나가 남아서(여유 자유도) 같은 끝단 위치를 여러 자세로 만들 수 있습니다.

## 2-2. ⭐ 관절 공간 vs 작업 공간

**이 연구의 핵심 개념입니다.**

| | 관절 공간 (joint space) | 작업 공간 (task/Cartesian space) |
|---|---|---|
| 표현 | [관절1, 관절2, ..., 관절6, 그리퍼] | [x, y, z, roll, pitch, yaw, 그리퍼] |
| 의미 | "각 관절을 몇 도로" | "그리퍼를 어디로, 어떤 방향으로" |
| 로봇이 바뀌면 | ❌ 의미가 달라짐 (링크 길이·배치가 다름) | ✅ 의미가 같음 |
| 계산 | 바로 제어 가능 | 역기구학 필요 |

→ **"어느 로봇팔이든 되게" 하려면 작업 공간(끝단 좌표)으로 표현**해야 합니다.
LIBERO도 동작이 **6차원 끝단 변화량 + 그리퍼 = 7차원**입니다.

## 2-3. 순기구학 / 역기구학

| | 무엇 | 어려움 |
|---|---|---|
| **순기구학 (FK)** | 관절값 → 끝단 위치 | 계산이 항상 됨 (쉬움) |
| **역기구학 (IK)** | 끝단 위치 → 관절값 | **답이 여러 개거나 없을 수 있음** |

**IK에서 생기는 문제**
- **해가 없음**: 팔이 닿지 않는 위치
- **해가 여러 개**: 팔꿈치를 위로/아래로 등
- **특이점(singularity)**: 특정 자세에서 관절 속도가 무한대로 튐 → 위험
- **관절 한계**: 관절이 돌 수 있는 각도 범위를 넘음

**대응**: 작업 공간을 **로봇 정면 탁상 위**로 제한하면 대부분 피할 수 있습니다.

## 2-4. ⭐ 회전 표현

논문마다 다르게 쓰기 때문에 셋 다 알아야 합니다.

| 표현 | 차원 | 특징 |
|---|---|---|
| **오일러각** (roll, pitch, yaw) | 3 | 직관적. **짐벌락** 문제 |
| **쿼터니언** | 4 | 안정적. 직관성 낮음 |
| **축-각 (axis-angle)** | 3 | 회전축 + 회전량. **LIBERO 상태가 이것** |
| **회전행렬** | 9 | 계산에 편리 |
| **6D 표현** | 6 | 학습에 유리 (연속성) |

**꼭 알 것**: 오일러각은 **표현이 끊기는 지점**이 있어서, 신경망이 학습하기 어려울 수 있습니다. 그래서 로봇 학습에서는 축-각이나 6D 표현을 자주 씁니다.

## 2-5. 제어

| 용어 | 뜻 |
|---|---|
| **위치 제어** | "여기로 가라" (우리가 쓸 방식) |
| **속도 제어** | "이 속도로 움직여라" |
| **토크/임피던스 제어** | 힘을 조절. 사람과 접촉할 때 |
| **절대 vs 상대(delta) 명령** | ⭐ "좌표 (0.3, 0.2, 0.1)로" vs "지금 위치에서 1cm 더" |
| **제어 주기** | 초당 명령 횟수 (Hz) |
| **지연(latency)** | 명령이 실제로 반영되기까지 걸리는 시간 |

> LIBERO는 **상대(delta) 방식이 기본**이고, 정책마다 절대/상대가 달라서 평가할 때 맞춰야 합니다.
> 제어 주기와 지연은 **"저사양에서도 되는가"** 연구의 핵심 변수입니다.

## 2-6. 그리퍼

- 보통 **열림 정도 1차원**으로 표현 (0=닫힘, 1=열림 또는 반대)
- ⭐ **"지금 물체를 잡고 있는가"**를 판정하는 데 쓰임 → **이 연구의 핵심 조건**
- 판정 방법: 그리퍼가 닫혀 있는데 완전히 닫히지 않음 = 무언가를 물고 있음

## 2-7. 좌표계와 캘리브레이션

| 용어 | 뜻 |
|---|---|
| **베이스 좌표계** | 로봇 기준 |
| **카메라 좌표계** | 카메라 기준 |
| **hand-eye calibration** | 카메라와 로봇의 위치 관계를 구하는 작업 |
| **손목 카메라 / 3인칭 카메라** | 로봇에 붙은 카메라 / 고정된 카메라 |

> VLA는 보통 **이미지에서 바로 동작을 출력**해서 캘리브레이션 없이도 동작하지만, 카메라 위치가 바뀌면 성능이 떨어집니다. → **데이터 수집 때와 실행 때 카메라를 같은 곳에 고정**해야 합니다.

## 2-8. 실습 과제

1. PiPER 관절 6개를 종이에 그리고, "그리퍼를 오른쪽으로 5cm" 옮길 때 어느 관절이 움직이는지 표시
2. Python으로 회전 변환 연습 (`scipy.spatial.transform.Rotation`)
   - 오일러각 → 쿼터니언 → 축-각 서로 변환해보기
3. LIBERO 상태 8차원이 각각 무엇인지 문서에서 확인하고 적기
   - (끝단 위치 3 + 축-각 3 + 그리퍼 2)
4. (가능하면) `piper_sdk` 설치하고 문서 읽기 — 관절 제어와 끝단 제어 함수 찾기

## 2-9. 체크리스트

- [ ] 6축과 7축의 차이를 설명할 수 있다
- [ ] 관절 공간과 작업 공간의 차이, 그리고 왜 작업 공간이 로봇 간 호환에 유리한지 안다
- [ ] FK와 IK가 뭔지, IK가 왜 어려운지 안다
- [ ] 축-각 표현이 무엇인지 안다
- [ ] 절대 명령과 상대(delta) 명령의 차이를 안다
- [ ] 그리퍼 값으로 "잡고 있는지"를 어떻게 판정할지 아이디어가 있다

## 2-10. 여유가 되면
