# 4단계. VLA 논문 읽기 (3~4주)

## 📌 쉬운 말 요약

**이 문서는 뭐 하는 곳?** 읽어야 할 논문 목록과 **논문 읽는 요령**입니다.

**논문이 무섭다면**: 처음부터 끝까지 읽는 사람은 없습니다. 이렇게 읽으세요.
1. **그림 1번을 봅니다** (대부분 전체 구조도예요. 여기에 논문의 90%가 있습니다)
2. 초록(맨 앞 5~6줄)만 읽습니다
3. 실험 표에서 **"뭐랑 비교했나"**만 봅니다
4. 끝에 **"한계(Limitation)"**를 봅니다 ← 다음 연구 아이디어가 여기 있어요

**한 편에 30분이면 충분합니다.** 다 이해 못 해도 정상이에요.

**꼭 읽을 3편만 고르면**
- **SmolVLA** — 우리가 쓸 모델
- **Real-Time Chunking** — 우리 연구와 가장 비슷한 선행 연구
- **Hi Robot** — 사람이 중간에 끼어들 때 처리하는 방법

---

## 4-1. VLA란

> **VLA = Vision(보고) + Language(듣고) + Action(움직이기)**
>
> 카메라 이미지와 언어 지시를 입력받아, **로봇 동작을 직접 출력**하는 모델

```
[카메라 이미지] ─┐
[언어 지시]    ─┼─▶ [VLM 백본] ─▶ [동작 출력부] ─▶ [관절/끝단 명령]
[로봇 상태]    ─┘
```

**기존 로봇 제어와 다른 점**: 태스크마다 프로그램을 따로 짜지 않고, **하나의 모델이 말로 지시받아** 여러 태스크를 수행합니다.

## 4-2. 읽을 논문 목록 (순서대로)

### 기초 — VLA의 시작

| 논문 | 핵심 | 왜 읽나 |
|---|---|---|
| **RT-1** (Google) | 로봇 데이터로 Transformer 학습 | VLA의 출발점 |
| **RT-2** | 웹 데이터로 학습한 VLM을 로봇에 전이 | "인터넷 지식 → 로봇" 아이디어 |
| **Octo** | 27M/93M 경량 범용 정책 | 작은 모델의 가능성 |

### 표준 — 반드시 읽을 것

| 논문 | 크기 | 핵심 |
|---|---|---|
| ⭐ **OpenVLA** | 7B | 오픈소스 VLA의 기준. 이미지→동작 토큰 자기회귀 출력 |
| ⭐⭐ **SmolVLA** | 0.45B | **내가 쓸 모델.** 경량 VLM + flow matching + 비동기 추론 |
| ⭐ **π0 / π0.5** | 3B | flow matching 기반, action expert 구조 |

### 전환·개입 — 연구 주제와 직결 ⭐

| 논문 | 핵심 | 내 연구와의 관계 |
|---|---|---|
| **Real-Time Chunking** | 추론이 느려도 chunk를 매끄럽게 이어붙이기 | **가장 가까운 선행연구.** 반드시 정독 |
| **Hi Robot** | 사람이 중간에 끼어드는 말을 처리하는 계층 구조 | 도중 개입 처리 |
| **RT-H** | 언어로 실시간 수정 | 언어 기반 교정 |
| **MemoryVLA** | 과거를 기억해 긴 태스크 수행 | "무엇을 하고 있었나" 기억 |

### 경량화 — 저사양 관련

| 논문 | 크기 | 핵심 |
|---|---|---|
| **TurboVLA** | 0.2B | 추론 1GB 미만, PiPER 실물 실험 포함 |
| **VLA-Adapter** | 0.5B 백본 | 소비자 GPU 1장으로 학습 |
| **FLOWER** | 0.95B | CALVIN(연속 지시)에 강함 |
| **TinyVLA / EdgeVLA** | ~1B | 엣지 기기용 |
| **Efficient VLA 서베이** | - | 경량화 기법 전반 정리 |

## 4-3. 논문 읽는 방법

**1회독 (10분)**
1. 제목 + 초록
2. **그림 1** (전체 구조도) — 여기에 논문의 90%가 있음
3. 결론

→ 여기서 **"이 논문이 푸는 문제"를 한 문장**으로 적기

**2회독 (40분)**
4. Introduction의 마지막 문단 (기여 목록)
5. Method — 그림과 함께
6. 실험 표 — **무엇과 비교했는지**, 어떤 조건인지

**3회독 (필요할 때)**
7. Related Work — 이 분야 지도 그리기
8. **Limitation / Future Work** — ⭐ **여기서 연구 아이디어가 나옵니다**
9. Appendix — 하이퍼파라미터, 데이터 상세

**막힐 때**
- 모르는 용어는 그때그때 검색해서 노트에 추가
- GitHub 코드를 같이 보면 훨씬 빨리 이해됩니다
- 리뷰 사이트(Semantic Scholar, OpenReview의 리뷰어 의견)도 도움이 됩니다

## 4-4. 논문마다 답해야 할 질문

각 논문을 읽고 [노트 템플릿](../02_논문노트/TEMPLATE.md)에 적으세요.

1. 이 논문이 푸는 **문제**는?
2. **방법**의 핵심 아이디어 한 문장은?
3. 모델 **크기**와 **백본**은?
4. **동작을 어떻게 출력**하나? (토큰 자기회귀 / diffusion / flow matching)
5. **action chunk**를 쓰나? 길이는?
6. 어떤 **벤치마크**에서, **무엇과 비교**했나?
7. **추론 속도**와 **필요 사양**은?
8. **한계**는? → 내 연구와 연결되는 지점은?

## 4-6. 용어 사전

| 용어 | 뜻 |
|---|---|
| **백본(backbone)** | 기반이 되는 사전학습 모델 (예: SmolVLM, PaliGemma) |
| **action expert** | 동작만 전담하는 작은 모듈 |
| **action token** | 동작을 이산 토큰으로 바꿔 언어처럼 출력하는 방식 |
| **FAST** | 동작 토큰화를 효율적으로 하는 기법 (π0-FAST) |
| **OXE (Open X-Embodiment)** | 여러 로봇 데이터를 모은 대규모 데이터셋 |
| **embodiment** | 로봇의 몸체 종류 |
| **zero-shot** | 학습하지 않은 상황에 바로 적용 |
| **generalization** | 새 물체·배치·조명에서도 되는가 |
| **rollout** | 정책을 한 번 끝까지 실행하는 것 |
| **success rate** | 성공률 |
