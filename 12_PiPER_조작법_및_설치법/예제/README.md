# 예제

공식 demo(`piper_sdk/demo/V2`)를 바탕으로, 처음 해 보는 사람이 차례로 돌려 볼 수 있게 줄인 파일들이다.
- 순서대로 돌리면 된다.
- 움직이는 예제는 시작 전에 Enter 를 눌러야 움직인다.

이 폴더에서 실행한다. 연구실 PC 에서는 `python3` 대신 `~/smolVLA/.venv/bin/python` 을 쓴다.

| 파일 | 하는 일 | 팔이 움직이나 |
|---|---|---|
| `01_read_state.py` | 펌웨어 버전, 제어 모드, 팔 상태, 관절·손끝·그리퍼 값, 1초 CAN 신호 수 | 아니요 (켜지도 않음) |
| `02_move_joint.py` | 관절 하나만 지금 자세에서 `--deg` 만큼 돌렸다가 제자리로 | 예 (속도 1~30%, 30° 이하만 받음) |
| `03_gripper.py` | 그리퍼를 벌렸다 닫았다 다시 벌림 | 그리퍼만 |
| `04_stop.py` | 비상 정지 / `--resume` 으로 풀고 다시 켜기 | 비상 정지면 천천히 내려앉음, 풀면 힘이 빠짐 |
| `common.py` | 연결, 켜기, 단위 바꾸기, 관절 범위 (다른 파일이 가져다 씀) | — |

```bash
python3 01_read_state.py
python3 02_move_joint.py --joint 6 --deg 10 --speed 10
python3 03_gripper.py --open-mm 50
python3 04_stop.py
```

- 펌웨어가 S-V1.8-8 이상이면 모든 명령 끝에 `--v3` 를 붙인다. piper_sdk 0.7.0a1 이상이 필요하다.
- CAN 이름이 `can0` 이 아니면 `--can can_follower1` 처럼 준다.
- `02_move_joint.py` 는 움직이지 않는 관절에 지금 각도를 그대로 보낸다. 범위를 넘는 목표는 보내지 않는다.
  - 쉬는 자세에서 J2·J3 가 범위 끝(0°)을 조금 넘게 읽히면, 범위 끝으로 잘라 보낸다. 0.5° 넘게 자를 때는 알려 준다.
- 끝나도 팔은 켜진 채 그 자리에 있다. 끌 때는 팔을 받치고 끈다 ([3_조작법.md](../3_조작법.md) 9절).

## 확인한 것

11/4 에 가짜 SDK(명령을 받아 적기만 하는 대역)를 붙여 네 파일을 끝까지 돌렸다. 확인한 것은 다음과 같다.
- 보내는 명령의 순서와 값: 켜기 → `MotionCtrl_2(0x01, 0x01, 속도, 0x00)` → `JointCtrl`
- 단위: 0.001°, 0.001 mm
- 범위를 넘는 목표는 거부하는지
- Ctrl-C 를 누르면 그 자리에 서는지

**실물 팔로는 아직 안 돌려 봤다.** 처음 돌릴 때는 `01` 만 먼저 해서 값이 맞게 나오는지 본다.
