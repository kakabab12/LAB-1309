## 5. 자료가 아니라 직접 해 보고 안 것 (연구실 PC, 11/4)

설치는 연구 가상환경을 건드리지 않으려고 임시 폴더에 했다. 미리 보기는 `uv pip install --dry-run` 이다.

| 내용 | 어떻게 알았나 |
|---|---|
| `pip install piper_sdk` → 0.6.2, V3·`piper-can` 없음 | 임시 폴더에 설치하고 패키지 안을 확인 |
| 연구 가상환경에 넣으면 3개만 추가 | 미리 보기 (`--dry-run`) |
| WeGo 플러그인을 의존성째 넣으면 opencv-python 5.0 이 들어옴 | 미리 보기 |
| `piper-doctor` 1단계 OK, 2단계 실패 (팔 없음) | 임시 폴더 설치 후 실행 |
| `python -m lerobot.teleoperate` 는 0.4.4 에 없음, `lerobot-teleoperate`·`lerobot-record` 는 PiPER 설정을 읽음 | 연구 가상환경의 lerobot 0.4.4 로 실행 (CAN 연결에서 멈춤) |
| 연구 가상환경 파이썬에 tkinter 없음, can-utils·ethtool 없음, gs_usb 는 있음 | `import tkinter`, `which candump`, `modinfo gs_usb` |
| 예제 4개의 명령 순서·단위·범위 거부·Ctrl-C | 가짜 SDK 를 붙여 실행 |
| 관절 0 자세가 접힌 자세라는 것 | **확인 안 함** (범위 표에서 짐작). 실물로 볼 것 |
