# 1. 설치법

## 0. 준비물

- PiPER 팔과 전원
- 팔에 딸려 온 USB-CAN 모듈. 공식 문서는 팔에 딸린 모듈만 지원한다고 적었다.
- 리눅스 PC. CAN 을 켜는 스크립트가 리눅스 전용이다.
  - 연구실 PC 는 Ubuntu 22.04, Python 3.10 이다.
  - WeGo 플러그인을 쓰려면 Python 3.10 이상, LeRobot 0.3.0 이상이 필요하다.

## 1. CAN 도구 (한 번, sudo)

```bash
sudo apt update && sudo apt install can-utils ethtool iproute2
```

| 도구 | 하는 일 |
|---|---|
| can-utils | `candump` 처럼 CAN 신호를 보는 도구 |
| ethtool | USB-CAN 모듈이 어느 USB 자리에 꽂혔는지 알아낸다 (모듈이 여러 개일 때) |
| iproute2 | `ip` 명령. 보통 이미 있다. `ip: command not found` 가 나오면 설치 |

그림 창 도구(`piper-ui`, `piper-setup` 등)를 쓰려면 tkinter 도 깐다.

```bash
sudo apt install python3-tk
```

## 2. piper_sdk (팔 제어 라이브러리)

### 펌웨어 버전부터

| 펌웨어 | 설치 | 쓰는 클래스 |
|---|---|---|
| S-V1.8-8 보다 낮음 | `pip3 install python-can piper_sdk` (11/4 기준 0.6.2) | `C_PiperInterface_V2` |
| S-V1.8-8 이상 | `pip3 install python-can "piper_sdk>=0.7.0a1"` | `C_PiperInterface_V3` |

- 펌웨어 버전은 설치하고 CAN 을 켠 뒤 `python3 예제/01_read_state.py` 로 본다. 어느 판으로 깔았든 V2 로 버전은 읽힌다.
- 0.7.0a1 은 미리 보기판(pre-release)이다. 버전을 적어야 받아진다.
- `piper-can` 명령도 0.7.0a1 부터 있다. 0.6.2 에서는 패키지 안의 `can_activate.sh` 를 쓴다 ([2_CAN_연결.md](2_CAN_연결.md)).
- python-can 은 3.3.4 이상이어야 한다.
- conda 를 쓰면 `which pip3` 로 어느 pip 인지 먼저 본다 (공식 문서).

### 일반 PC

```bash
pip3 install python-can piper_sdk
pip3 show piper_sdk          # 깔린 판 보기
```

올리기와 지우기는 다음과 같다.

```bash
pip3 install --upgrade piper_sdk
pip3 uninstall piper_sdk
```

### 연구실 PC (smolVLA 가상환경)

이 가상환경은 uv 로 만들어서 pip 가 없다. uv 로 넣는다.

```bash
cd ~/smolVLA
uv pip install --python .venv/bin/python piper_sdk python-can
```

새로 깔리는 것은 piper-sdk 0.6.2, python-can 4.6.1, wrapt 1.17.3 셋이다. torch·lerobot 등 다른 것은 안 바뀐다. 11/4 에 `--dry-run` 으로 확인했다.

## 3. WeGo 플러그인 (원격 조종, 시범 기록, 설정 창)

PyPI 이름은 `lerobot_robot_wego_piper` 이다.
- `lerobot_robot_piper` 라는 이름의 PyPI 패키지는 상관없는 다른 사람 것이다 (WeGo 안내).
- 코드에서 import 하는 이름은 `lerobot_robot_piper` 이다.

### 일반 PC (새 가상환경 권장)

```bash
pip install lerobot_robot_wego_piper
```

CAN 이름을 재부팅 뒤에도 유지하는 스크립트(`scripts/`)는 소스에만 있다.

```bash
git clone https://github.com/WeGo-Robotics/lerobot_robot_piper.git
cd lerobot_robot_piper && pip install -e .
```

### 연구실 PC (smolVLA 가상환경)

```bash
cd ~/smolVLA
uv pip install --python .venv/bin/python --no-deps lerobot_robot_wego_piper
```

- `--no-deps` 를 붙이는 이유: 의존성째 깔면 opencv-python 5.0 이 새로 깔린다. 그러면 이미 있는 opencv-python-headless 4.12 와 같은 `cv2` 를 덮어쓴다.
- 플러그인에 필요한 lerobot 0.4.4 와 Pillow 는 이미 있고, piper_sdk 는 2절에서 넣었다.
- `scripts/` 가 필요하면 위의 `git clone` 만 해 두고, 스크립트는 그 폴더에서 실행한다.

## 4. 잘 깔렸는지

```bash
python3 -c "import piper_sdk, can; print('ok')"
piper-doctor          # WeGo 플러그인을 깔았을 때
```

`piper-doctor` 는 읽기만 한다. 팔에 명령을 보내지 않는다.
- 패키지 → USB-CAN 모듈 → CAN 상태 → 팔 응답 → 재부팅 유지, 다섯 단계를 차례로 본다.
- 실패한 단계마다 고칠 명령을 알려 준다.

11/4 연구실 PC 결과 (팔 안 꽂음, 임시 폴더에 설치해서):

```
[1/5] Python packages & plugin registration
  [OK  ] Python 3.10.12
  [OK  ] piper_sdk
  [OK  ] lerobot - 0.4.4
  [OK  ] 'piper_follower' auto-discovered by lerobot
  [OK  ] 'piper_leader' auto-discovered by lerobot
[2/5] CAN adapter hardware
  [FAIL] no CAN-USB adapter (1d50:606f) on USB bus
  [WARN] gs_usb kernel module not loaded - usually auto-loads on plug
```

2단계 실패는 USB-CAN 모듈을 안 꽂아서다. 팔을 꽂고 다시 돌려 2~4단계가 OK 인지 본다.
