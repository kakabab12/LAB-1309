# 3. 조작법 (piper_sdk)

아래 코드는 공식 demo(`piper_sdk/demo/V2`, `V3`)를 바탕으로 했다.
- 바로 돌려 볼 수 있는 파일은 [예제/](예제/README.md) 에 있다.
- 처음에는 꼭 속도 10% 로 돌린다.

## 1. 연결하고 펌웨어 보기 (팔은 안 움직임)

```python
import time
from piper_sdk import C_PiperInterface_V2

piper = C_PiperInterface_V2(can_name="can0")
piper.ConnectPort()
time.sleep(0.05)                          # 펌웨어 답을 받을 시간. 안 기다리면 -0x4AF
print(piper.GetPiperFirmwareVersion())    # 예: S-V1.6-3
```

펌웨어가 **S-V1.8-8 이상**이면 `C_PiperInterface_V3` 를 쓴다 (piper_sdk 0.7.0a1 이상). 사용법은 아래와 같다.
- V3 에서 바뀐 것은 세 가지다: MOVE M 번호(0x04 → 0x06), MIT 제어 프레임, 그리퍼 각도 모드.
- 이 문서에서 쓰는 관절 제어(MOVE J), 손끝 제어(MOVE P), 그리퍼 폭 제어는 V2 와 같다.

## 2. 리더 / 팔로워 모드

SDK 명령을 받으려면 팔이 **팔로워(운동 출력 팔)** 모드여야 한다. 리더(티칭 입력 팔) 모드에서는 명령에 반응하지 않는다.

```python
piper.MasterSlaveConfig(0xFC, 0, 0, 0)    # 팔로워로   (0xFA 는 리더로)
```

- 바꾼 뒤에는 팔 전원을 껐다 켜야 적용된다.
- WeGo `piper-ui` 의 Set Follower / Set Leader 단추도 같은 명령을 보낸다.

## 3. 단위와 범위

SDK 는 모두 정수로 주고받는다.

| 무엇 | 함수 | 단위 | 예 |
|---|---|---|---|
| 관절 각도 | `JointCtrl`, `GetArmJointMsgs` | 0.001° | 10° → 10000 |
| 손끝 위치 | `EndPoseCtrl`, `GetArmEndPoseMsgs` | 0.001 mm | 215 mm → 215000 |
| 손끝 방향 (RX·RY·RZ 오일러각) | 같음 | 0.001° | 85° → 85000 |
| 그리퍼 벌림 | `GripperCtrl`, `GetArmGripperMsgs` | 0.001 mm (0 = 닫힘) | 50 mm → 50000 |
| 그리퍼 힘 | `GripperCtrl` | 0.001 N·m (0~5000) | 1 N·m → 1000 |
| 속도 | `MotionCtrl_2` | 최대 속도의 % (0~100) | 10 |

라디안에서 바꿀 때는 `round(rad * 57295.7795)` 로 계산한다 (1000 × 180 / π).

관절 범위 (`JointCtrl` 설명, 0° 는 영점):

| J1 | J2 | J3 | J4 | J5 | J6 |
|---|---|---|---|---|---|
| ±150° | 0~180° | −170~0° | ±100° | ±70° | ±120° |

- WeGo 표에는 J5 가 ±65° 로 더 좁게 적혀 있다. J5 는 ±65° 안에서 쓰는 것이 안전하다.
- 작은 그리퍼는 최대 70 mm 까지 벌어진다 (demo 주석).

## 4. 켜기

```python
while not piper.EnablePiper():     # 관절 6개가 다 켜질 때까지 되풀이
    time.sleep(0.01)
```

켜지면 모터에 힘이 들어가 그 자리에 선다.

## 5. 관절 움직이기 (MOVE J)

```python
piper.MotionCtrl_2(0x01, 0x01, 10, 0x00)   # CAN 명령 모드, MOVE J(관절), 속도 10%, 위치·속도 모드
piper.JointCtrl(j1, j2, j3, j4, j5, j6)     # 0.001° 단위 정수 6개
```

- 공식 demo 는 이 두 줄을 0.005초마다 계속 보낸다. 우리 예제(`02_move_joint.py`)는 0.01초마다 보낸다.
- 팔은 목표까지 스스로 경로를 만들어 간다. 목표만 바꿔 보내면 된다.
- 움직이고 싶지 않은 관절은 지금 각도를 그대로 넣는다. 0 을 넣으면 그 관절이 0° 로 간다.

## 6. 그리퍼

```python
piper.GripperCtrl(0, 1000, 0x02, 0)          # 오류 지우기 (처음 한 번, 0x02 = 끄고 오류 지움)
piper.GripperCtrl(0, 1000, 0x01, 0)          # 켜기 (0x01 = 켬)
piper.GripperCtrl(50 * 1000, 1000, 0x01, 0)  # 50 mm 벌리기, 힘 1 N·m
piper.GripperCtrl(0, 1000, 0x01, 0)          # 닫기
```

처음 쓰는 그리퍼가 늘 0 이고 안 움직이면, 공장에서 벌림 범위가 안 정해진 것이다 (공식 Q&A 1). 이렇게 한다.
1. 팔을 끈다 (`piper_ctrl_disable.py`). **힘이 바로 빠지니 팔을 받친다.**
2. 벌림 범위를 정한다 (`V2_piper_set_gripper_param.py`, 안의 값 `GripperTeachingPendantParamConfig(100, 70, 1)`).
3. 값이 나오는지 본다 (`piper_read_gripper_status.py`).
4. 닫았을 때 값이 너무 크면 그리퍼 영점을 맞춘다 (`piper_set_gripper_zero.py`).

## 7. 손끝 자세로 움직이기 (MOVE P)

```python
piper.MotionCtrl_2(0x01, 0x00, 10, 0x00)          # MOVE P (손끝 자세)
piper.EndPoseCtrl(X, Y, Z, RX, RY, RZ)            # 0.001 mm, 0.001°
```

- 공식 demo 의 자세: X 56.127 mm, Y 0, Z 215 mm, RX 0°, RY 85°, RZ 0°. demo 는 Z 를 258 mm 로 올렸다 내렸다 한다.
- 손끝 자세에서 관절 각도는 팔 안의 역기구학(IK)이 계산한다. 풀 수 없는 자세면 팔 상태에 `0x02 해 없음` 이 뜬다.
- 우리 실물 연결 코드(`11_실물_PiPER/real_piper`)는 MOVE P 를 쓰지 않는다. 시뮬과 같게 하려고 우리 IK 로 관절을 계산해서 MOVE J 로 보낸다.

## 8. 상태 읽기

| 함수 | 주는 것 |
|---|---|
| `GetArmJointMsgs().joint_state.joint_1` ~ `joint_6` | 관절 각도 (0.001°) |
| `GetArmGripperMsgs().gripper_state.grippers_angle`, `.grippers_effort` | 그리퍼 벌림 (0.001 mm), 힘 (0.001 N·m) |
| `GetArmEndPoseMsgs().end_pose.X_axis` … `RZ_axis` | 손끝 자세 (0.001 mm, 0.001°) |
| `GetArmStatus().arm_status` | 제어 모드, 팔 상태(오류), 움직임 모드, 관절별 오류 |
| `GetArmEnableStatus()` | 관절 6개가 켜졌는지 (True/False 6개) |
| `GetCanFps()` | 1초 CAN 신호 수 |

`print(piper.GetArmStatus())` 하면 SDK 가 이름을 붙여 보여 준다.

- 팔 상태 (`arm_status`)

  | 값 | 뜻 |
  |---|---|
  | 0x00 | 정상 |
  | 0x01 | 비상 정지 |
  | 0x02 | 해 없음 (IK) |
  | 0x03 | 특이점 |
  | 0x04 | 목표 각도가 범위를 넘음 |
  | 0x05 | 관절 통신 이상 |
  | 0x06 | 브레이크가 안 풀림 |
  | 0x07 | 충돌 |
  | 0x09 | 관절 상태 이상 |
  | 0x0E, 0x0F | 과열 |

- 제어 모드 (`ctrl_mode`)

  | 값 | 뜻 |
  |---|---|
  | 0x00 | 대기 |
  | 0x01 | CAN 명령 |
  | 0x02 | 티칭 |
  | 0x06 | 연동 티칭 입력 (리더 팔) |

## 9. 멈추기와 끄기

| 명령 | 무엇이 되나 |
|---|---|
| 지금 관절 각도를 목표로 다시 보내기 | 그 자리에 선다. 우리 예제와 real_piper 에서 Ctrl-C 를 누르면 이렇게 한다 |
| `EmergencyStop(0x01)` | 비상 정지. **팔이 천천히 내려앉는다** (demo `piper_ctrl_stop.py`) |
| `EmergencyStop(0x02)` = `ResetPiper()` | 풀기/리셋. **힘이 바로 빠져 떨어진다.** 오류를 지운다. 다시 켜야 움직인다 |
| `DisablePiper()` | 끄기. **모든 모터 힘이 바로 빠진다** |

- 끝낼 때는 팔을 접은 자세로 옮기고, 손으로 받친 채 끄거나 전원을 내린다.
- 접은 자세: WeGo `piper-ui` 의 Parking 단추, 또는 관절을 모두 0 으로 (demo `piper_ctrl_go_zero.py`). 범위 표에서 J2·J3 의 0° 가 범위 끝이라, 0 자세가 접힌 자세로 보인다. 실물로 확인할 것.
- 비상 정지 뒤에 다시 쓰려면 다음 순서로 한다. 공식 demo 설명은 "reset 하고 enable 을 두 번" 이라고 적었다.
  1. 팔이 다 내려앉은 것을 본다.
  2. `EmergencyStop(0x02)` 를 보낸다.
  3. `EnablePiper()` 로 다시 켠다.

## 10. 영점 맞추기 (필요할 때만)

관절 영점이 어긋나면 모든 각도가 그만큼 틀린다.

- WeGo `piper-calibrate` 로 맞춘다.
  1. 손으로 각 관절을 영점 자세에 둔다.
  2. Set Zero 를 누른다. 값이 모터 플래시에 저장되어 전원을 꺼도 남는다.
  3. 영점에서 5° 넘게 벗어난 관절은 한 번 더 묻는다.
- 리더·팔로워 짝은 같은 기준 자세에서 맞춘다.
- 영점 정확도는 손으로 자세를 얼마나 정확히 만드느냐에 달렸다. 링크 길이 오차나 기어 유격은 영점으로 고쳐지지 않는다 (WeGo 안내).
- 우리 실물 연결 전에는 `11_실물_PiPER/real_piper/check_fk.py` 를 먼저 돌린다. SDK 가 계산한 손끝 자세와 우리 모델이 계산한 자세를 견줘, 영점과 관절 방향(부호)이 맞는지 본다.
