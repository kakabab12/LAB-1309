# 4. 리더 팔로 원격 조종하고 시범 기록하기

사람이 리더 팔을 손으로 움직이면 팔로워 팔이 똑같이 따라 움직이는 것을 원격 조종(teleoperation)이라고 한다. 이것을 카메라와 함께 기록하면 VLA 학습에 쓰는 시범 데이터가 된다.

## 방법 1. 두 팔을 CAN 으로 바로 잇기 (공식, PC 없이 따라 움직임)

출처: piper_sdk `assets/double_piper.MD`

1. 한 팔은 리더(`MasterSlaveConfig(0xFA, 0, 0, 0)`)로, 다른 팔은 팔로워(`0xFC`)로 설정한다. 바꾼 뒤 팔을 다시 켠다.
2. 두 팔의 CAN 선을 서로 잇는다.
3. **팔로워를 먼저 켜고, 그다음 리더를 켠다.** 몇 초 기다린 뒤 리더를 손으로 움직이면 팔로워가 따라 한다.
4. 안 되면 CAN 선을 확인하고 두 팔을 껐다 켠다.

이 상태에서 USB-CAN 모듈을 같은 선에 꽂으면 PC 에서 읽기만 할 수 있다.

| 함수 | 읽는 것 |
|---|---|
| `GetArmJointCtrl()`, `GetArmGripperCtrl()` | 리더가 보낸 목표 (관절 0.001°, 그리퍼 0.001 mm) |
| `GetArmJointMsgs()`, `GetArmGripperMsgs()` | 팔로워가 실제로 간 값 |

원격 조종이 끝나고 PC 로 팔로워를 직접 움직이려면 먼저 리셋(`MotionCtrl_1(0x02, 0, 0)`)을 해야 한다 (공식 문서). **이때 힘이 빠지니 팔을 받친다.**

## 방법 2. WeGo 플러그인 + LeRobot (모듈 2개, PC 가 중계)

리더와 팔로워를 각자 USB-CAN 모듈로 PC 에 잇는다. PC 가 리더 각도를 읽어 팔로워에 보낸다.
- 카메라를 붙여 바로 LeRobot 데이터셋으로 기록할 수 있다.
- 한 스텝에 관절이 움직이는 양을 `max_relative_target` 으로 묶을 수 있다.

### 처음 한 번

```bash
piper-setup                                  # 팔 이름 can_leader1, can_follower1 정하기
sudo bash scripts/install_can_persist.sh     # 재부팅 뒤에도 이름·CAN 유지 (소스 폴더에서)
python camera_check.py                       # 카메라 번호 찾기 (소스 폴더에서)
```

### 원격 조종

창으로 보면서 하려면 `piper-teleop` 를 쓴다. 두 팔의 관절 막대, 팔로워 상태, 오류 번호가 나온다.

명령으로:

```bash
lerobot-teleoperate \
  --robot.type=piper_follower --robot.port=can_follower1 \
  --teleop.type=piper_leader --teleop.port=can_leader1
```

> WeGo README 의 `python -m lerobot.teleoperate` 는 예전 LeRobot 의 꼴이다. 연구실 PC 의 LeRobot 0.4.4 에는 그 모듈이 없다. 대신 `lerobot-teleoperate`, `lerobot-record` 명령을 쓴다.
> 11/4 에 이 명령과 아래 기록 명령이 PiPER 설정을 제대로 읽는 것까지 확인했다. 팔이 없어서 CAN 연결 단계에서 멈췄다.

### 시범 기록

```bash
lerobot-record \
  --robot.type=piper_follower --robot.port=can_follower1 \
  --robot.cameras='{"top": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30}}' \
  --teleop.type=piper_leader --teleop.port=can_leader1 \
  --dataset.repo_id=lab1309/piper_pick \
  --dataset.single_task="put the red cube on the blue pad" \
  --dataset.num_episodes=10 \
  --dataset.push_to_hub=false
```

| 설정 | 뜻 |
|---|---|
| `--robot.cameras` | 기록할 카메라 (이름, 장치 번호, 크기, fps). 여러 대면 `{"top": …, "wrist": …}` |
| `--dataset.repo_id` | 데이터셋 이름. 저장 위치는 `~/.cache/huggingface/lerobot/<이름>` (`--dataset.root` 로 바꿈) |
| `--dataset.single_task` | 이 시범들의 지시문 |
| `--dataset.num_episodes` | 몇 번 기록할지 |
| `--dataset.push_to_hub=false` | Hugging Face 에 올리지 않음 (기본은 올림) |

### Python 으로

```python
from lerobot_robot_piper import PiperFollowerConfig, PiperLeaderConfig, PiperFollower, PiperLeader

follower = PiperFollower(PiperFollowerConfig(port="can_follower1"))
leader = PiperLeader(PiperLeaderConfig(port="can_leader1"))
follower.connect(); leader.connect()
try:
    while True:
        action = leader.get_action()        # 리더 관절 읽기
        follower.send_action(action)        # 팔로워에 보내기
        obs = follower.get_observation()    # 팔로워 관절 + 카메라
finally:
    follower.disconnect(); leader.disconnect()
```

`disconnect()` 는 기본으로 팔로워 모터를 끈다 (`disable_torque_on_disconnect=True`). 힘이 빠지니 팔을 받친다.

## WeGo 기록 꼴과 우리 VLA 학습 꼴

| | WeGo 플러그인 기록 | 우리 시뮬 학습 데이터 (w12m) |
|---|---|---|
| 로봇 상태 | 7개: `joint1.pos` … `joint6.pos` (−100~100 으로 바꾼 값), `gripper.pos` (0~100) | 손끝 위치 3 + 손 방향 3 + 손가락 2 = 8개 (+ 장면 정보 24) |
| 동작 | 관절 목표 7개 (같은 꼴) | 손끝 변화량 6 + 그리퍼 1 |
| 사진 | 카메라 그대로 | 512×512, 위아래 뒤집힘, 위 카메라 + 손목 카메라 |

실물 시범을 우리 학습에 쓰려면 꼴을 바꾸는 도구가 있어야 한다. 아직 없다. 바꾸는 방법은 다음과 같다.
- 관절 각도는 우리 운동학(`11_실물_PiPER/real_piper/kin.py`)으로 손끝 위치와 방향으로 바꾼다.
- 사진은 `cameras.py` 와 같은 방법으로 자르고 뒤집는다.
